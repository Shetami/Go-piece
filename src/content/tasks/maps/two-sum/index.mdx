Напишите тело `TwoSum` за `O(n)`.

Что проверяют скрытые тесты:

- `[2 7 11 15]` и 9 → индексы 0 и 1; отрицательные числа тоже работают;
- `[3 3]` и 6 → пара из двух одинаковых значений находится;
- `[3 5]` и 6 → пары нет: элемент нельзя сложить сам с собой;
- пустой вход и отсутствие пары → `false`;
- 200 000 элементов, ответ в самом конце, — быстрее секунды.

<Reveal>

```go
func TwoSum(nums []int, target int) (int, int, bool) {
	seen := make(map[int]int, len(nums))
	for j, x := range nums {
		if i, ok := seen[target-x]; ok {
			return i, j, true
		}
		seen[x] = j
	}
	return 0, 0, false
}
```

**Мапа отвечает на вопрос «встречалось ли уже `target - x`» за `O(1)`.**
Двойной цикл задаёт тот же вопрос перебором — `O(n²)`, на 200 000
элементах это 20 миллиардов сложений.

**Порядок двух строк в теле цикла важен.** Сначала ищем пару среди
*прошлых* элементов, потом запоминаем текущий. Если сначала положить `x`
в мапу, то для `[3 5]` и 6 найдётся «пара» из тройки с самой собой.

**Дубликаты не мешают.** `[3 3]` и 6: на втором шаге первая тройка уже в
мапе, пара найдена. Если значение повторится ещё раз, мапа перезапишет
индекс — для «любой пары» это неважно.

</Reveal>
