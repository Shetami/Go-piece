title: Мапа мап падает на первой записи
description: Внешняя мапа создана, а запись во вложенную падает с паникой. Почините.

Права доступа хранятся в мапе мап: пользователь → ресурс → право.
Первая же запись падает:

```
panic: assignment to entry in nil map
```

Почините. Ожидаемый вывод:

```
map[аня:map[деньги:запись отчёты:чтение] боря:map[отчёты:запись]]
```

<Reveal>

**Внешнюю мапу создали, внутренние — нет.** `acl[g[0]]` для нового
пользователя — отсутствующий ключ, и чтение возвращает нулевое значение
типа `map[string]string`, то есть `nil`. Дальше `[g[1]] = ...` — запись в
`nil`-мапу, паника.

Литерал `map[string]map[string]string{}` создаёт только внешний уровень.
Вложенные мапы Go сам не заводит — в отличие от `defaultdict` в Python.

**Как чинят** — создавать внутреннюю мапу при первом обращении:

```go
if acl[user] == nil {
	acl[user] = map[string]string{}
}
acl[user][res] = perm
```

**Альтернатива** — плоская мапа с составным ключом:

```go
type key struct{ user, res string }
acl := map[key]string{}
acl[key{"аня", "отчёты"}] = "чтение"
```

Никаких вложенных `nil`, одно выделение памяти на элемент вместо двух
уровней. Минус — неудобно получить «все права одного пользователя».

</Reveal>
