Рейтинг строится по голосам. Запустите несколько раз: языки с пятью
голосами каждый раз стоят в разном порядке, с тремя — тоже.

Почините: при равных голосах языки должны идти по алфавиту. Ожидаемый
вывод:

```
1. go 5
2. java 5
3. python 5
4. ruby 5
5. kotlin 3
6. rust 3
7. zig 3
8. c 1
```

<Reveal>

**Сортировка упорядочивает только то, что вы ей сказали.** Для равных
голосов функция сравнения говорит «ни один не меньше другого», и их
взаимный порядок остаётся таким, каким был на входе. А на входе — ключи
мапы в случайном порядке.

`sort.SliceStable` не помог бы: стабильная сортировка сохраняет входной
порядок равных, но входной порядок тут и есть случайный.

**Как правильно** — добавить второй ключ сортировки:

```go
slices.SortFunc(names, func(a, b string) int {
	return cmp.Or(
		cmp.Compare(votes[b], votes[a]), // голоса по убыванию
		strings.Compare(a, b),           // имя по возрастанию
	)
})
```

`cmp.Or` (Go 1.22) возвращает первый ненулевой аргумент — удобная запись
сортировки по нескольким полям.

**Правило.** Всё, что выводится людям или сравнивается в тестах и пришло
из мапы, должно иметь полный порядок — такой, где равных элементов не
бывает.

</Reveal>
