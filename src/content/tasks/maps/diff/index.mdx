Напишите тело `Diff`.

Что проверяют скрытые тесты:

- добавленные, удалённые и изменённые ключи на обычном примере;
- ключ с **пустым** значением, который появился или исчез, — это тоже
  добавление или удаление, а не «ничего не изменилось»;
- одинаковые мапы → все три списка пустые;
- списки отсортированы — один и тот же вызов всегда даёт один и тот же
  ответ.

<Reveal>

```go
func Diff(old, cur map[string]string) (added, removed, changed []string) {
	for k, v := range cur {
		prev, ok := old[k]
		switch {
		case !ok:
			added = append(added, k)
		case prev != v:
			changed = append(changed, k)
		}
	}
	for k := range old {
		if _, ok := cur[k]; !ok {
			removed = append(removed, k)
		}
	}
	slices.Sort(added)
	slices.Sort(removed)
	slices.Sort(changed)
	return added, removed, changed
}
```

**`v, ok := m[k]` — единственный способ отличить «нет ключа» от «пустое
значение».** С `if old[k] == ""` ключ, у которого значение и было пустым,
считался бы добавленным, а исчезнувший с пустым значением — не удалённым.

**Два прохода.** Первый по новой мапе находит добавленные и изменённые,
второй по старой — удалённые. Одним проходом не обойтись: ключи, которых
нет в `cur`, по `cur` не увидеть.

**Сортировка — часть контракта.** Порядок обхода мапы случаен, и без
сортировки дифф в логах и тестах каждый раз выглядел бы по-разному.

</Reveal>
