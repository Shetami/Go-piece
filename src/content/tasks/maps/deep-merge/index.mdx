`config.yaml` плюс `config.prod.yaml`, значения Helm-чарта плюс
`--set`, настройки по умолчанию плюс настройки пользователя — везде одна
операция: наложить один документ на другой. Напишите `Merge`; правила — в
заготовке.

Базовый конфиг обычно общий и долгоживущий: из него собирают конфиги для
разных окружений и тенантов. Если результат делит с ним хотя бы одну
вложенную мапу, правка конфига одного тенанта незаметно меняет всех.

Что проверяют скрытые тесты:

- слияние на трёх уровнях: нетронутые ключи сохраняются, слайс заменяется
  целиком, скаляр заменяется мапой;
- `nil` удаляет ключ на верхнем уровне и в глубине, а `nil` для
  отсутствующего ключа ничего не создаёт; `Merge(nil, nil)`;
- правка результата на любой глубине — в мапе из `base`, в ключе, которого
  `override` не касался, в слайсе, в мапе внутри слайса, в значении из
  `override` — не видна во входах;
- сами входы после вызова не изменились.

```go
func Merge(base, override map[string]any) map[string]any {
	out := make(map[string]any, len(base)+len(override))
	for k, v := range base {
		out[k] = deepCopy(v)
	}
	for k, ov := range override {
		if ov == nil {
			delete(out, k)
			continue
		}
		bm, bok := out[k].(map[string]any)
		om, ook := ov.(map[string]any)
		if bok && ook {
			out[k] = Merge(bm, om)
			continue
		}
		out[k] = deepCopy(ov)
	}
	return out
}

func deepCopy(v any) any {
	switch x := v.(type) {
	case map[string]any:
		m := make(map[string]any, len(x))
		for k, e := range x {
			m[k] = deepCopy(e)
		}
		return m
	case []any:
		s := make([]any, len(x))
		for i, e := range x {
			s[i] = deepCopy(e)
		}
		return s
	default:
		return v
	}
}
```

**`maps.Clone` — поверхностная копия.** Он копирует только верхний уровень:
значения-мапы и слайсы остаются общими. Типичное решение «склонировать base
и рекурсивно слить в клон» проходит тесты на слияние, но ключ `keep`,
которого `override` не касался, в результате — та же мапа, что в `base`.
Поэтому копируется **каждое** значение, включая нетронутые.

**Значения из `override` тоже копируем.** Вторая частая ошибка —
`out[k] = ov` для нового ключа или заменённого слайса. Потом кто-то правит
результат, и меняется документ переопределений, который, может быть,
применяют к десятку конфигов.

**Мапа-результат не пишет во входы.** Наивный вариант сливает прямо в
`base` (`base[k] = …`) — быстро, но это мутация чужих данных. Здесь рекурсия
получает `bm` — уже нашу копию из `out`, поэтому писать в неё безопасно.

**`nil` как удаление — соглашение JSON Merge Patch (RFC 7386).** Оно же
объясняет, почему слайсы заменяются целиком: у массивов нет ключей, и
слить их «правильно» нельзя, не зная смысла данных.

**Что спросят дальше.** Как копировать значения других типов (`[]string`,
структуры) — через `reflect` или сериализацию, и чем опасен цикл во входе:
`deepCopy` уйдёт в бесконечную рекурсию, для защиты нужна мапа уже
посещённых указателей.
