Три мапы с необычными ключами: структура `point`, массив `[2]int` и `any`.
В последнюю пишут единицу — как `int`, как `int64` и как `float64`.

Напишите весь вывод программы.

<Reveal>

**Ключом может быть любой сравнимый тип.** Структуры сравниваются
поле за полем, массивы — элемент за элементом. Поэтому `point{1, 2}`,
созданный заново, находит ранее записанный ключ, а `point{2, 1}` — другой
ключ и даёт `false`.

**Ключ копируется в мапу.** `grid[k]` находит `"старт"`, потому что `k`
равен `[0 0]`. После `k[0] = 5` это уже другой ключ — отсутствующий. Сам
элемент мапы не пострадал: мапа хранит свою копию массива, а не ссылку на `k`.
Слайс ключом быть не может именно потому, что его нельзя сравнить через `==`.

**Ключ `any` сравнивается по паре (тип, значение).** `1`, `int64(1)` и `1.0`
математически равны, но у них разные динамические типы: `int`, `int64`,
`float64`. Для мапы это три разных ключа. Четвёртая запись снова `int` —
она перезаписывает первую.

Итого:

```
true false
старт
true 1
3 4
```

**Подвох с `any`.** Компилятор разрешит положить в `map[any]int` что угодно,
но если динамический тип несравним — слайс, мапа, функция, — запись упадёт в
рантайме с `panic: runtime error: hash of unhashable type []int`. Проверки
на этапе компиляции здесь нет.

</Reveal>
