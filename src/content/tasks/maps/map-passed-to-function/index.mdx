`fill` добавляет ключ в мапу-параметр. `replace` присваивает параметру новую
мапу и пишет уже в неё. Потом в исходной мапе увеличивают несуществующий ключ.

Напишите весь вывод программы.

<Reveal>

**Мапа — это указатель на внутреннюю структуру.** Переменная типа
`map[string]int` хранит указатель на `runtime.hmap`. При передаче в функцию
копируется указатель, поэтому `fill` пишет в ту же самую мапу и вызывающий
видит `a:1`.

**Но присваивание параметру — это присваивание локальной переменной.**
`m = map[string]int{...}` внутри `replace` меняет копию указателя. Внешняя
`m` по-прежнему указывает на старую мапу, а в новую, с ключами `b` и `c`,
больше никто не смотрит — её соберёт сборщик мусора.

**`m["hits"]++` на отсутствующем ключе работает.** Чтение отсутствующего
ключа даёт нулевое значение, `0 + 1 = 1` записывается обратно. Это
стандартный способ считать частоты без проверки `ok`.

`fmt.Println` печатает мапу с отсортированными ключами — поэтому вывод
детерминирован, хотя порядок обхода `range` случаен.

Итого:

```
map[a:1] 1
map[a:1 hits:1]
```

</Reveal>
