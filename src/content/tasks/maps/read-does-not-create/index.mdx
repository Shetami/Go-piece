Три способа обратиться к ключу, которого в мапе ещё нет: прочитать в
переменную и дописать в неё, дописать прямо через `m["y"] = append(m["y"], …)`
и увеличить счётчик через `++`.

Напишите весь вывод программы.

<Reveal>

**Чтение не создаёт ключ.** `m["x"]` для отсутствующего ключа возвращает
нулевое значение типа — для слайса это `nil` — и больше ничего не делает.
`append` в локальную `v` создаёт новый массив, но в мапу его никто не
кладёт. Мапа по-прежнему пуста.

**`m["y"] = append(m["y"], 1)` — идиома.** Справа чтение даёт `nil`,
`append` к `nil`-слайсу работает, а присваивание уже создаёт ключ. Никаких
проверок «есть ли ключ» не нужно.

**`counts["go"]++` — то же самое** в короткой записи:
`counts["go"] = counts["go"] + 1`. Чтение отсутствующего ключа даёт 0.

Итого:

```
0 true 1
1 [1 2]
map[go:2]
```

**Почему это удобно.** Нулевые значения в Go подобраны так, что с ними
можно сразу работать: к `nil`-слайсу можно дописывать, к нулю прибавлять.
Поэтому группировка и подсчёт в мапах пишутся без `if _, ok := m[k]; !ok`.
Исключение — вложенная мапа: `nil`-мапа только читается, запись в неё
паникует.

</Reveal>
