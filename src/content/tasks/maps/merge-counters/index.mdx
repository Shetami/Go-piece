`merge` должна прибавлять счётчики из одной мапы к другой. Программа
печатает:

```
map[go:2 rust:1 zig:4]
```

Почините. Ожидаемый вывод:

```
map[go:5 rust:2 zig:4]
```

<Reveal>

**`maps.Copy(dst, src)` — это `dst[k] = v` для каждой пары.** Для
существующих ключей значение заменяется. Для слияния настроек это как раз
то, что нужно: последний источник побеждает. Для счётчиков — нет.

**Как правильно:**

```go
for k, v := range src {
	dst[k] += v
}
```

Отсутствующий ключ читается как ноль, поэтому отдельно обрабатывать новые
ключи не нужно.

</Reveal>
