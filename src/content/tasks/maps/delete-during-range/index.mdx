В мапе четыре ключа. Внешний цикл на первой же итерации удаляет из мапы все
ключи, кроме текущего. Какой ключ окажется первым, заранее неизвестно — но
ответ от этого не зависит.

Напишите весь вывод программы.

<Reveal>

**Удалять во время обхода можно** — и это прямо разрешено спецификацией, не
паника и не гонка (если горутина одна). Больше того, про удаление
спецификация даёт гарантию: *если элемент, до которого обход ещё не дошёл,
удалён, он выдан не будет*.

Поэтому на первой итерации удаляются три ключа, до которых цикл ещё не
добрался, и выдавать больше нечего.

Итого:

```
итераций: 1
осталось: 1
```

**С добавлением всё иначе.** Про ключи, добавленные во время обхода,
спецификация говорит: *могут быть выданы, а могут и нет*. Цикл, который на
каждой итерации добавляет ключ, может закончиться через три итерации, а
может через десять — от запуска к запуску по-разному.

**Как пользуются.** Удалить из мапы всё, что подходит под условие, можно
одним циклом, без сбора ключей в отдельный слайс:

```go
for k, v := range m {
	if expired(v) {
		delete(m, k)
	}
}
```

Или короче — `maps.DeleteFunc(m, func(k string, v int) bool { ... })`.

</Reveal>
