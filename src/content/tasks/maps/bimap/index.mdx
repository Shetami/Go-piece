Реализуйте `BiMap[K, V]` — взаимно-однозначную мапу: логины ↔ id
пользователей, коды стран ↔ названия, внутренние ↔ внешние идентификаторы.
Искать нужно в обе стороны за O(1). Поля и конструктор — на ваше усмотрение.

Главное правило: после любой последовательности операций обе стороны
согласованы. `GetByKey(k)` вернул `v` — значит, `GetByValue(v)` вернёт `k`, и
наоборот.

Что проверяют скрытые тесты:

- обычные `Put` и поиск в обе стороны, повторный `Put` той же пары;
- `Put` существующего ключа с новым значением — старое значение больше ни на
  что не указывает;
- `Put(k, v)`, где `v` уже занято другим ключом, а у `k` своё значение, —
  рвутся обе старые пары;
- удаление по ключу и по значению, повторное удаление, нулевые `""` и `0` как
  обычные данные.

<Reveal>

```go
type BiMap[K, V comparable] struct {
	fwd map[K]V
	rev map[V]K
}

func (b *BiMap[K, V]) Put(k K, v V) {
	if old, ok := b.fwd[k]; ok {
		delete(b.rev, old)
	}
	if old, ok := b.rev[v]; ok {
		delete(b.fwd, old)
	}
	b.fwd[k] = v
	b.rev[v] = k
}

func (b *BiMap[K, V]) DeleteKey(k K) bool {
	v, ok := b.fwd[k]
	if !ok {
		return false
	}
	delete(b.fwd, k)
	delete(b.rev, v)
	return true
}
```

(Остальные методы — в эталонном решении.)

**Две мапы — это инвариант, а не просто два индекса.** Наивный `Put`
пишет `fwd[k] = v` и `rev[v] = k` — и ломает согласованность. Было `a→1`,
делаем `Put(a, 2)`: в `rev` остаётся `1→a`, и `GetByValue(1)` отвечает
неправду. Было ещё `b→2` — теперь `fwd[b] = 2`, хотя `2` принадлежит `a`.
Поэтому перед записью рвём **обе** старые связи: прежнее значение ключа и
прежний ключ значения.

**`v, ok := m[k]`, а не сравнение с нулём.** Пара `("", 0)` — законные
данные. Проверка `if old := b.fwd[k]; old != zero` пропустила бы её, и
«удалённая» пара осталась бы висеть в обратной мапе.

**Оба параметра типа — `comparable`.** Значение становится ключом второй
мапы, поэтому ограничение `any` для `V` не скомпилируется. Это частый
вопрос-уточнение: «а если значения — слайсы?» — тогда нужна своя функция
ключа или хэш.

**Что спросят дальше.** Потокобезопасность: один мьютекс на обе мапы —
разные мьютексы на `fwd` и `rev` дадут окно, в котором стороны расходятся.
И вариант «один ко многим», где обратная сторона — `map[V]map[K]struct{}`.
