Одинаковые события должны схлопнуться в одно: для этого их кладут в мапу по
ключу из `dedupKey`. Событий четыре, разных среди них два. Программа
печатает:

```
уникальных событий: 4
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 12: `return &e`.

**Указатели равны, только если указывают на одну и ту же переменную.**
`e` — параметр, при каждом вызове своя переменная, и `&e` всегда новый
адрес. Мапа сравнивает ключи через `==`, и для указателей это сравнение
адресов, а не содержимого. Четыре вызова — четыре разных ключа.

**Как правильно** — ключом делать саму структуру. Структура из сравнимых
полей сравнивается по полям, и одинаковые события дадут один ключ. Для
этого и `any` не нужен — `map[Event]bool` честнее.

**Когда указатель в ключе уместен.** Когда нужна именно идентичность
объекта: «видели ли мы этот узел графа», «есть ли у этого соединения
метаданные». Тогда два разных объекта с одинаковыми полями — действительно
разные ключи.

</Reveal>
