В кофейне вода бесплатная — она есть в мапе с ценой 0. Какао нет вовсе.
Программа печатает:

```
кофе: 200 ₽
вода: нет в меню
какао: нет в меню
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 9: `if price == 0`.

**Нулевое значение и отсутствие ключа — одно и то же для чтения.** Мапа
возвращает `0` и для воды, у которой цена действительно 0, и для какао,
которого нет. По одному значению их не различить, а проверка `price == 0`
считает оба случая «нет в меню».

**Как правильно** — спросить мапу явно:

```go
price, ok := prices[item]
if !ok {
	return item + ": нет в меню"
}
```

**Когда можно без `ok`.** Когда нулевое значение не встречается как
настоящее: счётчики, которые только растут, указатели, непустые строки.
В остальных случаях `ok` — единственный честный ответ на вопрос «есть ли
ключ».

</Reveal>
