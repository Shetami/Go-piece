Отчёт должен перечислить месяцы от лучшего к худшему. Программа печатает:

```
апрель: 150
март: 120
февраль: 90
январь: 100
```

Почините. Ожидаемый вывод:

```
апрель: 150
март: 120
январь: 100
февраль: 90
```

<Reveal>

**`slices.Sorted(maps.Keys(...))` сортирует ключи, а не значения.** Месяцы
отсортированы по алфавиту: а, м, ф, я. Первые два места совпали с нужным
порядком случайно, и на беглый взгляд отчёт выглядит правильным.

Сама идея верная: у мапы нет порядка — ни вставки, ни ключей, ни
значений, — и отсортировать надо явно. Просто критерий не тот.

**Как чинят** — собрать ключи и отсортировать их по значениям:

```go
months := slices.Collect(maps.Keys(sales))
slices.SortFunc(months, func(a, b string) int {
	return cmp.Compare(sales[b], sales[a]) // b, a — по убыванию
})
```

**Равные значения.** Если у двух месяцев одинаковые продажи, их порядок
между собой снова случаен: он зависит от того, в каком порядке ключи пришли
из мапы, а он при каждом запуске новый. Для стабильного отчёта добавляют
второй критерий: `cmp.Or(cmp.Compare(sales[b], sales[a]), cmp.Compare(a, b))`.

</Reveal>
