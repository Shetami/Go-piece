Напишите тело `FirstUnique`.

Что проверяют скрытые тесты:

- `"leetcode"` → `'l'`, `"loveleetcode"` → `'v'`;
- `""`, `"aabb"`, `"абаб"` → `false`;
- кириллица: `"ааббвг"` → `'в'`, `"ёсё"` → `'с'`;
- ответ всегда первый **по порядку в строке**, а не какой-нибудь из
  уникальных.

<Reveal>

```go
func FirstUnique(s string) (rune, bool) {
	counts := make(map[rune]int)
	for _, r := range s {
		counts[r]++
	}
	for _, r := range s {
		if counts[r] == 1 {
			return r, true
		}
	}
	return 0, false
}
```

**Два прохода по строке.** Первый считает, второй ищет первый символ со
счётчиком 1. Искать по мапе нельзя: у неё нет порядка, и ответ был бы
каждый раз разный — какой-нибудь уникальный вместо первого.

**`range` по строке выдаёт руны.** Подсчёт по `s[i]` считал бы байты: у
`ё` и `с` в UTF-8 общий первый байт `0xD1`, и он насчитался бы трижды.

**Если алфавит известен и мал**, мапу заменяют массивом `[26]int` или
`[256]int` — быстрее и без выделений. Для произвольного Юникода мапа —
нормальный выбор.

</Reveal>
