Напишите тело `GroupBy`: мапа от ключа к слайсу элементов с этим ключом.

Что проверяют скрытые тесты:

- группировка строк по длине;
- группировка структур по полю, порядок внутри группы — как во входе;
- для пустого входа — пустая мапа, но **не `nil`**: вызывающий может сразу в
  неё писать.

<Reveal>

```go
func GroupBy[T any, K comparable](xs []T, key func(T) K) map[K][]T {
	out := make(map[K][]T)
	for _, x := range xs {
		k := key(x)
		out[k] = append(out[k], x)
	}
	return out
}
```

**Два параметра типа.** `T` — элементы, на них ограничений нет. `K` — ключ
мапы, поэтому `comparable`. Оба выводятся из аргументов:
`GroupBy(words, func(s string) int { ... })` — `T = string`, `K = int`.

**`out[k] = append(out[k], x)`** — идиома группировки. Для нового ключа
`out[k]` возвращает `nil`, `append` к `nil` создаёт слайс. Никаких проверок
`ok` не нужно. Главное — присвоить результат обратно в мапу, а не в
локальную переменную.

**Почему не `nil`.** Запись в `nil`-мапу — паника. Функция, которая иногда
возвращает `nil`-мапу, заставляет каждого вызывающего проверять результат.
`make` в начале стоит одну аллокацию и снимает вопрос.

</Reveal>
