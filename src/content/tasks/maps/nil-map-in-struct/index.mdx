`Registry` считает, сколько раз добавили каждое имя. Программа падает:

```
panic: assignment to entry in nil map
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 14: `r := &Registry{}`.

**Нулевое значение мапы — `nil`, и в неё нельзя писать.** Литерал
`&Registry{}` оставляет поле `items` нулевым. Читать из `nil`-мапы можно —
вернётся ноль, `len` — 0, `range` пройдёт ноль раз. А запись паникует:
мапе негде хранить элементы, `hmap` ещё не создан.

**Как правильно.** Либо инициализировать поле в литерале, либо — лучше —
завести конструктор:

```go
func NewRegistry() *Registry {
	return &Registry{items: make(map[string]int)}
}
```

Третий вариант — ленивая инициализация прямо в методе:

```go
func (r *Registry) Add(name string) {
	if r.items == nil {
		r.items = make(map[string]int)
	}
	r.items[name]++
}
```

Так нулевой `Registry` становится полезным — это любимая в Go идея
«полезного нулевого значения», как у `sync.Mutex` и `bytes.Buffer`. Цена —
проверка в каждом методе, который пишет.

</Reveal>
