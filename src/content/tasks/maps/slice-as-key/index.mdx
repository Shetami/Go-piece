Маршрут — это слайс городов, и хочется считать поездки прямо по нему.
Компилятор не пропускает:

```
invalid map key type []string
```

Почините. Ожидаемый вывод — сколько раз ездили в Петербург, сколько в
Казань и сколько всего разных маршрутов:

```
2 1 2
```

<Reveal>

**Ключ мапы должен быть сравнимым через `==`.** Слайсы, мапы и функции
несравнимы: для слайса неясно, что считать равенством — один массив или
одинаковое содержимое, — и Go отказывается выбирать.

**Способ 1 — строка из элементов.** `strings.Join(route, "→")`.
Разделитель должен быть таким, который в элементах не встречается, иначе
`["a→b", "c"]` и `["a", "b→c"]` дадут один ключ.

**Способ 2 — массив вместо слайса.** Массивы сравнимы поэлементно:
`map[[2]string]int`. Подходит, если длина маршрута фиксирована.

**Способ 3 — структура**, если у ключа есть смысловые поля:
`type route struct{ from, to string }`. Самый читаемый вариант, когда он
возможен.

</Reveal>
