Типичный `New` сервиса: подключиться к базе, к кэшу, к очереди. Если
очередь недоступна — база и кэш уже открыты, и их надо закрыть, иначе
утекут соединения. Реализуйте `OpenAll`: при успехе — ресурсы и функция
закрытия, при неудаче — ничего открытого не остаётся.

Что проверяют скрытые тесты:

- при успехе ресурсы идут в порядке `openers`, `closeAll` закрывает их в
  обратном, ошибка `Close` одного не мешает закрыть остальные;
- ошибки закрытия и открытия подписаны именем ресурса (`close cache: …`,
  `open queue: …`) и находятся через `errors.Is`;
- повторный `closeAll` ничего не закрывает;
- ошибка открытия на середине: закрыто всё открытое, следующие ресурсы не
  открываются, `res` и `closeAll` — `nil`, в ошибке и причина, и ошибки
  отката;
- паника в `Open`: открытое закрыто, паника летит дальше как есть;
- пустой список — рабочий `closeAll`.

```go
func OpenAll(openers []Opener) (res []io.Closer, closeAll func() error, err error) {
	var names []string
	var opened []io.Closer
	success := false
	defer func() {
		if !success {
			err = errors.Join(err, closeReverse(names, opened))
		}
	}()

	for _, o := range openers {
		c, oerr := o.Open()
		if oerr != nil {
			return nil, nil, fmt.Errorf("open %s: %w", o.Name, oerr)
		}
		names = append(names, o.Name)
		opened = append(opened, c)
	}
	success = true

	closed := false
	return opened, func() error {
		if closed {
			return nil
		}
		closed = true
		return closeReverse(names, opened)
	}, nil
}

func closeReverse(names []string, cs []io.Closer) error {
	var errs []error
	for i := len(cs) - 1; i >= 0; i-- {
		if err := cs[i].Close(); err != nil {
			errs = append(errs, fmt.Errorf("close %s: %w", names[i], err))
		}
	}
	return errors.Join(errs...)
}
```

**Флаг успеха + один `defer`.** Приём из стандартной библиотеки и
`database/sql`: `defer` проверяет «дошли ли до конца». Он срабатывает и
при `return` с ошибкой, и при панике — поэтому `recover` не нужен вовсе:
отложенная функция закрывает ресурсы, а паника после неё летит дальше
сама, со своим значением и стеком.

**Ловушка с именованным `res`.** Хочется копить открытое прямо в
именованном результате `res` и в `defer` закрывать его. Но
`return nil, nil, err` сначала присваивает `nil` результатам и только
потом выполняет отложенные вызовы — откат увидит пустой `res` и ничего не
закроет. Поэтому открытое живёт в отдельной локальной переменной, а
именованным остаётся только `err`, который `defer` дополняет ошибками
отката.

**Обратный порядок** — потому что поздние ресурсы часто зависят от ранних
(транзакция живёт внутри соединения).

**`errors.Join` сохраняет всё.** Вызывающему нужна причина (`open queue`),
но и ошибки отката важны: незакрытое соединение — это утечка, о которой
надо знать. `Join` отбрасывает `nil`, поэтому копить можно без проверок.

**Что спросят следом.** Как сделать то же с таймаутом на закрытие
(`Close(ctx)`), и почему `closeAll` лучше делать идемпотентным: его часто
вызывают и в `defer`, и в обработчике сигнала.
