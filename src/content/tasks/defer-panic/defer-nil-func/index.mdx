`process` откладывает вызов `onDone`, а саму `onDone` присваивает чуть
позже, когда известно, что напечатать. Элементы печатаются, а потом:

```
panic: runtime error: invalid memory address or nil pointer dereference
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 7: `defer onDone()`.

**В момент `defer` вычисляется не только список аргументов, но и сама
функция.** `defer onDone()` читает значение переменной `onDone` сразу — а
там `nil`. Присваивание ниже на уже отложенный вызов не влияет. При выходе
Go пытается вызвать `nil`-функцию — и паникует.

**Как правильно** — отложить замыкание, которое прочтёт переменную при
выходе:

```go
defer func() { onDone() }()
```

Или просто перенести `defer` ниже присваивания. Правило то же, что для
аргументов: всё, что написано в строке `defer` до скобок вызова и внутри
них, вычисляется сразу. Замыкание — способ отложить само чтение.

</Reveal>
