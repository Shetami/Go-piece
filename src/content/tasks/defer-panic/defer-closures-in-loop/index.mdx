Первый цикл откладывает три замыкания над переменной цикла `i`. Второй —
три замыкания над `x`, объявленной до цикла и увеличиваемой в теле.

Напишите весь вывод программы. Версия Go — 1.22 или новее.

<Reveal>

**Отложенные вызовы выполняются в обратном порядке** — при выходе из `main`,
после строки `конец main`. Первыми идут те, что отложены последними: сначала
три замыкания второго цикла, потом первого, и каждая тройка — задом наперёд.

**С Go 1.22 у каждой итерации своя `i`.** Три замыкания первого цикла
захватили три разные переменные со значениями 0, 1 и 2.

**А `x` одна на всех.** Она объявлена вне цикла, и все три замыкания
захватили одну и ту же переменную. Прочитают они её при выходе из `main`,
когда там уже 3.

Итого:

```
конец main
x = 3
x = 3
x = 3
i = 2
i = 1
i = 0
```

**Если нужно значение на момент `defer`** — передайте его аргументом:
`defer func(x int) { ... }(x)` или просто `defer fmt.Println("x =", x)`.
Аргументы отложенного вызова вычисляются сразу.

</Reveal>
