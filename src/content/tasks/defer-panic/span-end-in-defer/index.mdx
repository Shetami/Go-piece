Трассировка в духе OpenTelemetry: `ctx, end := tr.Start(ctx, "name")` и
`defer end(&err)` в начале каждой функции. Реализуйте `Start` так, чтобы
спаны корректно вкладывались и получали правильный статус, в том числе
при панике.

Что проверяют скрытые тесты (часы фиктивные, каждый `Now` — плюс секунда):

- вложенный спан получает родителя из `ctx`, корневой — пустого;
- интервал родителя охватывает интервал ребёнка: `Start` фиксируется при
  старте, `End` — при завершении;
- функция вернула ошибку — статус `error`, `errors.Is` находит её в
  `Err`;
- паника — статус `panic`, текст паники в `Err`, время конца заполнено, а
  паника летит дальше;
- 20 горутин со спанами под одним корнем — все с правильным родителем,
  чисто под `-race`.

<Reveal>

```go
type spanKey struct{}

func (t *Tracer) Start(ctx context.Context, name string) (context.Context, func(errp *error)) {
	parent, _ := ctx.Value(spanKey{}).(string)
	start := t.Now()
	ctx = context.WithValue(ctx, spanKey{}, name)

	return ctx, func(errp *error) {
		s := Span{Name: name, Parent: parent, Start: start, Status: "ok"}
		r := recover()
		switch {
		case r != nil:
			s.Status, s.Err = "panic", fmt.Errorf("паника: %v", r)
		case errp != nil && *errp != nil:
			s.Status, s.Err = "error", *errp
		}
		s.End = t.Now()
		t.mu.Lock()
		t.spans = append(t.spans, s)
		t.mu.Unlock()
		if r != nil {
			panic(r)
		}
	}
}
```

**Указатель на ошибку.** Аргументы отложенного вызова вычисляются в
момент `defer`: `defer end(err)` передал бы `nil`, каким `err` был в начале
функции. `&err` вместе с именованным результатом даёт `end` доступ к
значению, которое функция действительно вернула.

**`recover` работает только в функции, которую вызвал `defer`.** Здесь
`end` и есть отложенная функция, поэтому `recover` внутри неё
останавливает панику. Стоит перенести его в хелпер, вызываемый из
`end`, — и он вернёт `nil`, статус останется `ok`, хотя функция упала.
Обёртка `defer func() { end(&err) }()` тоже ломает `recover` — лишний
уровень.

**Паника — дальше.** Трассировка — наблюдатель: она не имеет права менять
поведение программы. Записали спан — `panic(r)` с тем же значением.

**Свой тип ключа контекста.** Строковый ключ `"span"` может совпасть с
чужим пакетом. Значение неэкспортируемого `spanKey{}` не перетрёт никто.

**Что спросят следом.** Как передать спан через границу процесса
(заголовок `traceparent`), почему спаны часто сэмплируют и как привязать
к спану логи (trace id в каждой записи).
