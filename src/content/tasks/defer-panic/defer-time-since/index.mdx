`slowQuery` засекает время и через `defer` печатает, сколько длилась. Внутри
пауза в 200 мс. Программа печатает:

```
запрос занял 0s
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 10: `defer fmt.Println("запрос занял", time.Since(start)...)`.

**Аргументы отложенного вызова вычисляются сразу.** Отложен только вызов
`fmt.Println`. Его аргументы — строка и `time.Since(start).Round(...)` —
вычисляются в строке с `defer`, то есть через наносекунды после `start`.
Округлённое до 100 мс, это ноль. Потом функция спит, а в конце печатается
заранее посчитанный ноль.

**Как правильно** — отложить замыкание, внутри которого всё и вычисляется:

```go
defer func() {
	fmt.Println("запрос занял", time.Since(start))
}()
```

**Изящный вариант** — функция, которая возвращает функцию:

```go
func timer(name string) func() {
	start := time.Now()
	return func() { fmt.Println(name, time.Since(start)) }
}

defer timer("запрос")()
```

Здесь `timer("запрос")` вычисляется сразу (засекает время), а отложенным
становится то, что он вернул. Обратите внимание на двойные скобки: без
последних `()` отложилась бы сама `timer`.

</Reveal>
