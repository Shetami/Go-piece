У `T` два метода: `Val` на значении и `Ptr` на указателе. Оба откладываются
через `defer`, после чего поле `n` меняют с 1 на 2.

Напишите весь вывод программы.

<Reveal>

**Получатель — это тоже аргумент.** Вызов метода `t.Val()` по сути
`T.Val(t)`, и в момент `defer` получатель вычисляется так же, как любой
аргумент.

- `defer t.Val()` — получатель передаётся по значению. В момент `defer`
  структура копируется, в копии `n == 1`. Потом `t.n = 2` меняет оригинал,
  копию — нет.
- `defer t.Ptr()` — получатель указатель, компилятор подставляет `(&t).Ptr()`.
  Копируется адрес. Когда вызов исполнится, по адресу уже лежит `2`.

Порядок обратный: сначала `Ptr`, потом `Val`.

Итого:

```
указатель: 2
значение: 1
```

**Где стреляет.** `defer stats.Report()` с получателем-значением отчитается
о состоянии на начало функции, а не на конец. Если отложенный метод должен
увидеть итог — получатель должен быть указателем, или вызов оборачивают в
замыкание.

</Reveal>
