Программа пишет отчёт через `bufio.Writer` и откладывает `Flush`. Валидация
находит ошибку — и программа не печатает ни строчки: ни отчёта, ни
ошибки.

Почините так, чтобы весь вывод дошёл до экрана. Ожидаемый вывод:

```
отчёт: строк 3
ошибка: строка 2 пустая
```

<Reveal>

**`os.Exit` не запускает отложенные вызовы.** Он завершает процесс
немедленно: не раскручивает стек, не вызывает `defer`, не ждёт горутины.
`w.Flush()` так и не вызван, а всё, что было записано в `w`, лежало в
буфере в памяти процесса — и исчезло вместе с ним.

То же самое делает `log.Fatal`: это `Print` плюс `os.Exit(1)`.

**Как чинят** — не выходить из глубины программы. Всю работу — в функцию,
которая возвращает ошибку, а `main` решает, что с ней делать, после того
как отложенные вызовы отработали:

```go
func main() {
	w := bufio.NewWriter(os.Stdout)
	defer w.Flush()
	if err := run(w); err != nil {
		fmt.Fprintln(w, "ошибка:", err)
	}
}
```

В настоящей утилите нужен ещё ненулевой код выхода. Тогда `Flush` делают
явно, а `os.Exit(1)` вызывают последней строкой — или весь `main` сводят к
`os.Exit(realMain())`, где `realMain` возвращает код, а все её `defer`
успевают отработать.

</Reveal>
