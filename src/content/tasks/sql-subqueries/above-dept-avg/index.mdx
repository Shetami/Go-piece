Нужны сотрудники, чья зарплата строго выше **средней по их отделу**. Запрос
сравнивает со средней по всей компании: в список попал Борис, а Егора нет.

Почините. Ожидается:

```
Анна | Бэкенд   | 300
Вика | Бэкенд   | 250
Егор | Дизайн   | 190
Глеб | Фронтенд | 220
```

<Reveal>

**Подзапрос должен знать, о каком отделе речь.** Это коррелированный
подзапрос — он ссылается на строку внешнего запроса:

```sql
SELECT e.name, e.dept, e.salary
FROM employees e
WHERE e.salary > (
  SELECT avg(x.salary) FROM employees x WHERE x.dept = e.dept
)
ORDER BY e.dept, e.name;
```

Псевдонимы `e` и `x` обязательны: без них `dept = dept` внутри подзапроса
сравнит колонку саму с собой — и снова получится средняя по компании.

**Вариант без коррелированного подзапроса** — оконная функция:

```sql
SELECT name, dept, salary FROM (
  SELECT *, avg(salary) OVER (PARTITION BY dept) AS dept_avg
  FROM employees
) t
WHERE salary > dept_avg;
```

Один проход по таблице вместо подзапроса на каждую строку. Postgres часто
умеет переписать и коррелированный вариант, но оконная функция надёжнее.

</Reveal>
