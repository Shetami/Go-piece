Магазин выдаёт значок «Коллекционер» клиенту, который купил **каждый
активный** товар категории. Найдите все пары «категория — клиент», которые
заслужили значок.

- учитываются только товары с `is_active = true`: снятый с продажи товар
  покупать не обязательно, а его покупка ничего не добавляет;
- возвращённая покупка (`returned = true`) не считается;
- категория, в которой нет ни одного активного товара, значков не даёт.

- колонки: `category`, `name` (клиента);
- порядок: по `category`, затем по `name`.

Что проверяют скрытые данные: один и тот же товар, купленный несколько раз;
покупку снятого с продажи товара; возврат; категорию, где все товары сняты с
продажи; клиента без покупок.

<Reveal>

```sql
WITH categories AS (
  SELECT DISTINCT category
  FROM products
  WHERE is_active
)
SELECT k.category, c.name
FROM categories k
CROSS JOIN customers c
WHERE NOT EXISTS (
  SELECT 1
  FROM products p
  WHERE p.category = k.category
    AND p.is_active
    AND NOT EXISTS (
      SELECT 1
      FROM purchases x
      WHERE x.customer_id = c.id
        AND x.product_id = p.id
        AND NOT x.returned
    )
)
ORDER BY k.category, c.name;
```

Ответ:

```
Кофе | Аня
Чай | Даша
```

**Деление — это двойное отрицание.** «Клиент купил все товары категории» =
«нет такого товара категории, которого клиент не купил». Внешний `NOT EXISTS`
перебирает товары, внутренний ищет покупку. Кандидатов (категория × клиент)
даёт `CROSS JOIN`.

**Пустое множество.** В «Архиве» нет активных товаров, и «нет товара, который
клиент не купил» истинно для *всех* клиентов, включая Егора без покупок. Поэтому
категории берутся только из активных товаров — это условие стоит в CTE, а не
где-то сбоку.

**Счётчики врут на дублях.** Вариант через группировку тоже классика:
`HAVING count(DISTINCT x.product_id) = (SELECT count(*) … активных в
категории)`. Но каждое слово здесь важно: без `DISTINCT` Боря с тремя
«Эспрессо» и одной «Арабикой» набирает 4 из 3; без фильтра активности в
соединении Вера добирает недостающую «Робусту» снятым «Мокко»; без
`NOT returned` Гоша получает значок за возвращённый товар.

**Что спросят дальше.** «А если нужен процент собранной коллекции?» — тогда
деление превращается в `count(DISTINCT …) FILTER (…) / count(*)` по
`products LEFT JOIN purchases`, и снова те же три ловушки.

</Reveal>
