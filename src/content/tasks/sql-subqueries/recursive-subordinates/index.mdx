Найдите всех подчинённых Бориса (`id = 2`) — прямых и через любое число
ступеней.

- колонки: `name`, `depth` — 1 для прямых подчинённых, 2 для их подчинённых
  и так далее;
- сам Борис в ответ не входит;
- порядок: по `depth`, затем по `name`.

Если запрос зациклится, через пять секунд его остановят.

<Reveal>

```sql
WITH RECURSIVE subordinates AS (
  SELECT id, name, 1 AS depth
  FROM employees
  WHERE manager_id = 2

  UNION ALL

  SELECT e.id, e.name, s.depth + 1
  FROM employees e
  JOIN subordinates s ON e.manager_id = s.id
)
SELECT name, depth
FROM subordinates
ORDER BY depth, name;
```

**Как это исполняется.** Сначала нерекурсивная часть — прямые подчинённые.
Потом рекурсивная часть раз за разом соединяется с тем, что нашлось **на
прошлом шаге**, а не со всей накопленной таблицей. Когда шаг ничего не
добавил, рекурсия останавливается.

**Бесконечный цикл.** Если в данных есть цикл (A руководит B, B руководит
A), запрос не остановится. Защита — ограничение глубины (`WHERE s.depth <
100`) или, в Postgres 14+, конструкция `CYCLE id SET is_cycle USING path`.

**`UNION` вместо `UNION ALL`** выбрасывает дубликаты на каждом шаге и тоже
может спасти от цикла, но стоит дороже, и `depth` в строке всё равно разный.

</Reveal>
