**В подзапросе есть `NULL`** — `manager_id` директора. `id NOT IN (1, 2, 2,
1, NULL)` раскрывается в `id <> 1 AND id <> 2 AND ... AND id <> NULL`.
Последнее сравнение — `UNKNOWN`, и `AND` с ним никогда не даёт `TRUE`. Ни
одна строка не проходит.

С `IN` такого нет: `x IN (..., NULL)` истинно, если `x` совпал хоть с чем-то.
Ломается только отрицание.

**Как чинят:**

```sql
WHERE NOT EXISTS (
  SELECT 1 FROM employees s WHERE s.manager_id = e.id
)
```

или отфильтровать `NULL` в подзапросе: `WHERE manager_id IS NOT NULL`. Первый
вариант лучше: он не зависит от того, помнит ли автор про `NULL`.

</Reveal>
