title: Двумерная сетка падает на первой клетке
description: Сетку 3×4 создают через make и заполняют точками. Первая же запись в клетку — index out of range. Почините.
kind: fix

`newGrid` создаёт поле `h × w` и заполняет его точками. Программа падает:

```
panic: runtime error: index out of range [0] with length 0
```

Почините. Ожидаемый вывод:

```
....
..#.
....
```

<Reveal>

**`make([][]rune, h)` создаёт только внешний слайс** — `h` строк, каждая из
которых `nil`-слайс нулевой длины. Для строк памяти никто не выделял.
`grid[0][0]` — индекс 0 в слайсе длины 0.

**Каждую строку надо создать отдельно:**

```go
for y := range grid {
	grid[y] = make([]rune, w)
	...
}
```

**Вариант с одним выделением** — один массив на всю сетку, строки — его
окна:

```go
cells := make([]rune, h*w)
for y := range grid {
	grid[y] = cells[y*w : (y+1)*w : (y+1)*w]
}
```

Одно выделение вместо `h`, и данные лежат в памяти подряд. Третий индекс
не даёт `append` к одной строке залезть в следующую.

</Reveal>
