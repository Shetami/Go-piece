Ожидается порядок по возрастанию возраста: Аня, Боря, Вика. Программа
печатает:

```
[{Вика 35} {Аня 20} {Боря 28}]
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 17: `return people[i].age < people[i].age`.

**Опечатка: оба раза `i`.** Функция сравнивает элемент сам с собой и всегда
возвращает `false` — «ни один элемент не меньше другого». Для сортировки
это значит, что все элементы равны, а равные можно оставить в любом порядке.
Она и оставила.

Компилятор не поможет: выражение корректно. `go vet` тоже промолчит.

**Как не попадаться.** `sort.Slice` сравнивает по индексам, и индексы легко
перепутать. `slices.SortFunc` (Go 1.21) получает сами элементы:

```go
slices.SortFunc(people, func(a, b person) int {
	return cmp.Compare(a.age, b.age)
})
```

Здесь опечатка `a.age, a.age` тоже возможна, но в глаза бросается сильнее.
А `cmp.Compare` возвращает `-1/0/1` и правильно обрабатывает `NaN` — это
удобнее, чем писать `<` руками.

**Что ещё спросят.** `sort.Slice` нестабильна: равные элементы могут
поменяться местами. Если важен исходный порядок равных — `sort.SliceStable`
или `slices.SortStableFunc`.

</Reveal>
