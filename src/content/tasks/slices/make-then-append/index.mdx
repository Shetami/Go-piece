`squares` должна вернуть `[1 4 9]`. Вместо этого:

```
[0 0 0 1 4 9]
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 7: `out := make([]int, len(nums))`.

**`make` с одним числом задаёт длину, а не вместимость.** Слайс создаётся
уже с тремя элементами — тремя нулями. `append` дописывает *после* них: он
всегда пишет в позицию `len(out)`.

Автор хотел заранее выделить память, и это правильная мысль. Нужна форма с
тремя аргументами:

```go
out := make([]int, 0, len(nums)) // длина 0, вместимость 3
```

Либо оставить длину и писать по индексу, без `append`:

```go
out := make([]int, len(nums))
for i, n := range nums {
	out[i] = n * n
}
```

Оба варианта правильные. Ошибка — смешать их: `make` с длиной и `append`.

**Как ловить.** Линтер `makezero` из `golangci-lint` ищет ровно этот шаблон:
`append` к слайсу, созданному `make` с ненулевой длиной.

</Reveal>
