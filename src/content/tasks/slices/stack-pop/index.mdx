Стек на слайсе: `Push` дописывает в конец, `Pop` снимает с конца. Программа
падает:

```
panic: runtime error: index out of range [3] with length 3
```

Почините. Ожидаемый вывод:

```
3
2
1
```

<Reveal>

**Индексы слайса — от `0` до `len-1`.** `s.items[len(s.items)]` — первый
индекс *за* концом. Сообщение паники об этом и говорит: индекс 3 при длине
3.

```go
x := s.items[len(s.items)-1]
```

**Мелочь, которая важна для стека указателей.** `s.items[:len-1]` не
удаляет элемент из массива — он там остаётся, просто за длиной. Для `int`
неважно. Для `*BigObject` снятый объект будет жить, пока жив массив
стека. Тогда перед укорачиванием зануляют ячейку:

```go
s.items[len(s.items)-1] = nil
```

</Reveal>
