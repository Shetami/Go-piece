Напишите тело `FreeSlots`. Так работает «найти время для встречи» в любом
календаре: занятость участников сваливается в один список, и нужно
показать окна, куда встреча помещается.

Что проверяют скрытые тесты:

- встречи приходят в любом порядке, а `busy` после вызова остаётся прежним;
- встреча целиком внутри другой не «освобождает» хвост внешней;
- касающиеся встречи (`[600,660)` и `[660,720)`) не дают пустой щели между
  собой;
- окно ровно в `minLen` подходит, на минуту короче — нет;
- встречи до начала и после конца дня обрезаются или не учитываются вовсе;
- «перевёрнутые» и нулевые интервалы ничего не режут.

<Reveal>

```go
func FreeSlots(busy []Interval, day Interval, minLen int) []Interval {
	minLen = max(minLen, 1)
	b := slices.Clone(busy)
	slices.SortFunc(b, func(x, y Interval) int { return cmp.Compare(x.Start, y.Start) })

	var out []Interval
	cursor := day.Start
	for _, iv := range b {
		if iv.Start >= iv.End {
			continue
		}
		if iv.Start >= day.End {
			break
		}
		if iv.Start-cursor >= minLen {
			out = append(out, Interval{cursor, iv.Start})
		}
		cursor = max(cursor, iv.End)
	}
	if day.End-cursor >= minLen {
		out = append(out, Interval{cursor, day.End})
	}
	return out
}
```

**Сортировка копии.** Без сортировки по началу задачу не решить за
O(n log n), но `slices.SortFunc(busy, …)` переставит чужой слайс —
вызывающий, скорее всего, держит в нём расписание в своём порядке.
`slices.Clone` стоит одну аллокацию.

**Курсор — граница уже занятого.** После сортировки идём слева направо и
держим `cursor`: левее него всё занято или уже разобрано. Если следующая
встреча начинается правее курсора — между ними окно. **`max(cursor,
iv.End)`, а не `iv.End`** — иначе короткая встреча внутри длинной
отодвинет курсор назад, и середина длинной встречи окажется «свободной».

**Границы дня без отдельной обрезки.** Курсор стартует с `day.Start`,
поэтому встречи, закончившиеся до начала дня, ничего не дают (`iv.Start -
cursor` отрицательно). Встречи, начавшиеся после конца дня, обрывают цикл.
Хвост дня проверяется после цикла.

**Пустые интервалы пропускаем явно.** `{700, 650}` без проверки успел бы
отрезать окно `[cursor, 700)`, хотя встречи нет.

**Что спросят дальше.** Найти первое окно, общее для нескольких
участников (слить их списки — это та же задача); учесть часовые пояса;
отвечать на много запросов к одному календарю — тогда один раз слить
интервалы и искать двоичным поиском.
