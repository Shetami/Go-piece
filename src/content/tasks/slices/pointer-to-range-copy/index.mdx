`cheap` отбирает товары дешевле лимита и отдаёт указатели на них. Вызывающий
поднимает по указателям цену на 10. Ожидается, что чай и сахар в каталоге
подорожают:

```
[{чай 100} {кофе 350} {сахар 70}]
```

А каталог печатается без изменений. Отметьте строку, в которой заложена
поломка.

<Reveal>

Сломано в строке 16: `out = append(out, &p)`.

**`p` — копия элемента, а не сам элемент.** `range` на каждой итерации
копирует очередной `Product` в переменную `p`. Адрес `&p` — адрес этой
копии. Указатели ведут на копии, и цены меняются в них.

С Go 1.22 у каждой итерации своя `p`, поэтому указатели хотя бы разные — до
1.22 все они указывали бы на одну переменную с последним подходящим товаром.
Но и сейчас это не элементы каталога.

**Как правильно** — брать адрес элемента слайса по индексу:

```go
for i := range catalog {
	if catalog[i].Price < limit {
		out = append(out, &catalog[i])
	}
}
```

**Осторожно с таким указателем.** `&catalog[i]` указывает в массив под
слайсом. Если потом кто-то сделает `append` в `catalog` и массив
перевыделится, указатели останутся смотреть в старый массив.

</Reveal>
