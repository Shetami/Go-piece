Напишите тело `ReadAll`. `bufio.Scanner.Bytes`, `bufio.Reader.ReadSlice`,
буферы драйверов баз данных — всё это отдаёт срез своего внутреннего
буфера, валидный только до следующего вызова. Классический баг — сложить
такие срезы в слайс и получить N копий последней строки.

Что проверяют скрытые тесты:

- поля правильные даже после того, как сканер перезаписал свой буфер;
- пустые строки пропускаются, пустые поля (`"2,,"`, висящий разделитель)
  сохраняются;
- разные записи не делят память;
- поля одной записи — подслайсы одной копии строки, и `append` к полю не
  затирает соседнее;
- аллокаций — порядка двух на запись, а не по одной на каждое поле.

<Reveal>

```go
func ReadAll(next func() (line []byte, ok bool), sep byte) []Record {
	var out []Record
	for {
		line, ok := next()
		if !ok {
			return out
		}
		if len(line) == 0 {
			continue
		}
		own := bytes.Clone(line)
		rec := make(Record, 0, bytes.Count(own, []byte{sep})+1)
		for {
			i := bytes.IndexByte(own, sep)
			if i < 0 {
				rec = append(rec, own[:len(own):len(own)])
				break
			}
			rec = append(rec, own[:i:i])
			own = own[i+1:]
		}
		out = append(out, rec)
	}
}
```

**Буфер сканера — чужой.** `line` смотрит в массив, который сканер
перепишет при следующем вызове. `bytes.Split(line, …)` без копии даст
поля, указывающие в этот массив, и после чтения всего файла все записи
будут показывать мусор или последнюю строку. Копировать нужно **до**
следующего вызова `next`.

**Одна копия на запись, а не на поле.** `bytes.Clone(line)` — одна
аллокация, а поля — подслайсы этой копии. Копировать каждое поле (или
делать `string(field)`) честно, но это N аллокаций на строку, и на
миллионе строк это заметно в профиле. Слайс полей тоже выделяем один
раз: `bytes.Count` заранее говорит, сколько их будет.

**Третий индекс у каждого поля.** Поля лежат вплотную в одном массиве:
`own[:i]` имеет вместимость до конца строки, и `append` к нему перезапишет
разделитель и начало следующего поля. `own[:i:i]` это исключает. Кстати,
`bytes.Split` делает ровно так же, поэтому `bytes.Split(bytes.Clone(line),
[]byte{sep})` — тоже правильный ответ.

**Цена подслайсов** — одна маленькая строка из записи держит в памяти всю
копию строки. Для долгоживущих данных это повод скопировать нужные поля
отдельно.

**Что спросят дальше.** Поддержка кавычек и экранирования (тогда уже
`encoding/csv` и его `ReuseRecord`); чтение без хранения всего файла —
обработка записи сразу в колбэке; почему `string(b)` в ключе мапы
`m[string(b)]` не аллоцирует.
