Напишите тело `Spiral`. Задача проверяет не алгоритм как таковой, а
аккуратность с границами: четыре указателя, четыре прохода и условие
остановки.

Что проверяют скрытые тесты:

- квадратные и прямоугольные матрицы — и «лежачие» `3×4`, `3×5`, и
  «стоячие» `4×3`: ни один элемент не выдан дважды и ни один не потерян;
- одна строка, один столбец, `1×1`, `2×2`;
- пустая матрица и матрица из пустых строк — пустой результат;
- строки разной длины — паника;
- матрица не меняется, а на результат уходит одна аллокация.

<Reveal>

```go
func Spiral[T any](m [][]T) []T {
	if len(m) == 0 {
		return nil
	}
	cols := len(m[0])
	for _, row := range m {
		if len(row) != cols {
			panic("Spiral: строки разной длины")
		}
	}
	out := make([]T, 0, len(m)*cols)
	top, bottom, left, right := 0, len(m)-1, 0, cols-1
	for top <= bottom && left <= right {
		for j := left; j <= right; j++ {
			out = append(out, m[top][j])
		}
		top++
		for i := top; i <= bottom; i++ {
			out = append(out, m[i][right])
		}
		right--
		if top <= bottom {
			for j := right; j >= left; j-- {
				out = append(out, m[bottom][j])
			}
			bottom--
		}
		if left <= right {
			for i := bottom; i >= top; i-- {
				out = append(out, m[i][left])
			}
			left++
		}
	}
	return out
}
```

**Четыре границы, которые сжимаются.** `top`, `bottom`, `left`, `right` —
ещё не пройденный прямоугольник. Каждый проход забирает его край и
сдвигает соответствующую границу внутрь. Цикл идёт, пока прямоугольник не
пуст.

**Главная ловушка — последний слой из одной строки или одного столбца.** В
`3×4` после внешнего кольца остаётся строка `[6 7]`. Проход вправо её
забирает, и если без проверки `top <= bottom` пойти налево по «нижней»
строке — это та же строка, и `7 6` попадут в ответ второй раз. Симметрично
с одним столбцом в `4×3` и проверкой `left <= right`. Квадратные матрицы
эту ошибку не показывают — отсюда тесты на прямоугольники.

**Размер результата известен заранее** — `rows*cols`, поэтому
`make(…, 0, n)` и ни одного перевыделения в `append`. Проверка длины строк
заодно защищает от выхода за границы на рваной матрице.

**Что спросят дальше.** Заполнить матрицу `n×n` числами по спирали
(та же схема, запись вместо чтения); обойти «змейкой» или по диагоналям;
сделать итератор `iter.Seq[T]` вместо слайса, чтобы не выделять память
вовсе.
