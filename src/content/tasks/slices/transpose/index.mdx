Напишите тело `Transpose`.

Что проверяют скрытые тесты:

- `[[1 2 3] [4 5 6]]` → `[[1 4] [2 5] [3 6]]`, исходная матрица не
  меняется;
- матрица из одной строки → столбец;
- `nil` → пустой результат;
- двойное транспонирование возвращает исходное;
- `append` к одной строке результата не портит соседнюю.

<Reveal>

```go
func Transpose(m [][]int) [][]int {
	if len(m) == 0 {
		return nil
	}
	rows, cols := len(m), len(m[0])
	cells := make([]int, rows*cols)
	out := make([][]int, cols)
	for c := range out {
		out[c] = cells[c*rows : (c+1)*rows : (c+1)*rows]
		for r := range rows {
			out[c][r] = m[r][c]
		}
	}
	return out
}
```

**Размеры меняются местами:** в результате `cols` строк по `rows`
элементов. Частая ошибка — выделить `rows × cols` и получить
`index out of range` на неквадратной матрице. Квадратные тесты её не ловят.

**Результат — новые слайсы.** Транспонировать «на месте» можно только
квадратную матрицу; тут контракт — не трогать вход.

**Одно выделение на все клетки** с окнами по третьему индексу — приём
из `slices/grid-rows`. Можно и проще, `make([]int, rows)` на каждую
строку: так тоже правильно, просто выделений больше.

</Reveal>
