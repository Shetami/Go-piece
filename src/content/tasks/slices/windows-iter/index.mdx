Напишите тело `Windows`. Окна с шагом нужны для скользящих метрик,
n-грамм, поиска шаблонов во временных рядах. Итератор (Go 1.23) не
собирает все окна в память: их может быть почти столько же, сколько
элементов.

Что проверяют скрытые тесты:

- шаг меньше, равен и больше размера окна (с пропусками); последнее
  полное окно у самого конца не теряется; неполных окон нет;
- итератор можно обойти дважды с одинаковым результатом;
- `break` в `range` останавливает обход — рантайм паникует, если после
  этого итератор снова зовёт `yield`;
- окна — подслайсы, и `append` к окну не меняет исходный слайс;
- обход тысячи окон не выделяет память на каждое окно;
- неверные `size`/`step` — паника при вызове `Windows`, ещё до обхода.

<Reveal>

```go
func Windows[T any](s []T, size, step int) iter.Seq[[]T] {
	if size <= 0 || step <= 0 {
		panic("Windows: size и step должны быть больше нуля")
	}
	return func(yield func([]T) bool) {
		for i := 0; i+size <= len(s); i += step {
			if !yield(s[i : i+size : i+size]) {
				return
			}
		}
	}
}
```

**`yield` вернул `false` — выходим.** Цикл `for w := range seq` с
`break` превращается в то, что `yield` возвращает `false`. Если итератор
это проигнорирует и позовёт `yield` ещё раз, рантайм упадёт с паникой
«range function continued iteration after function for loop body returned
false». Это самая частая ошибка в самописных итераторах.

**Проверка аргументов — снаружи замыкания.** Всё, что внутри `func(yield
…)`, выполнится только при обходе. Паника «когда-нибудь потом, в другом
месте» — плохая диагностика, поэтому валидируем при создании.

**Условие `i+size <= len(s)`** даёт ровно полные окна и не теряет
последнее: для длины 7, окна 3 и шага 2 последнее окно начинается с
индекса 4 и заканчивается ровно на конце.

**Окно — подслайс с обрезанной вместимостью.** Копия на каждое окно — это
аллокация на каждый шаг, а окон почти `len(s)`. Подслайс бесплатен, но
`append` к `s[i:i+size]` писал бы в `s[i+size]`. Третий индекс это
исключает. Помните: окна при шаге меньше размера **перекрываются** —
запись по индексу в одно окно видна в соседних; это и есть «без
копирования».
