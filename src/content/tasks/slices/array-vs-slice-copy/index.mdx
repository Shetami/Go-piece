Есть массив `arr`, его копия `copyArr` и слайс `view` поверх `arr`. Через
слайс меняют нулевой элемент, через копию — первый.

Напишите весь вывод программы.

<Reveal>

**Массив в Go — значение, а не ссылка.** `copyArr := arr` копирует все три
элемента, и дальше это два независимых массива. Запись в `copyArr[1]`
на `arr` не влияет.

**Слайс — окно в чужой массив.** `arr[:]` своих данных не заводит: это
указатель на `arr`, длина 3 и вместимость 3. Поэтому `view[0] = 100` пишет
прямо в `arr`, и через `view` мы видим то же самое.

Итого:

```
[100 2 3]
[1 200 3]
[100 2 3]
```

**Что из этого следует.** Массив, переданный в функцию, копируется целиком,
и для `[1 << 20]byte` это мегабайт на каждый вызов. Поэтому массивы в Go
почти не передают — передают слайсы, а массив остаётся тем, что под ними
лежит. Исключения — маленькие массивы фиксированного размера вроде
`[16]byte` для UUID или `[32]byte` для хеша: их копирование дёшево, а
сравнивать их можно через `==`, чего слайсы не умеют.

</Reveal>
