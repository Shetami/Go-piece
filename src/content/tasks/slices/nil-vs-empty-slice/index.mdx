`a` объявлен через `var` и ничего не получил, `b` — пустой литерал. Их
сравнивают с `nil`, печатают, кодируют в JSON и дописывают в `a` элемент.

Напишите весь вывод программы.

<Reveal>

**У `nil`-слайса нулевой указатель, у пустого — ненулевой.** Длина и
вместимость у обоих ноль, но `[]int{}` указывает на реальный (пусть и
нулевого размера) участок памяти. Поэтому `a == nil` — `true`, а
`b == nil` — `false`.

**Почти везде разница не видна.** `len`, `range`, `append` и `fmt.Println`
обращаются с ними одинаково: оба печатаются как `[]`, `append` к `nil`-слайсу
заводит массив и работает как обычно.

**Кроме JSON.** `encoding/json` кодирует `nil`-слайс как `null`, а пустой —
как `[]`. Для клиента на JavaScript это разные вещи: `null.length` падает.

Итого:

```
true false
0 0
[] []
null []
[1]
```

**Как этим пользоваться.** Проверяйте пустоту через `len(s) == 0`, а не через
`s == nil` — так функция одинаково ведёт себя на обоих. А если слайс уходит в
API, решите явно, что там должно быть: если `[]`, инициализируйте
`make([]T, 0)`.

</Reveal>
