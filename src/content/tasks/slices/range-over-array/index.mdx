Во всех трёх циклах на первой итерации меняют элементы 1 и 2 — те, до
которых цикл ещё не дошёл. Идут по массиву, по указателю на массив и по
слайсу.

Напишите весь вывод программы.

<Reveal>

**Выражение в `range` вычисляется один раз, до начала цикла.** Для массива
это значит — копируется весь массив. Цикл дальше идёт по копии, и запись в
`arr` внутри тела её не задевает.

**Указатель на массив копируется как указатель.** Копия указателя смотрит на
тот же массив, поэтому изменения видны.

**Слайс копируется как заголовок** — указатель, длина, вместимость. Массив
под ним общий, изменения тоже видны.

Итого:

```
массив: [1 2 3]
указатель: [1 20 30]
слайс: [1 20 30]
```

**Цена копии.** `for i, v := range bigArray` для массива в мегабайт копирует
мегабайт. Если нужен только индекс — `for i := range bigArray` — копии не
будет: компилятор знает, что значения не читаются. Если значения нужны —
`range &bigArray` или `range bigArray[:]`.

</Reveal>
