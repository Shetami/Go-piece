Напишите методы `Set`. Такая структура хранит занятые диапазоны
IP-адресов и портов, скачанные куски файла, подтверждённые оффсеты в
консьюмере, свободные блоки в аллокаторе.

Что проверяют скрытые тесты:

- интервалы в любом порядке; касающиеся (`[1,3)` и `[3,5)`) склеиваются;
- новый интервал перекрывает несколько старых — «мост» сливает их в один;
- интервал внутри существующего ничего не меняет; пустые игнорируются;
- `Contains` на границах: `Start` входит, `End` — нет; нулевой `Set`
  работает;
- `Intervals` отдаёт копию;
- сверка со множеством-битмапом на сотнях случайных добавлений и
  инвариант «соседи не касаются»;
- 20 000 добавлений и 300 000 проверок — быстро.

```go
func (s *Set) Add(start, end int) {
	if start >= end {
		return
	}
	i := sort.Search(len(s.iv), func(k int) bool { return s.iv[k].End >= start })
	j := sort.Search(len(s.iv), func(k int) bool { return s.iv[k].Start > end })
	if i < j {
		start = min(start, s.iv[i].Start)
		end = max(end, s.iv[j-1].End)
	}
	s.iv = slices.Replace(s.iv, i, j, Interval{start, end})
}

func (s *Set) Contains(x int) bool {
	i := sort.Search(len(s.iv), func(k int) bool { return s.iv[k].End > x })
	return i < len(s.iv) && s.iv[i].Start <= x
}

func (s *Set) Intervals() []Interval {
	return slices.Clone(s.iv)
}
```

**Два двоичных поиска задают диапазон слияния.** Так как интервалы не
пересекаются и отсортированы, и `Start`, и `End` растут монотонно.
`i` — первый, кто кончается не левее `start`, `j` — первый, кто начинается
правее `end`. Все интервалы `s.iv[i:j]` задевают новый и сливаются с ним;
если `i == j`, сливать не с чем — это чистая вставка.

**`>=` и `>` — это и есть «касание».** `End >= start` цепляет интервал,
который кончается ровно там, где начинается новый; `Start > end` —
оставляет в слиянии тот, что начинается ровно на `end`. Поменяйте любой
знак — и `[1,3)`+`[3,5)` останутся двумя интервалами, а инвариант
«соседи не касаются» сломается.

**`slices.Replace(s, i, j, v)`** за один сдвиг заменяет отрезок на один
элемент: при `j-i > 1` хвост сдвигается влево, при `i == j` — вправо,
и если места не хватит, слайс вырастет. С Go 1.22 он обнуляет
освободившийся хвост. Вручную это `append(s[:i], append([]Interval{v},
s[j:]...)...)` — с лишней аллокацией и шансом ошибиться.

**Сложность.** Поиск — O(log n), сдвиг — O(n) в худшем случае. Если
вставок очень много, берут сбалансированное дерево или B-дерево, но для
тысяч интервалов слайс быстрее за счёт кэша. `Contains` ищет первый
интервал с `End > x` — если он начинается не правее `x`, число внутри.

**Что спросят дальше.** `Remove(start, end)`, который может разрезать
интервал на два; пересечение двух множеств двумя указателями; хранение
оффсетов Kafka с «дырками» и коммит только непрерывного префикса.
