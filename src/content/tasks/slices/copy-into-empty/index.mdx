`clone` должна вернуть независимую копию `[1 2 3]`. Возвращает:

```
[] 0
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 7: `dst := make([]int, 0, len(src))`.

**`copy` копирует `min(len(dst), len(src))` элементов.** Не вместимость, а
именно длину. У `dst` длина 0 — копируется ноль элементов. `copy` так и
сообщает: она возвращает число скопированных элементов, и здесь это `0`.
Результат просто никто не проверил.

Вместимость для `copy` значения не имеет: писать за пределы длины она не
будет, даже если место есть.

**Как правильно.**

```go
dst := make([]int, len(src))
copy(dst, src)
```

Или, начиная с Go 1.21, одной строкой: `slices.Clone(src)`. Ещё один
вариант — `append([]int(nil), src...)`, но у него есть особенность:
для пустого `src` он вернёт `nil`, а не пустой слайс.

</Reveal>
