---
title: Места хватает, а писать нельзя
description: Под пять элементов выделена память, но первая же запись по индексу падает с index out of range. Почините.
kind: fix
topic: slices
level: easy

---

Программа падает:

```
panic: runtime error: index out of range [0] with length 0
```

Почините. Ожидаемый вывод:

```
[1 4 9 16 25]
```

<Reveal>

**Индекс проверяется по длине, а не по вместимости.** `make([]int, 0, n)` —
слайс длины 0 с памятью под `n` элементов. Память есть, но элементов нет, и
`out[0]` — выход за границу. Вместимость — это обещание будущему `append`,
что перевыделять не придётся, а не разрешение писать по индексам.

**Две правильные пары:**

```go
out := make([]int, 0, n)   // и append
out = append(out, v)

out := make([]int, n)      // и запись по индексу
out[i] = v
```

Ошибка всегда в том, что их смешали. Обратная смесь — `make([]int, n)` и
`append` — не падает, а тихо даёт нули в начале.

</Reveal>
