`positive` отбирает положительные числа. Результат правильный, но исходный
слайс после вызова испорчен:

```
положительные: [5 3 8]
все показания: [5 3 8 -7 8]
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 8: `out := xs[:0]`.

**`xs[:0]` — пустой слайс над тем же массивом.** Длина ноль, но
вместимость и массив — от `xs`. Каждый `append` пишет в этот массив, по
порядку с начала: `5` на место `5`, `3` на место `-1`, `8` на место `3`.
Хвост `-7 8` остаётся как был.

**Это известный приём — фильтр на месте.** Он экономит выделение памяти и
безопасен, потому что запись никогда не обгоняет чтение. Но он **по
определению** меняет вход. Годится, когда вызывающий отдаёт слайс и больше им
не пользуется: `xs = filter(xs)`. Здесь контракт другой.

**Как правильно** — свой массив:

```go
var out []int                  // или make([]int, 0, len(xs))
```

Или `slices.DeleteFunc(slices.Clone(xs), func(x int) bool { return x <= 0 })`.

</Reveal>
