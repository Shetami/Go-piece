Напишите `FormatRanges` и `ParseRanges`. Такой формат встречается
повсюду: номера страниц для печати, список CPU в `taskset`, диапазоны
портов, номера упавших шардов в отчёте.

Что проверяют скрытые тесты:

- вход в любом порядке и с повторами; сам вход не переставляется;
- одиночные числа, пары (`4-5`, а не `4,5`), длинные серии;
- отрицательные числа: `[-5 -4 10]` → `"-5--4,10"`, и это же разбирается
  обратно;
- `ParseRanges` сохраняет порядок записи и ругается на `"1,,2"`, `"3-1"`,
  `"x"`, `"1-"`, `"1-2-3"`, висящую запятую;
- `Parse(Format(x))` — отсортированные уникальные `x`.

```go
func FormatRanges(ids []int) string {
	s := slices.Clone(ids)
	slices.Sort(s)
	s = slices.Compact(s)
	var b strings.Builder
	for i := 0; i < len(s); {
		j := i
		for j+1 < len(s) && s[j+1] == s[j]+1 {
			j++
		}
		if b.Len() > 0 {
			b.WriteByte(',')
		}
		b.WriteString(strconv.Itoa(s[i]))
		if j > i {
			b.WriteByte('-')
			b.WriteString(strconv.Itoa(s[j]))
		}
		i = j + 1
	}
	return b.String()
}

func ParseRanges(s string) ([]int, error) {
	if s == "" {
		return nil, nil
	}
	var out []int
	for _, part := range strings.Split(s, ",") {
		if part == "" {
			return nil, fmt.Errorf("пустой элемент в %q", s)
		}
		lo, hi := part, part
		if k := strings.IndexByte(part[1:], '-'); k >= 0 {
			lo, hi = part[:k+1], part[k+2:]
		}
		a, err := strconv.Atoi(lo)
		if err != nil {
			return nil, fmt.Errorf("элемент %q: %w", part, err)
		}
		b, err := strconv.Atoi(hi)
		if err != nil {
			return nil, fmt.Errorf("элемент %q: %w", part, err)
		}
		if a > b {
			return nil, fmt.Errorf("диапазон %q: начало больше конца", part)
		}
		for v := a; v <= b; v++ {
			out = append(out, v)
		}
	}
	return out, nil
}
```

**Clone → Sort → Compact.** Три шага превращают любой вход в
отсортированный список без повторов. `slices.Sort(ids)` без копии
переставил бы слайс вызывающего — такие побочные эффекты потом ищут
днями. `Compact` удаляет только соседние дубли, поэтому он идёт строго
после сортировки.

**Серия — два указателя.** `i` — начало серии, `j` двигается, пока
следующее число ровно на единицу больше. Серия из одного числа пишется
без дефиса. Повторы уже убраны, иначе `[1 1 2]` разорвал бы серию.

**Минус — то знак, то разделитель.** `strings.Split(part, "-")` на
`"-3--1"` даст `["" "3" "" "1"]`. Проще искать разделитель начиная со
второго символа: первый минус всегда знак. Всё остальное (`"1-"`,
`"1-2-3"`, `"1--"`) отсеивает `strconv.Atoi` — не надо писать свой
валидатор.

**Ошибки с контекстом через `%w`.** Вызывающий видит, какой элемент
сломан, и при этом может проверить `errors.Is(err, strconv.ErrSyntax)`.

**Что спросят дальше.** Защита от `"1-1000000000"` — лимит на размер
результата или выдача итератором; разбор без аллокации под `Split`
(цикл по `strings.Cut`); объединение двух таких строк без
разворачивания в числа — это уже слияние интервалов.
