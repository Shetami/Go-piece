`identity(3)` должна вернуть единицы на диагонали и нули вокруг. Программа
печатает:

```
[1 1 1]
[1 1 1]
[1 1 1]
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 10: `slices.Repeat([][]int{make([]int, n)}, n)`.

**`make` вызывается один раз.** Выражение `make([]int, n)` вычисляется до
вызова `Repeat` и даёт одну строку. `Repeat` копирует *элементы* слайса n раз,
а элемент — это заголовок слайса. Три заголовка, один массив:

```
grid[0] ─┐
grid[1] ─┼─→ [0 0 0]
grid[2] ─┘
```

Запись `grid[0][0] = 1` видна через все три строки, `grid[1][1]` — тоже, и
так далее. Три записи в разные «строки» — три записи в один массив.

**Как правильно** — отдельный `make` на каждую строку:

```go
grid := make([][]int, n)
for i := range grid {
	grid[i] = make([]int, n)
}
```

Если важна скорость, можно выделить один массив `n*n` и нарезать его на
строки, `grid[i] = flat[i*n : (i+1)*n]` — строки будут соседями в памяти, но
не пересекутся.

Та же ловушка есть в Python — `[[0] * n] * n` — и на собеседованиях её
любят именно за то, что на глаз код выглядит правильно.

</Reveal>
