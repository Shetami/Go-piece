`remove` убирает из очереди элемент по индексу. Удаляет, но сейчас
программа печатает:

```
[a e c d]
[d e c]
```

Почините `remove`, чтобы порядок остальных элементов сохранялся. Ожидаемый
вывод:

```
[a c d e]
[c d e]
```

<Reveal>

**Это приём «поменять с последним и отрезать».** Он удаляет за `O(1)`, но
переставляет последний элемент в середину. Хорош для множества, где
порядок неважен, и совсем не годится для очереди.

**Чтобы сохранить порядок, хвост надо сдвинуть на одну позицию влево:**

```go
return slices.Delete(q, i, i+1)
```

До Go 1.21 то же самое писали через `append`:

```go
return append(q[:i], q[i+1:]...)
```

Это `O(n)`: сдвигаются все элементы после `i`. Зато порядок цел.

**Помните, что работа идёт на месте.** И `slices.Delete`, и `append` пишут
в массив исходного слайса — переменной, переданной в `remove`, после
вызова пользоваться нельзя, только результатом.

</Reveal>
