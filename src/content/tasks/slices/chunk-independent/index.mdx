title: Порезать слайс на куски
description: Разбить слайс на части по n элементов без копирования данных — и так, чтобы append к одной части не затирал соседнюю.
kind: implement
topic: slices

---

Напишите тело `Chunk`.

Что проверяют скрытые тесты:

- `[1 2 3 4 5]` по 2 → `[[1 2] [3 4] [5]]`;
- пустой вход → ноль кусков;
- `append` к первому куску не меняет ни второй кусок, ни исходный слайс;
- `n <= 0` — паника.

<Reveal>

```go
func Chunk[T any](s []T, n int) [][]T {
	if n <= 0 {
		panic("Chunk: n должно быть больше нуля")
	}
	out := make([][]T, 0, (len(s)+n-1)/n)
	for len(s) > 0 {
		end := min(n, len(s))
		out = append(out, s[:end:end])
		s = s[end:]
	}
	return out
}
```

**Куски — окна в исходный массив**, данные не копируются. Но у окна
`s[:end]` вместимость до конца массива, и `append` к нему записал бы прямо
в начало следующего куска. **Третий индекс** `s[:end:end]` обрезает
вместимость до длины — любой `append` уйдёт в новый массив.

**`(len(s)+n-1)/n`** — деление с округлением вверх: сколько кусков
получится. Предвыделение избавляет `out` от роста.

**В стандартной библиотеке** с Go 1.23 есть `slices.Chunk` — он
возвращает итератор и тоже режет с третьим индексом.

</Reveal>
