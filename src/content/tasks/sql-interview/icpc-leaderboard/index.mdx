Жюри студенческой олимпиады публикует итоговую таблицу. Правила — как на
ICPC.

- в зачёт идут посылки, отправленные во время тура: с `contest.starts_at`
  включительно до `contest.ends_at` **не** включительно;
- задача **решена**, если есть хотя бы одна посылка с вердиктом `OK`;
  момент решения — **первая** такая посылка, повторные `OK` ничего не
  меняют;
- **штраф** за решённую задачу — полные минуты от начала тура до
  момента решения (секунды отбрасываются) плюс **20 минут** за каждую
  неудачную посылку по этой задаче **до** момента решения. Посылки после
  решения не штрафуются. Ошибка компиляции (`CE`) неудачной попыткой не
  считается;
- нерешённые задачи штрафа не дают, сколько бы попыток по ним ни было;
- в таблицу входят только официальные команды (`is_official`), в том числе
  без единой посылки.

Команды ранжируются по числу решённых задач (больше — выше), при равенстве —
по штрафу (меньше — выше). Полностью равные команды делят место, следующее
место пропускается: 1, 1, 3.

- колонки: `place`, `team`, `solved`, `penalty`;
- порядок: `place`, затем `team`.

<Reveal>

```sql
WITH valid AS (
  SELECT s.*, c.starts_at
  FROM submissions s
  CROSS JOIN contest c
  WHERE s.submitted_at >= c.starts_at
    AND s.submitted_at <  c.ends_at
),
first_ok AS (
  SELECT team_id, problem_id, min(submitted_at) AS ok_at, min(starts_at) AS starts_at
  FROM valid
  WHERE verdict = 'OK'
  GROUP BY team_id, problem_id
),
solved AS (
  SELECT f.team_id, f.problem_id,
         floor(extract(epoch FROM f.ok_at - f.starts_at) / 60)::int
           + 20 * (SELECT count(*) FROM valid v
                   WHERE v.team_id = f.team_id
                     AND v.problem_id = f.problem_id
                     AND v.submitted_at < f.ok_at
                     AND v.verdict NOT IN ('OK', 'CE')) AS penalty
  FROM first_ok f
),
totals AS (
  SELECT t.id, t.name,
         count(s.problem_id)        AS solved,
         coalesce(sum(s.penalty), 0) AS penalty
  FROM teams t
  LEFT JOIN solved s ON s.team_id = t.id
  WHERE t.is_official
  GROUP BY t.id, t.name
)
SELECT rank() OVER (ORDER BY solved DESC, penalty) AS place,
       name AS team, solved, penalty
FROM totals
ORDER BY place, team;
```

Ответ:

```
1 | Альфа   | 2 | 110
1 | Бета    | 2 | 110
3 | Гамма   | 1 |  20
4 | Дельта  | 0 |   0
4 | Эпсилон | 0 |   0
```

**Опорная точка — первая успешная посылка.** Все правила ICPC отсчитываются
от неё: время решения, «неудачные попытки до», игнорирование того, что
после. Поэтому сначала `first_ok` — одна строка на пару «команда × задача»
с моментом решения, а штраф считается уже относительно неё. Пары без `OK`
в `first_ok` не попадают вовсе — это и есть правило «нерешённые не
штрафуются»: три неудачи Дельты по задаче A ей ничего не стоят.

**Считать штрафные попытки — по окну «до решения».** У Альфы по A: WA в
10:05, OK в 10:30 — `30 + 20 = 50`. После решения B она отправила WA —
штрафа нет, и повторный OK по A в 11:20 тоже ничего не меняет. Заготовка
штрафует каждую не-OK посылку подряд и не считает время.

**CE и секунды.** Бета получила CE до решения A — без штрафа. Её решение в
10:50:59 — это 50 полных минут: `floor(секунды / 60)`. `round` дал бы 51, и
ничья с Альфой (110 : 110) разрушилась бы.

**Граница тура.** Гамма сдала C ровно в 15:00:00 — после конца (`<
ends_at`), задача не решена, а TL по ней в 12:00 не штрафуется.

**`rank`, а не `row_number`.** Альфа и Бета равны по обоим ключам и
делят первое место, следующее — третье. `dense_rank` дал бы 2 вместо 3 —
в спорте так не считают. `row_number` раздал бы места 1 и 2 произвольно.
Порядок строк при равном месте задаёт второй ключ `ORDER BY` — имя.

**Команды без посылок.** Эпсилон ничего не отправлял, но участвовал —
строится от `teams` через `LEFT JOIN`, `count(s.problem_id)` даёт 0.
Неофициальные «Гости» с тремя задачами из таблицы исключены.

**Что спросят дальше.** Как сделать «заморозку» таблицы за час до конца —
посылки после `ends_at − 1 hour` учитываются как попытки, но их вердикт
скрыт; и как считать таблицу на лету на тысячи команд — материализованный
агрегат по `(team, problem)` с обновлением на каждую посылку.
