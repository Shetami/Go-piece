Напишите тело `Compress`: каждая серия одинаковых символов заменяется
символом и длиной серии. Длина 1 не пишется.

Что проверяют скрытые тесты:

- `"aaabcc"` → `"a3bc2"`, `"abc"` → `"abc"`, повторная серия после
  другой: `"aabbaa"` → `"a2b2a2"`;
- кириллица: `"ёёёжж"` → `"ё3ж2"`;
- серия длиннее девяти: 12 букв `x` → `"x12"`;
- одна буква и пустая строка.

<Reveal>

```go
func Compress(s string) string {
	rs := []rune(s)
	var b strings.Builder
	for i := 0; i < len(rs); {
		j := i
		for j < len(rs) && rs[j] == rs[i] {
			j++
		}
		b.WriteRune(rs[i])
		if n := j - i; n > 1 {
			b.WriteString(strconv.Itoa(n))
		}
		i = j
	}
	return b.String()
}
```

**Внутренний цикл находит конец серии**, внешний прыгает сразу за неё.
Каждая руна просматривается один раз — O(n).

**Где ошибаются.**

- Байты вместо рун: `"ё"` — два байта, и счётчик ломает букву пополам.
- `string(rune('0' + n))` вместо `strconv.Itoa(n)`: для `n = 12` получится
  `<` — символ с кодом 60. Отсюда тест на длинную серию.
- Забытая последняя серия, когда серию записывают «при смене символа»:
  после цикла остаётся незаписанный хвост.

**`strings.Builder`** — правильный способ собирать строку по кусочкам.
`result += ...` в цикле каждый раз копирует всю строку и даёт O(n²).
