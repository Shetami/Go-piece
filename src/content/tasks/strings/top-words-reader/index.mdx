Классика собеседований — «топ-k слов в тексте» — с продовой поправкой:
текст приходит из `io.Reader` (файл на гигабайт, тело запроса) и целиком
в память не читается. Напишите `TopWords` по правилам из комментария.

Что проверяют скрытые тесты:

- регистр и пунктуация, ограничение `k`, `k = 0`, текст без слов;
- равные частоты — по алфавиту;
- `don't`, `кто-то` — одно слово; `-то`, одинокий дефис, кавычки вокруг
  слова, двойной дефис — разделители; `’` — тоже апостроф;
- `ё` и `е` — одно и то же;
- reader, который отдаёт по одному байту: кириллица разрезана пополам;
- ошибка reader не теряется и не выдаётся за конец текста.

<Reveal>

```go
type WordCount struct {
	Word  string
	Count int
}

func TopWords(r io.Reader, k int) ([]WordCount, error) {
	br := bufio.NewReader(r) // ReadRune склеивает руны, разрезанные между Read
	counts := map[string]int{}
	var word strings.Builder
	var pending rune // апостроф или дефис после слова: решим, когда увидим следующий символ
	flush := func() {
		if word.Len() > 0 {
			counts[word.String()]++
			word.Reset()
		}
		pending = 0
	}
	for {
		c, _, err := br.ReadRune()
		if err == io.EOF {
			break
		}
		if err != nil {
			return nil, fmt.Errorf("чтение текста: %w", err)
		}
		switch {
		case unicode.IsLetter(c) || unicode.IsDigit(c):
			c = unicode.ToLower(c)
			if c == 'ё' {
				c = 'е'
			}
			if pending != 0 {
				word.WriteRune(pending) // знак оказался между буквами — часть слова
				pending = 0
			}
			word.WriteRune(c)
		case (c == '\'' || c == '’' || c == '-') && word.Len() > 0 && pending == 0:
			pending = c
		default:
			flush()
		}
	}
	flush()
	if k <= 0 || len(counts) == 0 {
		return nil, nil
	}
	out := make([]WordCount, 0, len(counts))
	for w, n := range counts {
		out = append(out, WordCount{w, n})
	}
	slices.SortFunc(out, func(a, b WordCount) int {
		return cmp.Or(cmp.Compare(b.Count, a.Count), strings.Compare(a.Word, b.Word))
	})
	return out[:min(k, len(out))], nil
}
```

**Поток, а не `io.ReadAll` + `strings.FieldsFunc`.** На маленьком тексте
разницы нет, на гигабайтном логе — `ReadAll` съест гигабайт памяти ещё до
подсчёта. `bufio.Reader.ReadRune` читает с буфером и сам склеивает руну,
разрезанную между двумя `Read`. Самописное «прочитать кусок и
`string(buf[:n])`» превращает половинки «ё» в `�` — такие слова
тихо портятся.

**Апостроф и дефис — отложенное решение.** Встретив `-` после буквы, ещё
нельзя сказать, часть ли он слова: всё решает следующий символ. Поэтому
знак кладём в `pending` и дописываем в слово, только если за ним снова
буква. Это одна переменная состояния вместо заглядывания вперёд — и
работает в потоке, где «вперёд» ещё не прочитано.

**Нормализация до подсчёта.** Нижний регистр и `ё → е` применяем к руне
до записи в слово: иначе «Ёж» и «еж» окажутся разными ключами мапы.
Какие нормализации нужны, зависит от задачи — важно делать их в одном
месте.

**Порядок — сортировка с тай-брейкером.** Обход мапы случаен, и без
второго ключа сортировки топ при равных частотах будет меняться между
запусками. Сортировка всех слов — `O(n log n)`; для большого словаря и
маленького `k` спросят про кучу на `k` элементов (`container/heap`) —
`O(n log k)`.
