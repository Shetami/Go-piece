Напишите тело `Reverse`: строка задом наперёд.

Что проверяют скрытые тесты:

- латиница и пустая строка;
- кириллица — `"Привет"` → `"тевирП"`;
- смесь разной ширины — `"aя日"` → `"日яa"`;
- двойной разворот возвращает исходную строку.

Кнопка «Запустить» соберёт код с пустым `main` — так видно ошибки компиляции,
не тратя попытку.

<Reveal>

```go
func Reverse(s string) string {
	r := []rune(s)
	for i, j := 0, len(r)-1; i < j; i, j = i+1, j-1 {
		r[i], r[j] = r[j], r[i]
	}
	return string(r)
}
```

**Почему нельзя по байтам.** Напрашивается вот это:

```go
b := []byte(s)
for i, j := 0, len(b)-1; i < j; i, j = i+1, j-1 {
	b[i], b[j] = b[j], b[i]
}
return string(b)
```

На `"golang"` работает, на `"Привет"` выдаёт мусор. Каждая русская буква — два
байта; переставив байты местами, вы получаете последовательности, которые не
являются корректным UTF-8, и на выходе `�`. Тест с кириллицей стоит в проверке
именно ради этого.

**Почему обмен на месте, а не сборка новой строки.** `[]rune(s)` уже выделил
память — второй слайс не нужен. Строки в Go неизменяемы, поэтому менять что-то
можно только в промежуточном слайсе, а `string(r)` в конце копирует его в
новую строку. Итого два выделения — меньше уже не получится.

**Про `i, j := 0, len(r)-1` и условие `i < j`.** При нечётной длине средний
символ остаётся на месте, и это правильно: менять его не с чем. Условие `i < j`,
а не `i <= j`, — иначе средний символ поменялся бы сам с собой, что безвредно,
но бессмысленно.

**Где это ломается по-настоящему.** Руна — всё ещё не «символ, который видит
пользователь». Буква `é` бывает одной руной (U+00E9), а бывает двумя: `e` плюс
комбинируемый акут U+0301. Разворот по рунам во втором случае перенесёт акут на
другую букву. Эмодзи с модификатором цвета кожи или флаг из двух региональных
индикаторов развалятся так же. Правильная единица здесь — **графема**, и
считать её умеет `golang.org/x/text/unicode/norm` или сторонний
`rivo/uniseg`. На собеседовании достаточно сказать, что вы об этом знаете:
задача про руны, а уточнение про графемы показывает глубину.

**Что спросят следом.** Почему в Go нет `strings.Reverse` (потому что
однозначного ответа на «что такое символ» нет), и чем `[]rune(s)` отличается от
`utf8.RuneCountInString(s)` по памяти — второе ничего не выделяет.
