Текст пришёл из textarea, из письма или из выгрузки Word. Перед сохранением
его нормализуют: внутри абзаца — одиночные пробелы, между абзацами —
ровно одна пустая строка. Напишите тело `NormalizeText`.

Что проверяют скрытые тесты:

- табы, пробелы подряд и одиночный перевод строки внутри абзаца — один пробел;
- неразрывный пробел `U+00A0` — тоже пробел;
- три-четыре пустые строки подряд — один разделитель `"\n\n"`;
- строка, в которой только пробелы и табы, разделяет абзацы так же, как пустая;
- окончания `"\r\n"`;
- пустой текст и текст из одних пробелов → `""`.

<Reveal>

```go
func NormalizeText(s string) string {
	s = strings.ReplaceAll(s, "\r\n", "\n")
	var paras []string
	var cur []string
	flush := func() {
		if len(cur) > 0 {
			paras = append(paras, strings.Join(cur, " "))
			cur = cur[:0:0]
		}
	}
	for _, line := range strings.Split(s, "\n") {
		words := strings.Fields(line)
		if len(words) == 0 {
			flush()
			continue
		}
		cur = append(cur, words...)
	}
	flush()
	return strings.Join(paras, "\n\n")
}
```

**Думаем строками, а не подстроками.** Первое, что приходит в голову, —
`strings.Split(s, "\n\n")`. Оно ломается на строке `"\n  \n"`: для человека
это пустая строка, а для `Split` — нет. Поэтому идём по строкам и решаем
для каждой: есть в ней слова или она разделитель.

**`strings.Fields` делает основную работу.** Он режет по `unicode.IsSpace`,
а это не только пробел и таб, но и `\r`, `\v`, `U+0085` и неразрывный пробел
`U+00A0`, который любит вставлять Word. Самописное «заменить `"  "` на
`" "` в цикле» неразрывный пробел не заметит.

**`"\r\n"` заменяем до разбиения.** Иначе строка `"\r"` между двумя
абзацами — формально непустая. Здесь её, правда, спас бы и `Fields`, но
явная нормализация концов строк — хорошая привычка для любого парсера.

**`cur[:0:0]`, а не `cur[:0]`.** `strings.Join` копирует, так что здесь
и `cur[:0]` был бы безопасен. Но если бы в `paras` складывались сами
слайсы, повторное использование массива переписало бы прошлые абзацы —
классический алиасинг слайсов.
