`preview` должна оставить пять символов и многоточие. Вывод (через `%q`,
чтобы было видно байты):

```
"Hello…"
"Пр\xd0…"
```

Вместо «Приве…» — две буквы и обломок третьей. Отметьте строку, в которой
заложена поломка.

<Reveal>

Сломано в строке 10: `return title[:n] + "…"`.

**Индекс строки считается в байтах.** `title[:5]` — первые пять байт.
Латинская буква в UTF-8 занимает один байт, поэтому на «Hello» ошибка не
видна. Кириллическая — два: пять байт — это «П», «р» и первый байт «и».
Строка перестаёт быть корректным UTF-8, и в интерфейсе появится `�`.

Строкой выше та же ошибка: `len(title) <= n` сравнивает с `n` число байт, а
не символов. Но она лишь заставляет резать чуть чаще, чем надо, а портит
данные именно срез.

**Как правильно** — работать с рунами:

```go
runes := []rune(title)
if len(runes) <= n {
	return title
}
return string(runes[:n]) + "…"
```

`[]rune(s)` выделяет память под всю строку. Если заголовки длинные, а
резать надо часто, можно пройти `range` по строке и остановиться на n-й руне —
`range` отдаёт байтовые индексы начала каждой руны.

Строго говоря, и руны — не «символы»: «ё» можно записать двумя кодовыми
точками, а эмодзи с флагом — ещё больше. Для честной работы с графемами есть
`golang.org/x/text`, но на собеседовании обычно хватает рун.

</Reveal>
