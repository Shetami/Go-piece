Программа печатает:

```
user
config
le
```

Вместо `lesson` — `le`. Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 10: `strings.TrimRight(file, ".json")`.

**Второй аргумент `TrimRight` — набор символов, а не суффикс.**
`TrimRight(s, ".json")` отрезает справа *любые* из символов `.`, `j`, `s`,
`o`, `n`, пока не встретит другой символ. Для `user.json` это `n`, `o`,
`s`, `j`, `.` — дальше `r`, которого в наборе нет, стоп. Совпадение.

Для `lesson.json` после точки идут `n`, `o`, `s`, `s` — все из набора. Стоп
только на `e`. Остаётся `le`.

**Как правильно:**

```go
return strings.TrimSuffix(file, ".json")
```

А для произвольного расширения — `strings.TrimSuffix(file, filepath.Ext(file))`.

**Та же пара есть слева:** `TrimLeft` (набор) и `TrimPrefix` (строка). И у
`Trim` — только набор. Если вызываете `Trim*` со строкой длиннее одного
символа, остановитесь и проверьте, что имели в виду.

</Reveal>
