В «Привет, Мир» две заглавные, в «Élan» — одна. Функция находит в «Привет,
Мир» девять, а в «Élan» — одну, но, как выяснится, случайно.

Почините. Ожидаемый вывод:

```
1
2
1
```

<Reveal>

**Цикл по индексу идёт по байтам.** `s[i]` — байт, `rune(s[i])` — число от
0 до 255, превращённое в руну. Для ASCII это совпадает с буквой, а для
остального — нет. «П» в UTF-8 — это байты `0xD0 0x9F`. `rune(0xD0)` — это
`Ð` (латинская заглавная «эт»), и `IsUpper` честно говорит «да». `0x9F` —
управляющий символ, «нет». Для каждой кириллической буквы проверяется её
первый байт, и с заглавностью самой буквы это никак не связано.

«Élan» считается верно по совпадению: первый байт `É` — `0xC3`, это `Ã`,
тоже заглавная. Для `é` первый байт тот же, `0xC3`, и строчная буква
посчиталась бы заглавной.

**Как чинят** — `range` по строке:

```go
for _, r := range s {
	if unicode.IsUpper(r) { n++ }
}
```

`range` декодирует UTF-8 и отдаёт целые руны.

**Правило.** `for i := 0; i < len(s); i++` по строке годится только для
разбора ASCII-протоколов: заголовков HTTP, чисел, разделителей. Как только
речь о тексте, который пишут люди, — `range` или пакет `unicode/utf8`.

</Reveal>
