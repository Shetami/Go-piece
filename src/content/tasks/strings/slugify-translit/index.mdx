Блог строит адрес статьи из заголовка: «Щука и ёж: две истории» →
`/posts/shchuka-i-yozh-dve-istorii`. Таблица транслитерации уже дана —
мапа `translit`. Напишите `Slug` по правилам из комментария.

Что проверяют скрытые тесты:

- заглавные буквы, которые транслитерируются в несколько латинских
  (`Щ`, `Ё`, `Ж`);
- `ъ` и `ь` не рвут слово: «подъезд» → `podezd`, а не `pod-ezd`;
- пунктуация, пробелы, `_` и `-` подряд и по краям — один дефис между
  словами и ни одного по краям; строка из одних знаков → `""`;
- чужие буквы (`é`, `ü`, иероглифы) выпадают, не разрывая слово;
- лимит длины: обрезка по границе слова, в том числе когда граница ровно
  на лимите; слово длиннее лимита режется; `maxLen <= 0` — без лимита.

```go
var translit = map[rune]string{
	'а': "a", 'б': "b", 'в': "v", 'г': "g", 'д': "d", 'е': "e", 'ё': "yo",
	'ж': "zh", 'з': "z", 'и': "i", 'й': "y", 'к': "k", 'л': "l", 'м': "m",
	'н': "n", 'о': "o", 'п': "p", 'р': "r", 'с': "s", 'т': "t", 'у': "u",
	'ф': "f", 'х': "kh", 'ц': "ts", 'ч': "ch", 'ш': "sh", 'щ': "shch",
	'ъ': "", 'ы': "y", 'ь': "", 'э': "e", 'ю': "yu", 'я': "ya",
}

func Slug(title string, maxLen int) string {
	var b strings.Builder
	sep := false // был разделитель после последнего слова
	for _, r := range title {
		r = unicode.ToLower(r)
		var out string
		switch {
		case r >= 'a' && r <= 'z' || r >= '0' && r <= '9':
			out = string(r)
		case translit[r] != "" || r == 'ъ' || r == 'ь':
			out = translit[r]
		case unicode.IsLetter(r) || unicode.Is(unicode.Mn, r):
			continue // незнакомая буква: выбрасываем, слово не разрываем
		default:
			sep = true
			continue
		}
		if out == "" {
			continue
		}
		// Дефис ставим лениво — только перед следующим словом: так не
		// бывает ни дефисов по краям, ни двойных.
		if sep && b.Len() > 0 {
			b.WriteByte('-')
		}
		sep = false
		b.WriteString(out)
	}
	s := b.String()
	if maxLen > 0 && len(s) > maxLen {
		cut := s[:maxLen] // в слаге только ASCII — резать по байтам безопасно
		if s[maxLen] == '-' {
			return cut // граница как раз между словами
		}
		if i := strings.LastIndexByte(cut, '-'); i > 0 {
			return cut[:i]
		}
		return cut
	}
	return s
}
```

**Сначала `ToLower` по руне, потом мапа.** Таблица только строчная, и
это нормально: `unicode.ToLower('Щ')` даёт `'щ'`, а дальше `"shch"`.
Обратный порядок — `strings.ToLower` от уже транслитерированной строки —
тоже работает, но требует держать в мапе и заглавные.

**Разделитель ставим лениво.** Вместо «дописать `-`, а потом схлопнуть
двойные и срезать по краям» запоминаем флаг `sep` и пишем дефис только
перед следующим словом, если что-то уже есть. Двойных дефисов и дефисов
по краям не бывает по построению — не нужно `strings.Trim` и цикл
замены `"--"`.

**Три вида «ничего»: разделитель, выпадающая буква и пустая замена.**
Пробел рвёт слово, а `ъ` и `é` — нет. Если смешать эти случаи, получится
`pod-ezd` или `caf-m-ller`. Именно поэтому `ъ`/`ь` отдельно проверяются
в `switch` — их значение в мапе пустое, и `translit[r] != ""` их бы не
поймал.

**Обрезка — по байтам, но безопасно.** После транслитерации в слаге
только ASCII, поэтому `s[:maxLen]` не разрежет руну. Граница слова: если
следующий символ — `-`, срез уже ровный; иначе откатываемся к последнему
дефису. На собеседовании дальше спрашивают про уникальность слагов
(`-2`, `-3` при коллизии) и почему слаг не должен меняться при правке
заголовка — ссылки уже разошлись.
