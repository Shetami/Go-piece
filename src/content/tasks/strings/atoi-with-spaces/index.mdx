title: Числа через запятую с пробелами
description: Строку «10, 20 ,30» режут по запятым и складывают. Два числа из трёх не разбираются. Почините.
kind: fix
topic: strings

Сумма должна быть 60. Программа печатает:

```
пропускаю: strconv.Atoi: parsing " 20 ": invalid syntax
сумма: 40
```

Почините. Ожидаемый вывод:

```
сумма: 60
```

<Reveal>

**`strconv.Atoi` не пропускает пробелы.** Ни ведущие, ни хвостовые:
`" 20 "` — ошибка синтаксиса. После `Split` по запятой пробелы остались
при числах. Первое и третье числа разобрались только потому, что
пробелов рядом с ними случайно не оказалось, — на другом вводе упали бы
и они.

**Как чинят:**

```go
n, err := strconv.Atoi(strings.TrimSpace(part))
```

Если разделители бывают разными — `strings.FieldsFunc` с функцией, которая
режет и по запятым, и по пробелам. А для настоящего CSV — `encoding/csv`: он
знает про кавычки и запятые внутри значений.

</Reveal>
