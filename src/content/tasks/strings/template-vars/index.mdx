Тексты уведомлений хранятся в базе как шаблоны: `Привет, {{name}}! Заказ
{{ order }} собран.` Напишите `Render`: подставить значения из мапы, а на
кривом шаблоне или неполных данных — вернуть внятную ошибку. Правила — в
комментарии к функции.

Что проверяют скрытые тесты:

- пробелы внутри скобок, повтор одной переменной, пустое значение;
- `\{{` — буквальные скобки; одиночные `{`, `}` и `}}` — обычный текст;
  обратная косая черта без `{{` за ней остаётся в тексте;
- значение, внутри которого есть `{{b}}`, не разворачивается второй раз;
- незакрытая `{{` и пустое имя — `ErrSyntax`;
- при нескольких пропущенных переменных — `errors.Join`, по одной ошибке
  на имя (повторы не дублируются), в порядке появления, каждая
  `errors.Is(…, ErrMissing)`;
- при ошибке результат — пустая строка.

```go
var (
	// ErrMissing — в vars нет значения для переменной шаблона.
	ErrMissing = errors.New("нет значения")
	// ErrSyntax — шаблон синтаксически кривой.
	ErrSyntax = errors.New("ошибка синтаксиса шаблона")
)

func Render(tpl string, vars map[string]string) (string, error) {
	var b strings.Builder
	var missing []error
	seen := map[string]bool{}
	for {
		i := strings.Index(tpl, "{{")
		if i < 0 {
			b.WriteString(tpl)
			break
		}
		// "\{{" — экранированные скобки: пишем "{{" и идём дальше.
		if i > 0 && tpl[i-1] == '\\' {
			b.WriteString(tpl[:i-1])
			b.WriteString("{{")
			tpl = tpl[i+2:]
			continue
		}
		b.WriteString(tpl[:i])
		rest := tpl[i+2:]
		name, after, ok := strings.Cut(rest, "}}")
		if !ok {
			return "", fmt.Errorf("%w: незакрытая {{", ErrSyntax)
		}
		name = strings.TrimSpace(name)
		if name == "" {
			return "", fmt.Errorf("%w: пустое имя переменной", ErrSyntax)
		}
		if v, ok := vars[name]; ok {
			b.WriteString(v) // значение пишем как есть, повторно не разбираем
		} else if !seen[name] {
			seen[name] = true
			missing = append(missing, fmt.Errorf("%w: %s", ErrMissing, name))
		}
		tpl = after
	}
	if len(missing) > 0 {
		return "", errors.Join(missing...)
	}
	return b.String(), nil
}
```

**Идём по шаблону, а не по мапе.** Соблазнительное решение —
`for k, v := range vars { tpl = strings.ReplaceAll(tpl, "{{"+k+"}}", v) }`.
Оно ломается трижды: не видит `{{ name }}` с пробелами, молча оставляет
незаполненные переменные и — главное — разворачивает значения повторно.
Если пользователь назвался `{{b}}`, а `b` — секретный токен, секрет уйдёт
в письмо. К тому же результат зависит от случайного порядка обхода мапы.

**`strings.Index` + `strings.Cut` вместо посимвольного автомата.**
Ищем открывающие скобки, режем по ближайшим закрывающим — имя между ними.
Каждый кусок текста пишется в `strings.Builder` ровно один раз, подстановка
не участвует в дальнейшем поиске.

**Ошибки копим, а не падаем на первой.** Автор шаблона хочет увидеть сразу
все пропущенные поля. `seen` не даёт повторить одно имя дважды,
`errors.Join` собирает их в одну ошибку, а `errors.Is` по-прежнему находит
`ErrMissing` внутри. Синтаксические ошибки, наоборот, прерывают разбор:
после незакрытой скобки дальнейший текст уже не интерпретировать.

**Что спросят дальше.** HTML-экранирование подставленных значений (это
уже `html/template`), фильтры вида `{{ name | upper }}` и кэширование
разобранного шаблона: разбор в список кусков один раз, подстановка — много.
