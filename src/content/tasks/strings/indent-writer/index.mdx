CLI печатает дерево: ошибки внутри шагов, вывод подкоманд с отступом.
Удобнее всего — writer-обёртка: код внутри пишет как обычно, а отступ
добавляется сам. Напишите `IndentWriter`: поля структуры, конструктор и
метод `Write`. Правила — в комментариях.

Что проверяют скрытые тесты:

- много строк в одном `Write` и одна строка в нескольких `Write`, в том
  числе `"\n"` отдельным вызовом;
- пустые строки — без префикса (никаких хвостовых пробелов);
- вывод, который кончается на `"\n"`, не оставляет висящего префикса;
  пустой `Write` ничего не пишет;
- два `IndentWriter` друг в друге, запись через `fmt.Fprintf`;
- `n` — число байт **из `p`**, без префиксов: иначе `io.Copy` вернёт
  `short write`;
- при ошибке нижележащего writer — ошибка и `n`, не больше реально
  записанных байт из `p`.

<Reveal>

```go
type IndentWriter struct {
	w      io.Writer
	prefix []byte
	bol    bool // «начало строки»: следующий байт — первый в строке
}

func NewIndentWriter(w io.Writer, prefix string) *IndentWriter {
	return &IndentWriter{w: w, prefix: []byte(prefix), bol: true}
}

func (iw *IndentWriter) Write(p []byte) (int, error) {
	written := 0
	for len(p) > 0 {
		if iw.bol && p[0] != '\n' {
			if _, err := iw.w.Write(iw.prefix); err != nil {
				return written, err
			}
			iw.bol = false
		}
		// Кусок до конца строки включительно или до конца p.
		end := len(p)
		if i := bytes.IndexByte(p, '\n'); i >= 0 {
			end = i + 1
		}
		n, err := iw.w.Write(p[:end])
		written += n
		if err != nil {
			return written, err
		}
		if n < end {
			return written, io.ErrShortWrite
		}
		iw.bol = p[end-1] == '\n'
		p = p[end:]
	}
	return written, nil
}
```

**Состояние между вызовами — один флаг.** `bol` («begin of line») говорит,
что следующий байт — первый в строке. Префикс пишем лениво, перед первым
байтом строки, а не сразу после `"\n"`. Иначе вывод, который заканчивается
переводом строки, оставит висящий префикс, а строка, пришедшая в
следующем `Write`, получит его дважды или ни разу.

**`n` — про `p`, а не про то, что ушло вниз.** Контракт `io.Writer`: `Write`
возвращает, сколько байт *из `p`* записано, и обязан вернуть ошибку, если
`n < len(p)`. Вернуть `len(p) + len(prefix)·k` — частая ошибка: `io.Copy`
и `bufio.Writer` сверяют `n` с `len(p)` и отвечают `io.ErrShortWrite`, а
`fmt.Fprintf` вернёт вызывающему неверную длину.

**Пишем кусками по строке.** `bytes.IndexByte` находит конец строки, кусок
уходит вниз одним вызовом. Побайтовая запись тоже правильная, но на
каждый байт — вызов нижележащего writer, а если это сокет или файл без
буфера — системный вызов.

**Вложенность бесплатна.** `IndentWriter` сам является `io.Writer`,
поэтому `NewIndentWriter(outer, "- ")` работает без единой строки кода:
внутренний добавляет `"- "`, внешний — `"  "`. Это и есть сила маленьких
интерфейсов. Дальше спросят про конкурентную запись (нужен мьютекс:
`bol` — общее состояние) и про `"\r\n"`.
