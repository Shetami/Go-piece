Напишите тело `Balanced`: скобки `()`, `[]`, `{}` сбалансированы и
правильно вложены. Остальные символы игнорируются.

Что проверяют скрытые тесты:

- `"([]{})"`, `"{[()()]}"` и код `"func() { return a[0] }"` — да;
- неправильная вложенность: `"([)]"` — нет, хотя счёт каждого вида сходится;
- незакрытые и лишние закрывающие: `"(("`, `")("`, `"())"` — нет;
- пустая строка — да.

<Reveal>

```go
func Balanced(s string) bool {
	pairs := map[rune]rune{')': '(', ']': '[', '}': '{'}
	var stack []rune
	for _, r := range s {
		switch r {
		case '(', '[', '{':
			stack = append(stack, r)
		case ')', ']', '}':
			if len(stack) == 0 || stack[len(stack)-1] != pairs[r] {
				return false
			}
			stack = stack[:len(stack)-1]
		}
	}
	return len(stack) == 0
}
```

**Почему стек, а не счётчики.** Три счётчика (по одному на вид) пропустят
`"([)]"`: открыли и закрыли по одной каждого вида, но закрыли не в том
порядке. Закрывающая скобка должна совпасть с *последней* открытой — это
определение стека.

**Три места, где ошибаются:**

- закрывающая при пустом стеке (`")("`) — без проверки `len(stack) == 0`
  будет паника на `stack[-1]`;
- забытая проверка в конце — `"(("` пройдёт, если просто вернуть `true`;
- стек в Go — это слайс: `append` для пуша, `stack[:len(stack)-1]` для попа.
  Отдельный тип не нужен.

</Reveal>
