Напишите тело `LongestUnique` за `O(n)`.

Что проверяют скрытые тесты:

- `"abcabcbb"` → 3, `"pwwkew"` → 3, `"bbbbb"` → 1, `""` → 0;
- `"abba"` → 2 и `"tmmzuxt"` → 5 — на них ломаются почти все первые
  версии;
- `"привет"` → 6: длина в символах;
- полмиллиона символов — быстрее секунды.

<Reveal>

```go
func LongestUnique(s string) int {
	last := map[rune]int{}
	best, start, pos := 0, 0, 0
	for _, r := range s {
		if p, ok := last[r]; ok && p >= start {
			start = p + 1
		}
		last[r] = pos
		best = max(best, pos-start+1)
		pos++
	}
	return best
}
```

**Окно `[start, pos]` всегда без повторов.** Правая граница идёт по
строке, левая прыгает вперёд, когда очередной символ уже есть в окне. Обе
двигаются только вперёд — отсюда `O(n)`.

**`p >= start` — главное условие.** Мапа помнит последнюю позицию символа,
даже если она давно левее окна. В `"abba"` на последней `a` мапа скажет
«была в позиции 0», и без проверки `start` откатится назад, с 2 на 1, —
окно `"bba"` с повтором, ответ 3 вместо 2.

**`pos` — счётчик рун, а не индекс из `range`.** Индекс в `range` по
строке — байтовое смещение, и для кириллицы длины окон были бы вдвое
больше.

</Reveal>
