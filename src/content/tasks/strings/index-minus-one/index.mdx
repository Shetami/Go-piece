`domain` отрезает всё, что после последней `@`. По контракту для строки без
`@` результат пустой. Программа печатает:

```
"example.com"
"mail.ru"
"admin"
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 13: `host := email[at+1:]` — индекс используется, не
проверенный на `-1`.

**`strings.Index` и `LastIndex` возвращают `-1`, если не нашли.**
`-1 + 1 = 0`, и `email[0:]` — вся строка. Паники нет, результат правдоподобный —
именно поэтому баг живёт долго: «admin» похоже на имя хоста.

**Как правильно** — проверять `at < 0` до среза. Или взять функцию, где
«не нашли» — отдельное значение:

```go
_, host, ok := strings.Cut(email, "@")
if !ok {
	return ""
}
```

`Cut` режет по *первому* вхождению, а здесь нужно последнее — для этого
`LastIndex` с проверкой. Но в остальных случаях `Cut` избавляет от
арифметики с `-1` совсем.

</Reveal>
