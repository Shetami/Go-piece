`escape` заменяет `<`, `>` и `&` на HTML-сущности. Программа печатает:

```
&amp;lt;b&amp;gt;Tom &amp; Jerry&amp;lt;/b&amp;gt;
```

Почините. Ожидаемый вывод:

```
&lt;b&gt;Tom &amp; Jerry&lt;/b&gt;
```

<Reveal>

**Каждый `ReplaceAll` проходит по результату предыдущего.** Первые два
вставили `&lt;` и `&gt;` — в них есть `&`. Третий экранирует и эти
амперсанды. Получается двойное экранирование.

**Починка 1** — поставить `&` первым. Работает, но хрупко: порядок замен
держится на внимательности.

**Починка 2** — `strings.NewReplacer`: он проходит строку один раз и
заменяет каждый исходный кусок, не заглядывая в то, что уже вставил.

```go
var htmlEscaper = strings.NewReplacer("&", "&amp;", "<", "&lt;", ">", "&gt;")
```

**Починка 3, настоящая** — `html.EscapeString` или `html/template`,
который экранирует сам и с учётом контекста (атрибут, скрипт, URL).
Экранирование HTML руками — источник XSS: здесь, например, не
экранированы кавычки, и в атрибуте такой текст опасен.

</Reveal>
