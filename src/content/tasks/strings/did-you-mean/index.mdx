`go biuld` отвечает `unknown command "biuld"`, а хорошая утилита добавляет
«Did you mean build?». Напишите `Suggest` по правилам из комментария.

Что проверяют скрытые тесты:

- перестановка соседних букв (`biuld`, `tets`) — расстояние 2;
- русские слова: `ё` против `е` — одна замена, а не две;
- регистр не важен; кандидаты, одинаковые без учёта регистра, выдаются
  один раз — в первом написании;
- при равном расстоянии — алфавитный порядок, а не порядок в списке;
- `limit` обрезает выдачу, `limit = 0` и отсутствие подходящих → `nil`;
- пустой ввод: расстояние равно длине кандидата.

```go
func Suggest(input string, candidates []string, maxDist, limit int) []string {
	type hit struct {
		s    string
		dist int
	}
	in := []rune(strings.ToLower(input))
	seen := map[string]bool{}
	var hits []hit
	for _, c := range candidates {
		lc := strings.ToLower(c)
		if seen[lc] {
			continue
		}
		seen[lc] = true
		if d := levenshtein(in, []rune(lc)); d <= maxDist {
			hits = append(hits, hit{c, d})
		}
	}
	slices.SortFunc(hits, func(a, b hit) int {
		return cmp.Or(cmp.Compare(a.dist, b.dist), strings.Compare(a.s, b.s))
	})
	var out []string
	for _, h := range hits[:min(limit, len(hits))] {
		out = append(out, h.s)
	}
	return out
}

func levenshtein(a, b []rune) int {
	prev := make([]int, len(b)+1)
	cur := make([]int, len(b)+1)
	for j := range prev {
		prev[j] = j
	}
	for i := 1; i <= len(a); i++ {
		cur[0] = i
		for j := 1; j <= len(b); j++ {
			cost := 1
			if a[i-1] == b[j-1] {
				cost = 0
			}
			cur[j] = min(prev[j]+1, cur[j-1]+1, prev[j-1]+cost)
		}
		prev, cur = cur, prev
	}
	return prev[len(b)]
}
```

**Руны, а не байты.** Левенштейн по байтам считает замену «ё» на «е» за
две операции (оба байта разные) и отбрасывает очевидную подсказку. Приводим
обе строки к `[]rune` — после `strings.ToLower`, чтобы регистр не давал
лишних замен.

**Две строки таблицы вместо матрицы.** Каждая клетка зависит только от
левой, верхней и диагональной, поэтому хватает `prev` и `cur`, которые
меняются местами после каждой строки. Память `O(m)` вместо `O(n·m)` —
то, о чём спросят сразу после работающего решения. Второй вопрос —
отсечение: если минимум строки уже больше `maxDist`, дальше считать
бессмысленно.

**Порядок при равенстве — часть контракта.** `tets` одинаково далеко от
`get`, `test` и `vet`. Без тай-брейкера порядок зависит от порядка в
списке команд, а если кандидаты пришли из мапы — меняется от запуска к
запуску, и тесты флакают. `cmp.Or` склеивает сравнения по ключам в одну
строку.

**Дедупликация по нижнему регистру через мапу.** `seen` хранит
нормализованный ключ, а в выдачу идёт исходное написание — пользователь
увидит `Deploy`, как команда зарегистрирована. Заодно дубликаты не
считаются дважды. Перестановку за одну операцию умеет расстояние
Дамерау–Левенштейна — ещё одна строка в `min`, если спросят.
