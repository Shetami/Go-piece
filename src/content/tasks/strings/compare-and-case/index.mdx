Три сравнения строк оператором «меньше», поиск буквы в слове «привет»,
перевод в верхний регистр слова со `ß` и сравнение без учёта регистра.

Напишите весь вывод программы.

<Reveal>

**Строки сравниваются побайтно.** Никакой локали и никакого «алфавитного»
порядка: сравниваются байты UTF-8 слева направо.

- `"apple" < "banana"` — `a` меньше `b`, `true`.
- `"Zebra" < "apple"` — заглавная `Z` (90) меньше строчной `a` (97), `true`.
- `"10" < "9"` — `'1'` меньше `'9'`, дальше уже не смотрят, `true`. Числа в
  строках так не сортируют.

**`Index` возвращает позицию в байтах.** В «привет» буква `в` — четвёртая по
счёту, но каждая буква занимает два байта, и индекс — 6. `IndexRune` ищет руну,
но возвращает тоже байтовый индекс — те же 6. Резать строку по этому индексу
правильно: `s[:6]` — это «при».

**`ToUpper` работает по одной руне.** У `ß` нет однобуквенной заглавной
пары в простом отображении Unicode, поэтому она остаётся как есть. `len`
считает байты: `ß` занимает два, всего 7.

**`EqualFold` сравнивает без учёта регистра**, а `==` — побайтно.

Итого:

```
true true true
6 6
STRAßE 7
true false
```

**Если нужен порядок «как у людей»** — пакет `golang.org/x/text/collate` с
правилами конкретного языка. А для регистронезависимого сравнения не делайте
`strings.ToLower(a) == strings.ToLower(b)`: это две лишние аллокации и не
всегда тот же результат, что у `EqualFold`.

</Reveal>
