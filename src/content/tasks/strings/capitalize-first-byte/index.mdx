`capitalize` должна вернуть `"Go"` и `"Язык"`. Вывод через `%q`:

```
"Go"
"�\x8fзык"
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 13: `strings.ToUpper(s[:1]) + s[1:]`.

**`s[:1]` — первый байт, а не первая буква.** «я» в UTF-8 — два байта,
`0xD1 0x8F`. `s[:1]` отрезает только `0xD1`. Для `strings.ToUpper` это
некорректный UTF-8: такой байт она заменяет на `U+FFFD` (`�`). А второй
байт буквы, `0x8F`, остаётся висеть в начале `s[1:]` — отсюда `\x8f`.

**Как правильно** — взять первую руну и её длину в байтах:

```go
r, size := utf8.DecodeRuneInString(s)
return string(unicode.ToUpper(r)) + s[size:]
```

**Про `strings.Title`.** Готовая функция для этого была, но она объявлена
устаревшей: она не знает правил разных языков (в голландском «ij» в начале
слова — обе заглавные, в турецком у «i» другая заглавная пара). Замена —
`cases.Title` из `golang.org/x/text/cases` с указанием языка.

</Reveal>
