Правило: не меньше восьми символов. Латинский `qwerty` проверка отклоняет,
а кириллический «пароль» из шести букв пропускает.

Почините. Ожидаемый вывод:

```
secret12: ок
пароль: слишком короткий
пароль12: ок
qwerty: слишком короткий
```

<Reveal>

**`len` строки — это байты.** В UTF-8 латинская буква занимает один байт,
кириллическая — два. `len("пароль")` — 12, и проверка «не меньше 8»
проходит.

**Как чинят** — считать руны:

```go
if utf8.RuneCountInString(pw) < 8 { ... }
```

`len([]rune(pw))` даёт то же, но выделяет память под слайс рун, а
`RuneCountInString` просто считает.

**Где ещё байты выдают себя за символы.** Ограничения длины полей в
формах и API, обрезка текста, выравнивание столбцов в таблице (`%-10s`
отсчитывает руны, но широкие иероглифы и эмодзи всё равно поедут). А вот
для ограничений хранилища — `varchar` в байтовых кодировках, размер
сообщения в очереди — как раз нужны байты. Прежде чем чинить, решите, что
именно вы ограничиваете.

</Reveal>
