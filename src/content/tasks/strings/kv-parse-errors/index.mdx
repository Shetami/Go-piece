Строки вида `host=db.local port=5432 name="my app"` встречаются в логах
(logfmt), DSN, аннотациях и флагах. Напишите `ParseKV`: разобрать строку в
мапу, а на кривом вводе вернуть `*ParseError` с позицией, по которой человек
найдёт опечатку. Правила и позиции ошибок — в комментарии к функции.

Что проверяют скрытые тесты:

- кавычки с пробелами и `=` внутри, экранирования `\"` и `\\`, пустое
  значение `empty=`, кириллические ключи, пробелы по краям и двойные пробелы;
- позицию для каждого вида ошибки, в том числе когда строка просто
  кончилась;
- позиция считается **в символах**: перед ошибкой стоит кириллица;
- при ошибке мапа — `nil`, а не наполовину заполненная;
- повторный ключ: `errors.Is(err, ErrDuplicateKey)` и `errors.As` в
  `*ParseError` с позицией начала ключа;
- синтаксическая ошибка в повторной паре — это синтаксическая ошибка, а не
  повтор.

```go
var ErrDuplicateKey = errors.New("повторный ключ")

type ParseError struct {
	Pos int
	Msg string
	Err error
}

func (e *ParseError) Error() string { return fmt.Sprintf("позиция %d: %s", e.Pos, e.Msg) }
func (e *ParseError) Unwrap() error { return e.Err }

func ParseKV(s string) (map[string]string, error) {
	rs := []rune(s) // позиции — в символах, поэтому работаем со слайсом рун
	n := len(rs)
	res := map[string]string{}
	fail := func(pos int, msg string) (map[string]string, error) {
		return nil, &ParseError{Pos: pos, Msg: msg}
	}
	i := 0
	for {
		for i < n && rs[i] == ' ' {
			i++
		}
		if i == n {
			return res, nil
		}
		// Ключ.
		start := i
		for i < n && isKeyRune(rs[i]) {
			i++
		}
		if i == n || rs[i] != '=' {
			return fail(i, "ожидали '='")
		}
		if i == start {
			return fail(i, "пустой ключ")
		}
		key := string(rs[start:i])
		i++ // '='

		// Значение.
		var val strings.Builder
		if i < n && rs[i] == '"' {
			open := i
			i++
			closed := false
			for i < n && !closed {
				switch r := rs[i]; r {
				case '"':
					closed = true
				case '\\':
					if i+1 < n && (rs[i+1] == '"' || rs[i+1] == '\\') {
						val.WriteRune(rs[i+1])
						i++
					} else {
						return fail(i, "неизвестное экранирование")
					}
				default:
					val.WriteRune(r)
				}
				i++
			}
			if !closed {
				return fail(open, "незакрытая кавычка")
			}
			if i < n && rs[i] != ' ' {
				return fail(i, "ожидали пробел после кавычки")
			}
		} else {
			for i < n && rs[i] != ' ' {
				if rs[i] == '"' {
					return fail(i, "кавычка внутри значения")
				}
				val.WriteRune(rs[i])
				i++
			}
		}
		// Дубликат проверяем после разбора значения: синтаксическая
		// ошибка в этой же паре важнее.
		if _, dup := res[key]; dup {
			return nil, &ParseError{Pos: start, Msg: "повторный ключ " + key, Err: ErrDuplicateKey}
		}
		res[key] = val.String()
	}
}

func isKeyRune(r rune) bool {
	return unicode.IsLetter(r) || unicode.IsDigit(r) || r == '_' || r == '-' || r == '.'
}
```

**Руны, а не байты.** Позицию ошибки увидит человек: в редакторе, в
подчёркивании под строкой. Для него «ф» — один символ. Проще всего сразу
превратить строку в `[]rune` и ходить индексом — тогда позиция равна
индексу. Альтернатива — идти по байтам и держать отдельный счётчик рун,
но это второе состояние, которое легко рассинхронизировать.

**Ошибка — тип, причина — обёрнутый sentinel.** `*ParseError` несёт
данные (позицию), а `ErrDuplicateKey` — категорию. Благодаря `Unwrap`
вызывающий код может спросить и `errors.As(err, &pe)`, чтобы подсветить
место, и `errors.Is(err, ErrDuplicateKey)`, чтобы выбрать текст подсказки.
Не пытайтесь закодировать категорию в `Msg` — сравнение строк ошибок
ломается от первой правки текста.

**Порядок проверок — часть контракта.** Дубликат ключа проверяется после
того, как значение разобрано целиком. Иначе на `a=1 a="x` пользователь
получит «повторный ключ», исправит его и тут же наткнётся на незакрытую
кавычку. Позиция для незакрытой кавычки — открывающая: конец строки
ничего не говорит о том, где начался сломанный кусок.

**Частичный результат не отдаём.** При ошибке возвращаем `nil`: мапа с
половиной ключей выглядит как успех и маскирует проблему. На собеседовании
дальше спрашивают: как вернуть *все* ошибки (копить в слайс и
`errors.Join`), и как стримить разбор из `io.Reader` без `[]rune` всей
строки.
