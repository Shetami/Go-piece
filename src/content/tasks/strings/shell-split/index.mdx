Сервис запускает команды из конфига (`cmd: cp "мой файл.txt" /backup`),
а `strings.Fields` режет «мой файл.txt» пополам. Напишите `SplitArgs` —
упрощённый shell-токенайзер по правилам из комментария.

Что проверяют скрытые тесты:

- разные пробельные разделители, пустая строка;
- кавычки, склеенные с текстом и друг с другом, в одно слово;
- `""` и `''` — пустые аргументы, а не пропуск;
- разная семантика `\`: в одинарных кавычках буквальная, в двойных —
  только перед `"` и `\`, снаружи — перед чем угодно;
- `#` — обычный символ (комментариев нет);
- незакрытые кавычки и `\` в конце — `*SyntaxError` с позицией в символах,
  в том числе после кириллицы.

<Reveal>

```go
type SyntaxError struct {
	Pos int
	Msg string
}

func (e *SyntaxError) Error() string { return fmt.Sprintf("символ %d: %s", e.Pos, e.Msg) }

func SplitArgs(line string) ([]string, error) {
	rs := []rune(line)
	var args []string
	var cur strings.Builder
	inArg := false // есть начатый аргумент, даже пустой (после "")
	for i := 0; i < len(rs); i++ {
		r := rs[i]
		switch {
		case r == ' ' || r == '\t' || r == '\n':
			if inArg {
				args = append(args, cur.String())
				cur.Reset()
				inArg = false
			}
		case r == '\\':
			if i+1 == len(rs) {
				return nil, &SyntaxError{Pos: i, Msg: "'\\' в конце строки"}
			}
			i++
			cur.WriteRune(rs[i])
			inArg = true
		case r == '\'':
			open := i
			end := -1
			for j := i + 1; j < len(rs); j++ {
				if rs[j] == '\'' {
					end = j
					break
				}
			}
			if end < 0 {
				return nil, &SyntaxError{Pos: open, Msg: "незакрытая одинарная кавычка"}
			}
			cur.WriteString(string(rs[i+1 : end]))
			i = end
			inArg = true
		case r == '"':
			open := i
			i++
			for ; i < len(rs) && rs[i] != '"'; i++ {
				if rs[i] == '\\' && i+1 < len(rs) && (rs[i+1] == '"' || rs[i+1] == '\\') {
					i++
				}
				cur.WriteRune(rs[i])
			}
			if i == len(rs) {
				return nil, &SyntaxError{Pos: open, Msg: "незакрытая двойная кавычка"}
			}
			inArg = true
		default:
			cur.WriteRune(r)
			inArg = true
		}
	}
	if inArg {
		args = append(args, cur.String())
	}
	return args, nil
}
```

**Аргумент — не «кусок между пробелами», а результат склейки.** В shell
`a"b c"'d'` — одно слово `ab cd`: кавычки не разделяют, а только
выключают особый смысл пробела. Поэтому аргумент копится в
`strings.Builder`, а разделителем служит только пробел *вне* кавычек.

**Флаг «аргумент начат» отдельно от содержимого.** Проверка
`cur.Len() > 0` теряет пустые аргументы: `git commit -m ""` превратится в
`git commit -m`, и следующий флаг станет сообщением коммита. Флаг `inArg`
выставляется любыми кавычками, даже пустыми.

**Три режима `\`.** В одинарных кавычках — буквальная, в двойных —
экранирует только `"` и `\` (в настоящем shell ещё `$`, `` ` `` и перевод
строки), снаружи — любой символ. Путаница режимов даёт то `c:dir` вместо
`c:\dir`, то незакрытую кавычку на `"a\"`.

**Зачем вообще разбирать.** Главный соблазн — `exec.Command("sh", "-c",
line)`. Это отдаёт строку интерпретатору с подстановками, пайпами и
`; rm -rf`, и любой кусок пользовательского ввода превращается в
инъекцию. Свой токенайзер плюс `exec.Command(args[0], args[1:]...)` —
безопасная альтернатива; на собеседовании об этом спросят обязательно.
