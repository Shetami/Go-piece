Маски `*.log`, `user:*:session`, `app-??.txt` встречаются везде: правила
ротации логов, фильтры ключей в кэше, списки игнорирования. Напишите
`Match` — без `path.Match`, `filepath.Match` и `regexp`. Правила — в
комментарии.

Что проверяют скрытые тесты:

- `*` в начале, в середине, в конце и несколько штук, в том числе пустое
  совпадение; `*` проходит сквозь `/`;
- ситуации, где первая подходящая буква после `*` — не та (`"*ab"` против
  `"aab"`);
- `?` — одна руна: `"??"` подходит к `"ёж"`;
- `\*`, `\?`, `\\` и экранированная обычная буква;
- `\` в конце шаблона — `ErrBadPattern`, даже если имя не совпадает с
  первого символа;
- шаблон `a*a*…a*b` (40 звёзд) против 200 букв `a` — быстрее 3 секунд.

```go
var ErrBadPattern = errors.New("некорректный шаблон")

func Match(pattern, name string) (bool, error) {
	// Сначала разбираем шаблон целиком: так ошибка находится всегда,
	// а не только если сравнение до неё дошло.
	type tok struct {
		r    rune
		kind byte // 'c' — символ, '?' — любой один, '*' — любая строка
	}
	var toks []tok
	pr := []rune(pattern)
	for i := 0; i < len(pr); i++ {
		switch pr[i] {
		case '\\':
			if i+1 == len(pr) {
				return false, ErrBadPattern
			}
			i++
			toks = append(toks, tok{pr[i], 'c'})
		case '*':
			toks = append(toks, tok{kind: '*'})
		case '?':
			toks = append(toks, tok{kind: '?'})
		default:
			toks = append(toks, tok{pr[i], 'c'})
		}
	}
	s := []rune(name)
	// Жадный разбор с одной точкой отката: запоминаем последнюю '*' и
	// позицию в name, с которой она начала «съедать». При несовпадении
	// звезда съедает ещё один символ. Более ранние звёзды пересматривать
	// не нужно — отсюда отсутствие экспоненты.
	p, i := 0, 0
	star, mark := -1, 0
	for i < len(s) {
		switch {
		case p < len(toks) && toks[p].kind == '*':
			star, mark = p, i
			p++
		case p < len(toks) && (toks[p].kind == '?' || toks[p].r == s[i]):
			p++
			i++
		case star >= 0:
			mark++
			p, i = star+1, mark
		default:
			return false, nil
		}
	}
	// name кончился — в шаблоне могут остаться только звёзды.
	for p < len(toks) && toks[p].kind == '*' {
		p++
	}
	return p == len(toks), nil
}
```

**Рекурсия «звезда съедает 0, 1, 2… символа» — экспонента.** Наивное
решение пробует для каждой `*` все длины и рекурсивно проверяет хвост. На
`a*a*…*b` против строки из `a` оно перебирает все способы разложить
строку по звёздам — число вариантов растёт как биномиальный
коэффициент, и 40 звёзд не дождутся ответа. Именно так уходили в отказ
реальные glob-реализации в FTP-серверах и shell.

**Достаточно одной точки отката.** Когда встречаем `*`, запоминаем её и
текущую позицию в строке. При несовпадении откатываемся к последней
звезде и отдаём ей ещё один символ. Возвращаться к более ранним звёздам
не нужно: всё, что они могли бы съесть, может съесть и последняя. Итог —
`O(n·m)` в худшем случае и почти линейно на практике. Альтернатива —
динамика по таблице `(len(p)+1)×(len(s)+1)`, тоже `O(n·m)`, но с памятью.

**Шаблон разбираем в токены заранее.** Так `\*` становится обычным
символом и не путается со звёздочкой, а кривой шаблон отклоняется всегда,
а не только когда сравнение дошло до его конца. Ошибка «иногда» хуже
ошибки «всегда»: она всплывёт в проде на другом имени файла.

**Руны, а не байты.** `?` должен съесть «ё» целиком. На байтах `"??"`
совпадёт с одной кириллической буквой, а `"?"` — с половиной.
