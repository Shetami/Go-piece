В строке `"привет, мир"` ищут подстроку `"мир"`, печатают длину строки,
найденный индекс, хвост от этого индекса и число символов до него.

Напишите весь вывод программы.

<Reveal>

**Строка в Go — байты, и индексы у неё байтовые.** Каждая буква кириллицы в
UTF-8 занимает два байта, запятая и пробел — по одному. `"привет"` — 12
байт, `", "` — 2, `"мир"` — 6. Всего 20.

**`strings.Index` возвращает байтовое смещение**, а не номер символа: `"мир"`
начинается с 14-го байта. Зато срез `s[14:]` по этому индексу корректен —
индекс попадает ровно на начало руны.

**Номер символа — отдельный подсчёт.** До `"мир"` восемь рун: шесть букв,
запятая, пробел.

Итого:

```
20
14
мир
8
```

**Правило.** Индексы, которые вернули функции `strings`, можно смело
использовать для срезов той же строки. Опасно другое: считать индекс
самому, «на глаз» по символам, — `s[:8]` отрежет четыре буквы, а не восемь.

</Reveal>
