Напишите тело `IsPalindrome`. Учитываются только буквы и цифры, регистр не
важен.

Что проверяют скрытые тесты:

- латиница с пробелами и знаками: `"Was it a car or a cat I saw?"`;
- кириллица: `"А роза упала на лапу Азора"`;
- пустая строка, одна буква и строка из одних знаков — палиндромы.

<Reveal>

```go
func IsPalindrome(s string) bool {
	var rs []rune
	for _, r := range s {
		if unicode.IsLetter(r) || unicode.IsDigit(r) {
			rs = append(rs, unicode.ToLower(r))
		}
	}
	for i, j := 0, len(rs)-1; i < j; i, j = i+1, j-1 {
		if rs[i] != rs[j] {
			return false
		}
	}
	return true
}
```

**Руны, а не байты.** Сравнение `s[i]` с `s[len(s)-1-i]` работает только для
ASCII. У «А» и «а» в конце кириллической строки байты идут в другом
порядке, чем в начале, и байтовый разворот ломает буквы.

**Сначала фильтр, потом сравнение.** Проще собрать нормализованные руны и
сравнить два конца, чем пропускать пробелы и знаки в двух указателях
одновременно. Но можно и так — без слайса, с двумя индексами по строке, —
это ответ на «а без дополнительной памяти?». Двигаться с конца строки по
рунам помогает `utf8.DecodeLastRuneInString`.

**Про `ToLower`.** Для немецкой `ß` или турецкой `İ` простого посимвольного
понижения регистра недостаточно, и полноценное сравнение без учёта регистра
— это `strings.EqualFold` или `golang.org/x/text/cases`. Для задачи с
собеседования `unicode.ToLower` достаточно.

</Reveal>
