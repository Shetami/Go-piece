Сервис отдаёт файлы по `GET /files/<путь>` или распаковывает архив, где
имена файлов задаёт автор архива. Если склеить путь «в лоб», запрос
`/files/../../etc/passwd` отдаст системный файл — это path traversal,
одна из самых частых уязвимостей. Напишите `SafeJoin` по правилам из
комментария.

Что проверяют скрытые тесты:

- повторные слеши, `.`, `..` внутри допустимого пути, ведущий `/` у
  пользовательского пути, пустой путь, корень `/`;
- `...`, `..a`, `.hidden` — обычные имена;
- выход выше корня — ошибка, даже если потом путь «возвращается» в
  похожую директорию (`a/../../files-evil/x`);
- `\` как разделитель;
- нулевой байт — `ErrBadPath`.

<Reveal>

```go
var (
	// ErrTraversal — путь пытается выйти за пределы корня.
	ErrTraversal = errors.New("выход за пределы корня")
	// ErrBadPath — в пути недопустимый символ.
	ErrBadPath = errors.New("недопустимый путь")
)

func SafeJoin(root, rel string) (string, error) {
	if strings.IndexByte(rel, 0) >= 0 {
		return "", ErrBadPath
	}
	// Слайс как стек сегментов: ".." снимает верхний.
	var stack []string
	parts := strings.FieldsFunc(rel, func(r rune) bool { return r == '/' || r == '\\' })
	for _, p := range parts {
		switch p {
		case ".":
		case "..":
			if len(stack) == 0 {
				return "", ErrTraversal
			}
			stack = stack[:len(stack)-1]
		default:
			stack = append(stack, p)
		}
	}
	if len(stack) == 0 {
		return root, nil
	}
	return strings.TrimSuffix(root, "/") + "/" + strings.Join(stack, "/"), nil
}
```

**Стек сегментов вместо проверки префикса.** Популярное решение —
`filepath.Join(root, rel)` и `strings.HasPrefix(result, root)`. Оно
ломается на соседней директории: `/srv/files` — префикс строки
`/srv/files-evil/x`. Правильный префикс — `root + "/"`, но проще вообще
не выходить за корень: идём по сегментам, `..` снимает верхний элемент
стека, а пустой стек на `..` — это и есть попытка выйти наружу.

**Ошибка, а не молчаливая обрезка.** `path.Clean("/" + rel)` тоже
безопасен: `..` выше корня он просто выбрасывает. Но запрос с `../../`
— почти всегда атака или баг клиента, и об этом стоит узнать (вернуть 400
и записать в лог), а не отдать какой-то другой файл.

**`\` — тоже разделитель.** На Linux `..\..\x` — одно странное имя, но
тот же путь может уйти в Windows-хранилище, в zip-архив, в S3-ключ,
который потом выгрузят на Windows. Разбираем оба разделителя —
`strings.FieldsFunc` заодно выкидывает пустые сегменты от `//`.

**Нулевой байт.** В C-функциях строка кончается на `\0`: `report.pdf\0.png`
пройдёт проверку расширения `.png`, а откроется `report.pdf`. Go-шный
`os.Open` такой путь отвергнет, но путь мог уйти в C-библиотеку или в
другую систему. Последний рубеж защиты — не строки, а ОС: в Go 1.24
появился `os.Root`, который не выпускает за корень даже через симлинки;
про симлинки на собеседовании спросят обязательно.
