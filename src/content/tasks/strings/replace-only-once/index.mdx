Программа печатает:

```
go
hello-world
go-is fun again
```

Первые два заголовка превратились правильно, в третьем остались пробелы.
Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 10: `strings.Replace(title, " ", "-", 1)`.

**Последний аргумент `Replace` — сколько вхождений заменить.** `1` — только
первое. Тесты на заголовках из одного-двух слов этого не заметят: там один
пробел или ни одного.

`-1` означает «все», и для этого есть отдельная функция:

```go
s := strings.ReplaceAll(title, " ", "-")
```

**Как не попадаться.** Если видите `Replace` с `1` или `-1` на конце — это
почти всегда должен был быть `ReplaceAll`. Настоящий смысл `n` — редкие
случаи вроде «заменить первое вхождение префикса». А для настоящих slug'ов
ещё понадобится транслитерация и выкидывание знаков препинания — но это
уже другая задача.

</Reveal>
