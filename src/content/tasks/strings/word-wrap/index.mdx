Напишите тело `Wrap`.

Что проверяют скрытые тесты:

- обычный английский текст по ширине 10;
- русский текст — ширина считается в символах, а не байтах;
- табы, переводы строк и пробелы подряд превращаются в один пробел;
- слово длиннее ширины стоит на отдельной строке целиком;
- пустой текст → ни одной строки.

<Reveal>

```go
func Wrap(text string, width int) []string {
	var lines []string
	var cur strings.Builder
	curLen := 0
	for _, w := range strings.Fields(text) {
		wl := utf8.RuneCountInString(w)
		if curLen > 0 && curLen+1+wl > width {
			lines = append(lines, cur.String())
			cur.Reset()
			curLen = 0
		}
		if curLen > 0 {
			cur.WriteByte(' ')
			curLen++
		}
		cur.WriteString(w)
		curLen += wl
	}
	if curLen > 0 {
		lines = append(lines, cur.String())
	}
	return lines
}
```

**`strings.Fields` решает половину задачи:** режет по любым пробельным
символам и выбрасывает пустое.

**Длину держим отдельно в рунах.** `cur.Len()` — это байты, и русская
строка «переполнялась» бы вдвое раньше.

**Условие переноса — `curLen > 0 && ...`.** Без `curLen > 0` длинное
слово в начале строки вызвало бы перенос пустой строки. А так оно просто
встаёт в пустую строку, пусть и превышая ширину, — лучше, чем резать
слово.

**`+1` — пробел** между словами, он тоже занимает место.

</Reveal>
