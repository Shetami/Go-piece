Файл режут на строки и каждое имя проверяют по мапе. Программа печатает:

```
"admin\r": false
"guest\r": false
"root": true
```

Почините. Ожидаемый вывод:

```
"admin": true
"guest": false
"root": true
```

<Reveal>

**В Windows строки кончаются на `\r\n`.** `Split` по `\n` оставляет `\r` в
конце каждой строки. `TrimSpace` убрал его только у последней — потому
`root` и прошёл. Без `%q` этот `\r` в выводе не виден вовсе: терминал
просто переводит каретку в начало строки.

**Как правильно** — читать построчно через `bufio.Scanner`: его
`ScanLines` отрезает `\r` перед `\n` сам. Заодно он не держит в памяти весь
файл целиком.

Если данные уже в строке, с Go 1.24 есть `strings.Lines` — но он оставляет
перевод строки в каждом куске, так что `TrimRight(line, "\r\n")` всё равно
нужен.

</Reveal>
