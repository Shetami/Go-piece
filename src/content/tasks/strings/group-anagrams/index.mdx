Напишите тело `GroupAnagrams`.

Что проверяют скрытые тесты:

- `[eat tea tan ate nat bat]` → `[[eat tea ate] [tan nat] [bat]]`;
- кириллица и регистр: `Пила` и `липа` — одна группа;
- `aab` и `abb` — разные группы: важно не только какие буквы, но и
  сколько;
- пустой вход → пусто;
- порядок групп — по первому появлению, одинаковый при каждом вызове.

<Reveal>

```go
func GroupAnagrams(words []string) [][]string {
	var groups [][]string
	index := map[string]int{}
	for _, w := range words {
		r := []rune(strings.ToLower(w))
		slices.Sort(r)
		key := string(r)
		i, ok := index[key]
		if !ok {
			i = len(groups)
			index[key] = i
			groups = append(groups, nil)
		}
		groups[i] = append(groups[i], w)
	}
	return groups
}
```

**Ключ группы — отсортированные буквы.** У анаграмм они совпадают:
`eat`, `tea`, `ate` → `aet`. Сортировать надо **руны**, не байты: байты
кириллической буквы, разъехавшиеся при сортировке, дадут мусор вместо
строки, а совпадения случатся не там.

**Мапа хранит номер группы, а не саму группу.** Так порядок групп
определяется слайсом `groups`, а не случайным порядком обхода мапы. Если
сложить группы в `map[string][]string` и потом обойти её — ответ будет
каждый раз в другом порядке.

**Другой ключ** — счётчик букв: `[26]int` для латиницы работает как ключ
мапы (массивы сравнимы) и считается за `O(len)` без сортировки.
