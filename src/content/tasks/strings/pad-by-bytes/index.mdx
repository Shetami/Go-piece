`pad` дополняет строку пробелами до нужной ширины. Для `coffee` всё
хорошо, а русские названия короче:

```
чай    |90
coffee    |350
сахар|60
```

Почините. Ожидаемый вывод:

```
чай       |90
coffee    |350
сахар     |60
```

<Reveal>

**`len(s)` — длина в байтах.** `"чай"` — три буквы, но шесть байт, и `pad`
считает, что добавить надо четыре пробела вместо семи. `"сахар"` — десять
байт, и пробелов не добавляется вовсе.

**Считать надо руны:** `utf8.RuneCountInString(s)`.

**А проще — отдать это `fmt`.** Ширина в `%-10s` считается в рунах:

```go
fmt.Printf("%-10s|%s\n", name, price)
```

**Где руны не спасут.** Иероглифы и эмодзи в терминале занимают по две
колонки, а комбинированные символы вроде `й` из двух рун — одну. Для
настоящего выравнивания по ширине экрана нужна библиотека, которая знает
ширину символов, например `golang.org/x/text/width`.

</Reveal>
