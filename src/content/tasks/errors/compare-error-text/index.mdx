`findUser` возвращает `ErrNotFound`, обёрнутую с номером пользователя.
`status` должен превратить её в 404. Программа печатает:

```
200 500
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 19: ошибку узнают по тексту.

**Текст обёрнутой ошибки — это текст всей цепочки.** `err.Error()` —
`"user 42: not found"`, а не `"not found"`. Сравнение строк ломается от
первой же обёртки, от исправленной опечатки, от перевода сообщения.

**Как правильно** — `errors.Is(err, ErrNotFound)`. Он идёт по цепочке через
`Unwrap` и сравнивает каждое звено с сентинелом. Заодно проверка на `nil`
не нужна: `errors.Is(nil, ErrNotFound)` — просто `false`.

**Текст ошибки — для человека.** Код решает по идентичности (`errors.Is`)
или по типу (`errors.As`). Если чужая библиотека не даёт ни того, ни
другого — это повод завести issue, а сравнение подстрок оставить как
временную меру с комментарием.

</Reveal>
