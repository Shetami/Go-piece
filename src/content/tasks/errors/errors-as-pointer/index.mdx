`HTTPError` реализует `error` методом на указателе. `fetch` возвращает её,
обёрнутую в `fmt.Errorf`. Дальше — три проверки и печать.

Напишите весь вывод программы.

<Reveal>

**`errors.As` ищет в цепочке ошибку нужного типа.** Цель — `&he`, указатель
на переменную типа `*HTTPError`. `As` разворачивает обёртку, находит
`*HTTPError`, присваивает его в `he` и возвращает `true`. Код доступен:
`404`.

**`errors.Is` сравнивает на равенство.** Внутри лежит указатель, и мы
сравниваем его с *другим* указателем на новую структуру. Указатели разные —
`false`, хотя поля совпадают. Для структур-ошибок нужен `As`, а `Is` — для
сентинелов вроде `io.EOF`.

**Цель `As` может быть интерфейсом.** Тогда `As` ищет ошибку, которая этот
интерфейс реализует. Метода `Timeout` у `HTTPError` нет — `false`. Так,
например, проверяют сетевые ошибки: `var ne net.Error; errors.As(err, &ne) && ne.Timeout()`.

Итого:

```
true 404
false
false
fetch: http 404
```

**Частая ошибка** — передать в `As` сам `he`, а не `&he`, или взять
`var he HTTPError` без звёздочки. В первом случае `As` паникует («target must
be a non-nil pointer»), во втором — тоже: `HTTPError` без указателя не
реализует `error`. Обе ошибки ловит `go vet` (проверка `errorsas`), так что
не отключайте его.

</Reveal>
