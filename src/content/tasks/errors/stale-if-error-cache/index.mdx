Каталог товаров читается из медленного сервиса через кэш. Когда сервис
лежит, лучше показать цену пятиминутной давности, чем страницу ошибки.
Но решать это должен вызывающий, поэтому кэш возвращает **и** значение,
**и** ошибку — редкий в Go, но законный контракт.

Реализуйте `Cache` по контракту в заготовке. Главное здесь — по-разному
обращаться с разными ошибками источника.

Что проверяют скрытые тесты:

- свежее значение отдаётся без обращения к источнику, после `ttl` —
  перезагружается;
- источник упал — старое значение и `*StaleError` с возрастом и
  причиной; упавшая загрузка не кэшируется; без старого значения —
  ошибка источника как есть;
- «не найдено» кэшируется на `negTTL`, а старое значение после него
  отдавать нельзя — даже когда источник потом упадёт;
- медленная загрузка одного ключа не блокирует другие.

<Reveal>

```go
func (c *Cache) Get(key string) (string, error) {
	c.mu.Lock()
	e, ok := c.entries[key]
	now := c.now()
	if ok {
		age := now.Sub(e.at)
		if e.missing && age < c.negTTL {
			c.mu.Unlock()
			return "", e.err
		}
		if !e.missing && age < c.ttl {
			c.mu.Unlock()
			return e.val, nil
		}
	}
	c.mu.Unlock()

	v, err := c.load(key)

	c.mu.Lock()
	defer c.mu.Unlock()
	now = c.now()
	switch {
	case err == nil:
		c.entries[key] = entry{val: v, at: now}
		return v, nil
	case errors.Is(err, ErrNotFound):
		c.entries[key] = entry{missing: true, err: err, at: now}
		return "", err
	}
	if e, ok := c.entries[key]; ok && !e.missing {
		return e.val, &StaleError{Key: key, Age: now.Sub(e.at), Err: err}
	}
	return "", err
}
```

**«Не найдено» — это ответ, «таймаут» — нет.** Кэшировать
отрицательный ответ полезно: бот, перебирающий несуществующие ID, иначе
проходит сквозь кэш в базу. Кэшировать временный сбой вредно: сервис
поднялся через секунду, а мы ещё минуту отдаём ошибку. Различаем через
`errors.Is(err, ErrNotFound)` — источник может обернуть его как угодно.

**Удалённое не воскрешать.** Если источник сказал «не найдено», старое
значение надо забыть: товар сняли с продажи, и показывать его «на всякий
случай» после следующего сбоя — ошибка. Запись о значении заменяется
записью о его отсутствии.

**Значение и ошибка одновременно.** В Go принято: если `err != nil`,
результат не смотрят. `*StaleError` — осознанное исключение, и поэтому
отдельный тип: вызывающий, который не знает о нём, обработает ошибку как
обычно (500), а знающий сделает `errors.As` и покажет старое с пометкой.
`Unwrap` сохраняет причину для логов и `errors.Is`.

**Мьютекс — не на время загрузки.** Под блокировкой только чтение и
запись мапы; сам `load` идёт без неё. После загрузки запись перечитывается:
её мог обновить параллельный `Get`. Цена — несколько одновременных
загрузок одного ключа; убирают её через singleflight.

**Что спросят дальше.** Singleflight для одинаковых ключей, фоновое
обновление до истечения ttl (stale-while-revalidate), ограничение
размера (LRU) и сколько максимум можно отдавать устаревшее.
