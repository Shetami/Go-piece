Программа печатает:

```
пустая корзина
false
```

Текст совпадает с `ErrEmpty`, а `errors.Is` говорит «не она». Отметьте
строку, в которой заложена поломка.

<Reveal>

Сломано в строке 12: `return errors.New("пустая корзина")`.

**Каждый вызов `errors.New` создаёт новую ошибку.** Он возвращает указатель
на свежую структуру `errorString`. Два указателя на разные структуры не
равны, даже если текст внутри одинаковый. `errors.Is` сравнивает через `==`,
текст его не интересует.

Сентинел-ошибка работает только тогда, когда её создают один раз, на уровне
пакета, и дальше возвращают *эту самую переменную*:

```go
return ErrEmpty
```

Или оборачивают её: `fmt.Errorf("checkout: %w", ErrEmpty)`.

**Почему так сделано.** Если бы ошибки сравнивались по тексту, любое
изменение сообщения ломало бы проверки, а две разные библиотеки с
сообщением «not found» считались бы одной ошибкой.

</Reveal>
