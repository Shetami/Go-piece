`readFile` не находит файл и возвращает ошибку. `lookupEnv` работает.
Ожидается, что `loadConfig` вернёт ошибку, а она печатает:

```
{Raw: Env:prod} <nil>
```

Отметьте строку, в которой потерялась ошибка.

<Reveal>

Ошибка теряется в строке 25: `cfg.Env, err = lookupEnv("APP_ENV")`.

**`err` одна на обе операции.** `readFile` положил в неё ошибку, но
проверки после этого нет — и следующий вызов перезаписал `err` своим
`nil`. Единственная проверка ниже видит только результат `lookupEnv`.

Компилятор не жалуется: переменная `err` используется, пусть и не та её
версия. `go vet` тоже молчит. Такое ловит `staticcheck` (SA4006 — «значение
присвоено и не использовано») и `ineffassign`.

**Как правильно** — проверять ошибку сразу после каждого вызова, до
следующего:

```go
data, err := readFile("app.yaml")
if err != nil {
	return Config{}, fmt.Errorf("конфиг: %w", err)
}
```

</Reveal>
