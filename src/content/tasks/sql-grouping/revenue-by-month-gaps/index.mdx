График выручки за первое полугодие 2024 года. В марте и мае продаж не было,
но на графике эти месяцы нужны — с нулём, иначе ось X поедет.

- колонки: `month` — первое число месяца, тип `date`; `revenue`;
- ровно шесть строк, с января по июнь;
- порядок: по `month`.

<Reveal>

```sql
SELECT m.month::date AS month, coalesce(sum(s.amount), 0) AS revenue
FROM generate_series(date '2024-01-01', date '2024-06-01', interval '1 month') AS m(month)
LEFT JOIN sales s ON date_trunc('month', s.sold_at) = m.month
GROUP BY m.month
ORDER BY m.month;
```

**`GROUP BY` группирует то, что есть, и не создаёт месяцы из ничего.** Раз
продаж в марте нет, нет и группы. Нужна сетка всех месяцев, к которой
продажи присоединяются через `LEFT JOIN`.

**`generate_series`** строит ряд дат с шагом. Возвращает `timestamp` — отсюда
приведение `::date` в выводе.

**`count` и `sum` после `LEFT JOIN`**: для пустого месяца `sum(s.amount)` —
`NULL`, поэтому `coalesce(..., 0)`.

**Июльская продажа** в сетку не попадает: сетка заодно ограничивает период.
На больших таблицах лучше дополнительно отфильтровать `sales` по диапазону
дат, чтобы индекс по `sold_at` отсёк лишнее до соединения.

</Reveal>
