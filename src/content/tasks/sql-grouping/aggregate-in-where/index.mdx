Нужны клиенты, у которых больше двух заказов, и сумма этих заказов. Запрос
падает:

```
aggregate functions are not allowed in WHERE
```

Почините. Ожидается:

```
Аня  | 3 | 1000
Вера | 4 |  550
```

<Reveal>

**`WHERE` работает до группировки, `HAVING` — после.** Логический порядок
выполнения: `FROM` → `WHERE` → `GROUP BY` → `HAVING` → `SELECT` →
`ORDER BY` → `LIMIT`. В момент `WHERE` групп ещё нет, и `count(*)` считать не
по чему.

```sql
GROUP BY customer
HAVING count(*) > 2
```

**Как выбирать между ними.** Условие на отдельную строку (`amount > 100`) —
в `WHERE`: строки отсеются до группировки, и работы меньше. Условие на
группу целиком (`count(*)`, `sum(...)`) — в `HAVING`.

**Из того же порядка следует:** псевдоним из `SELECT` нельзя использовать в
`WHERE` — `WHERE orders > 2` не сработает. В `ORDER BY` можно: он идёт
после `SELECT`.

</Reveal>
