`status` переводит ошибку в код ответа: таймаут — 504, отмена клиентом —
499. Программа печатает:

```
500
500
200
```

Почините. Ожидаемый вывод:

```
504 таймаут
499 клиент ушёл
200
```

<Reveal>

**`call` оборачивает ошибку контекста**, и это правильно: в логе видно, на
каком запросе всё кончилось. Но после обёртки `err` — это уже
`*fmt.wrapError`, а не `context.DeadlineExceeded`. Сравнение через `==`
видит только верхнее звено и не совпадает ни с чем.

**Как правильно** — `errors.Is`, он идёт по цепочке `Unwrap`:

```go
case errors.Is(err, context.DeadlineExceeded):
	return "504 таймаут"
case errors.Is(err, context.Canceled):
	return "499 клиент ушёл"
```

**Почему различать важно.** 504 — сервис не успел, это его проблема и
повод для алерта. 499 — клиент ушёл сам, считать это ошибкой сервиса
значит зря будить дежурного.

</Reveal>
