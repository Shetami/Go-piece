Сервис недоступен, и `callWithRetry` повторяет вызов. На всё про всё у
вызывающего 250 мс. Программа печатает пять попыток и

```
итог: попытки кончились
```

— уже после того, как вызывающий давно перестал ждать. Почините. Ожидаемый
вывод:

```
попытка 1
попытка 2
попытка 3
итог: context deadline exceeded
```

<Reveal>

**`time.Sleep` не знает о контексте.** Функция принимает `ctx` и ни разу на
него не смотрит. Дедлайн наступает на 250-й миллисекунде, посреди третьей
паузы, но `Sleep` досыпает своё, и цикл идёт дальше. Пять попыток, полсекунды
работы — вдвое дольше, чем разрешено.

**Как чинят** — ждать через `select`, который слышит отмену:

```go
select {
case <-ctx.Done():
	return ctx.Err()
case <-time.After(100 * time.Millisecond):
}
```

Если контекст отменили во время паузы, функция выходит сразу и честно
говорит почему: `context deadline exceeded`.

**Что ещё стоит сделать в настоящих повторах.** Передавать `ctx` в сам
`call`, чтобы прерывался и запрос, а не только паузы. Увеличивать паузу
экспоненциально и добавлять случайный разброс (jitter), чтобы тысяча
клиентов не повторяли синхронно. И не повторять ошибки, которые повтором
не лечатся, — `400 Bad Request` сколько ни повторяй, лучше не станет.

</Reveal>
