После того как наблюдатели стали не нужны, в программе должна остаться
одна горутина. Программа печатает:

```
горутин: 4
```

Почините. Ожидаемый вывод:

```
горутин: 1
```

<Reveal>

**`cancel` — единственный способ закрыть `Done()` у этого контекста.**
`context.WithCancel` возвращает контекст и функцию отмены. Отмену
выбросили в `_`. Родитель — `Background()`, который не отменяется никогда.
Значит, `ctx.Done()` не закроется, и горутина, которая его ждёт, будет
ждать до конца программы. Три вызова — три вечных горутины.

**`go vet` об этом знает**: проверка `lostcancel` пишет «the cancel function
returned by context.WithCancel should be called, not discarded». Кнопка
«Запустить» показывает это предупреждение.

**Как чинят** — не выбрасывать отмену, а отдать её тому, кто решает, когда
наблюдатель больше не нужен:

```go
func startWatcher(parent context.Context) (stop func()) {
	ctx, cancel := context.WithCancel(parent)
	go func() { <-ctx.Done() }()
	return cancel
}
```

**Даже если горутины нет**, отмену вызывать надо: дочерний контекст
регистрируется в родителе, и если родитель долгоживущий (контекст
сервера), незакрытые дети копятся в нём как утечка памяти.

</Reveal>
