`handle` при наличии токена кладёт пользователя в контекст и передаёт
контекст дальше. Программа печатает:

```
авторизован: user:anna
process: аноним
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 22: `ctx := context.WithValue(...)`.

**`:=` внутри блока объявляет новую переменную.** Новая `ctx` живёт до
закрывающей скобки `if` и затеняет параметр. Внутри блока всё выглядит
правильно — поэтому проверка там и печатает пользователя. После `if` снова
виден параметр — исходный контекст без значения.

Компилятор не возражает: новая `ctx` используется в `Println`. Не будь этой
строки — была бы ошибка «declared and not used», и баг нашёлся бы сам.

**Как правильно** — присваивание: `ctx = context.WithValue(...)`.
Контексты неизменяемы, каждый `With...` возвращает новый — и его надо
положить туда, откуда его возьмут дальше.

</Reveal>
