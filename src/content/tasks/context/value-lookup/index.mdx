Ключ — свой тип `key` на основе `string`. В родительский контекст кладут
«Аню», в дочерний по тому же ключу — «Борю». Потом ищут по ключу своего
типа, по голой строке `"user"` и по ключу, которого нет.

Напишите весь вывод программы.

<Reveal>

**`WithValue` не меняет контекст, а создаёт новый поверх.** Контексты
неизменяемы. `child` — это узел с одной парой ключ-значение и ссылкой на
`ctx`. `Value` идёт от узла вверх по родителям и возвращает первое
совпадение.

- `ctx.Value` видит только «Аню» — про дочерний узел родитель не знает.
- `child.Value` находит «Борю» на своём узле и дальше не идёт.

**Ключи сравниваются через `==`, вместе с типом.** `"user"` — это `string`,
а в контексте лежит `key("user")`. Типы разные — не равны, `nil`. Именно для
этого и заводят свой тип ключа: чужой пакет со строкой `"user"` не сможет ни
прочитать, ни затереть ваше значение.

Отсутствующий ключ — `nil`.

Итого:

```
Аня Боря
<nil>
<nil>
```

**Про скорость.** Поиск линейный: каждый `WithValue` — ещё один узел в
цепочке. Для пары значений запроса (trace id, пользователь) это не важно, но
класть в контекст десятки значений или использовать его вместо параметров
функции — плохая идея и по скорости, и по читаемости.

</Reveal>
