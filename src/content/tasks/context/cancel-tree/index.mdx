От `parent` отпочкованы два дочерних контекста. Сначала отменяют `child`,
потом — `parent`, и после каждого шага смотрят на `Err()`.

Напишите весь вывод программы.

<Reveal>

**Отмена распространяется от родителя к детям, но не обратно.** Отмена
`child` закрывает его `Done` и ставит `Err`, но родитель о ней не узнаёт:
`parent.Err()` — `nil`. Иначе один отменённый подзапрос обрушивал бы весь
запрос.

**Отмена родителя отменяет всё поддерево.** `cancelParent()` проходит по
всем зарегистрированным детям. `child2` получает ту же ошибку
`context canceled`, его `Done` закрыт, чтение проходит сразу.

Итого:

```
<nil> context canceled
context canceled context canceled
done закрыт
```

**Зачем тогда `defer cancel2()`**, если родитель и так всё отменит? Родитель
держит ссылку на каждого ребёнка, пока тот не отменён. Если родитель
долгоживущий (например, контекст сервера), а дети создаются на каждый
запрос, без `cancel` они копятся в памяти. `go vet` предупреждает о
потерянной функции отмены (проверка `lostcancel`).

</Reveal>
