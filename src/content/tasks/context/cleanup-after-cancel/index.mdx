Запрос отменён, и именно поэтому надо записать аудит — с идентификатором
запроса из контекста. Программа печатает:

```
аудит не записан: context canceled
```

Почините. Ожидаемый вывод:

```
аудит [r42]: запрос прерван
```

<Reveal>

**Отменённый контекст отменён для всех, кто его получит.** `saveAudit`
честно уважает контекст и сразу возвращает `ctx.Err()`. Мы передали ей
контекст запроса, который уже отменён, — значит, она ничего не делает.

Просто передать `context.Background()` — плохая починка: пропадёт
идентификатор запроса и всё остальное, что лежит в контексте (трассировка,
пользователь).

**Как чинят** — `context.WithoutCancel` (Go 1.21):

```go
saveAudit(context.WithoutCancel(ctx), "запрос прерван")
```

Он сохраняет значения родителя, но не наследует ни отмену, ни дедлайн:
`Done()` у него — `nil`, `Err()` — всегда `nil`.

**Не забудьте про свой таймаут.** Контекст без отмены живёт вечно. Если
запись аудита может зависнуть, ограничьте её отдельно:
`context.WithTimeout(context.WithoutCancel(ctx), time.Second)`. Тот же
приём нужен для корректного завершения: в обработчике сигнала основной
контекст уже отменён, а на сброс буферов и закрытие соединений нужно ещё
немного времени.

</Reveal>
