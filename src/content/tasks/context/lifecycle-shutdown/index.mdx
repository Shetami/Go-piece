`main` сервиса поднимает компоненты: пул базы, кэш, консьюмер, HTTP.
Останавливать их нужно в обратном порядке — сначала перестать принимать
трафик, потом дочитать очередь, и только потом закрыть базу. Если старт
упал посередине, уже поднятое надо аккуратно закрыть. Реализуйте `Start`
и `Stop`.

Что проверяют скрытые тесты:

- запуск по порядку, остановка в обратном; повторный `Stop` ничего не
  делает;
- сбой старта третьего — откатывается только то, что успело запуститься,
  ошибка с именем упавшего;
- старт упал из-за отмены своего `ctx` — откат всё равно получает живой
  контекст;
- при остановке: один компонент вернул ошибку, двое зависли — каждый
  получает свой свежий таймаут, остальные всё равно останавливаются, а
  итоговая ошибка содержит все три с именами.

<Reveal>

```go
func (a *App) Start(ctx context.Context) error {
	for i, c := range a.Components {
		if err := c.Start(ctx); err != nil {
			startErr := fmt.Errorf("start %s: %w", c.Name, err)
			a.started = i
			return errors.Join(startErr, a.Stop(context.WithoutCancel(ctx)))
		}
	}
	a.started = len(a.Components)
	return nil
}

func (a *App) Stop(ctx context.Context) error {
	var errs []error
	for i := a.started - 1; i >= 0; i-- {
		c := a.Components[i]
		if err := a.stopOne(ctx, c); err != nil {
			errs = append(errs, fmt.Errorf("stop %s: %w", c.Name, err))
		}
	}
	a.started = 0
	return errors.Join(errs...)
}

func (a *App) stopOne(ctx context.Context, c Component) error {
	sctx, cancel := context.WithTimeout(ctx, a.StopTimeout)
	defer cancel()
	return c.Stop(sctx)
}
```

**Обратный порядок — как `defer`.** То, что поднято последним, зависит
от поднятого раньше: HTTP-обработчики ходят в кэш и базу. Закрыть базу
первой — значит уронить запросы, которые ещё дорабатывают.

**Один общий таймаут на все `Stop` — классическая ошибка.** Если первый
компонент завис и съел весь бюджет, остальные получат уже истёкший
контекст и не успеют даже сбросить буферы. Отдельный `WithTimeout` на
каждый ограничивает ущерб одним компонентом, а общий `ctx` сверху
по-прежнему задаёт потолок.

**Откат после отмены — через `WithoutCancel`.** Старт часто падает
именно потому, что отменили его контекст (SIGTERM во время запуска).
Если передать этот же `ctx` в откат, все `Stop` получат отменённый
контекст и ничего не закроют. `WithoutCancel` сохраняет значения
(логгер, trace), а срок задаёт `StopTimeout`.

**Ошибки не прерывают остановку.** Остановка — это «сделать максимум»:
соединения с базой надо закрыть, даже если консьюмер не смог
закоммитить смещения. `errors.Join` отдаёт все сбои разом, и каждый
находится через `errors.Is`.

**Что спросят дальше:** как запускать независимые компоненты
параллельно (граф зависимостей, как в `uber-go/fx`), и почему HTTP-сервер
при остановке должен сначала провалить readiness-пробу и подождать,
пока балансировщик уберёт под из ротации.
