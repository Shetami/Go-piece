Напишите `Sleep(ctx, d)`: пауза на `d`, которая прерывается отменой
контекста.

Что проверяют скрытые тесты:

- без отмены — ждёт не меньше `d` и возвращает `nil`;
- контекст истёк во время паузы — возврат сразу, `DeadlineExceeded`;
- уже отменённый контекст — возврат сразу, `Canceled`.

<Reveal>

```go
func Sleep(ctx context.Context, d time.Duration) error {
	t := time.NewTimer(d)
	defer t.Stop()
	select {
	case <-t.C:
		return nil
	case <-ctx.Done():
		return ctx.Err()
	}
}
```

**`select` на двух событиях** — единственный способ ждать «что случится
раньше». `time.Sleep` блокирует горутину целиком, и ничто снаружи его не
прервёт.

**`NewTimer` и `Stop` вместо `time.After`.** `time.After(time.Hour)` при
раннем выходе по отмене оставил бы таймер жить до срабатывания. До Go 1.23
это была утечка памяти на час; сейчас неиспользуемые таймеры собираются
сборщиком мусора, но `Stop` всё равно яснее выражает намерение и
освобождает таймер сразу.

**Где пригодится.** Паузы между повторами, опрос с интервалом, ожидание в
тестах. Любой `time.Sleep` в коде, у которого есть контекст, — повод
заменить его на такую функцию.

</Reveal>
