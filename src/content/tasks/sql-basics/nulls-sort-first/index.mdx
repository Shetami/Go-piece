Хотели показать трёх пользователей, которые заходили на сайт позже всех.
У двоих `last_login` пуст — они ни разу не входили.

Что вернёт запрос? Три строки, в каждой имя и дата через `|`, пустое значение
пишите как `NULL`.

<Reveal>

```
Боря | NULL
Даша | NULL
Вера | 2024-06-10
```

**В Postgres `NULL` при сортировке больше любого значения.** По возрастанию
`NULL` оказываются в конце, по убыванию — в начале. Поэтому «самые недавние»
открываются теми, кто не заходил никогда. (В MySQL и SQL Server наоборот:
там `NULL` меньше всего. Переносимым такое поведение не назовёшь.)

**Как чинят** — сказать явно:

```sql
ORDER BY last_login DESC NULLS LAST, name
```

или отфильтровать: `WHERE last_login IS NOT NULL`.

**Зачем `, name` в сортировке.** У Бори и Даши одинаковый ключ — `NULL`, и
без второго ключа их порядок не определён. С `LIMIT` это превращается в
«плавающую» выдачу: от запуска к запуску в тройку может попадать разный
человек.

</Reveal>
