Напишите тело `SortedKeys`.

Что проверяют скрытые тесты:

- ключи-числа и ключи-строки по возрастанию;
- ключ своего типа `type userID int64`;
- пустая мапа.

<Reveal>

```go
func SortedKeys[K cmp.Ordered, V any](m map[K]V) []K {
	return slices.Sorted(maps.Keys(m))
}
```

**Итераторы из Go 1.23.** `maps.Keys` возвращает не слайс, а итератор
`iter.Seq[K]`. `slices.Sorted` собирает его в слайс и сортирует. До 1.23
писали цикл `for k := range m { keys = append(keys, k) }` и `slices.Sort`.
Оба ответа правильные; первый показывает, что вы следите за языком.

**`cmp.Ordered` и свои типы.** В `cmp.Ordered` все элементы с тильдой:
`~int | ~int8 | ... | ~string`. Поэтому `userID` с базовым `int64` проходит —
третий тест про это. Без тильд (`int | int64 | string`) он бы не
скомпилировался.

**Зачем вообще сортировать ключи.** Порядок обхода мапы случаен. Любой
вывод, который должен быть стабильным — отчёт, ключ кэша, подпись запроса,
тестовые ожидания, — строится по отсортированным ключам.

</Reveal>
