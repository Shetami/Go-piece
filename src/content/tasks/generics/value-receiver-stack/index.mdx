Программа кладёт в стек две строки и печатает:

```
в стеке: 0
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 9: `func (s Stack[T]) Push(v T)` — получатель по
значению.

**Метод на значении получает копию структуры.** `s.Push("a")` копирует
`Stack` — то есть заголовок слайса `items` — в параметр-получатель.
`append` создаёт новый массив и присваивает новый заголовок полю *копии*.
Копия умирает в конце метода, оригинал остаётся пустым.

Дженерики здесь ни при чём: с `Stack` без параметров типа было бы то же
самое. Но в обобщённом коде такие ошибки встречаются чаще — его пишут «по
образцу» и копируют сигнатуры.

**Как правильно** — указатель в получателе:

```go
func (s *Stack[T]) Push(v T)
```

**Правило.** Если хоть один метод типа меняет его состояние, делайте все
методы на указателе. Смесь из значений и указателей путает и читателя, и
набор методов для интерфейсов: `Stack[T]` без звёздочки не реализовал бы
интерфейс с `Push`, если бы `Push` был на указателе.

</Reveal>
