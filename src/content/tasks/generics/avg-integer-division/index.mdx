`Avg` делит сумму на количество. Её вызывают с целыми, с дробными и с
`int8`. Последней строкой — просто сумма `0.1` и `0.2`.

Напишите весь вывод программы.

<Reveal>

**Тип выводится из аргументов.** `Avg(1, 2)` — обе константы целые,
`T = int`. `Avg(1.0, 2)` — одна дробная, и нетипизированные константы сводятся к
самому «широкому» виду: `T = float64`.

**Операции внутри — операции конкретного типа.** Для `int` деление
целочисленное: `3 / 2 = 1`. Для `float64` — `1.5`.

**`int8` переполняется молча.** `100 + 100 = 200` в `int8` не помещается и
заворачивается в `-56`. Деление на 2 даёт `-28`. Паники нет, компилятор
не видит проблемы — константы 100 в `int8` помещаются, переполнение
случается уже при сложении во время работы.

**Сумма `0.1 + 0.2`** — классика двоичной дроби.

Итого:

```
1
1.5
-28
0.30000000000000004
```

**Вывод.** Дженерик не делает арифметику «общей» — он подставляет тип. Если
для среднего важна дробная часть, результат должен быть `float64` независимо
от `T`: `float64(Sum(xs...)) / float64(len(xs))`. А накапливать сумму узких
типов лучше в широком.

</Reveal>
