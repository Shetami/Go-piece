`Pair` — обобщённая структура. `Zero` возвращает нулевое значение любого
типа. Печатаем `%T` инстанцированного типа, структуру с пустым слайсом и
нулевые значения для строки, указателя, слайса и самой `Pair`.

Напишите весь вывод программы.

<Reveal>

**Инстанцированный тип получает имя с аргументами.** `%T` печатает
`main.Pair[string,int]` — без пробела после запятой. В рефлексии это
отдельный тип: `Pair[string,int]` и `Pair[string,bool]` не имеют общего
«родителя».

**`%+v` печатает имена полей.** `Val` — `nil`-слайс, печатается как `[]`.

**`var z T` — единственный универсальный способ получить нулевое значение.**
Написать `return nil` нельзя: `T` может быть `int`. Для строки ноль — `""`
(`%q` показывает кавычки), для указателя и слайса — `nil`.

**Нулевая `Pair[int, bool]`** — структура из нулевых полей: `{0 false}`.

Итого:

```
main.Pair[string,int]
{Key:a Val:[]}
"" true true
{0 false}
```

**Что спросят следом.** Как проверить, что `T` равен нулю: для
`comparable` — `x == zero`, а для `any` — только через `reflect.ValueOf(x).IsZero()`
или отдельным параметром. Потому что `==` у `any`-параметра типа
использовать нельзя.

</Reveal>
