Допишите `BiMap`. Пример — сопоставление id пользователя и его почты:
по id нужна почта для рассылки, по почте — id для входа. Почта
уникальна, и при её смене или передаче другому пользователю старые
связи обязаны исчезнуть.

Что проверяют скрытые тесты:

- повторный `Put` той же пары ничего не меняет, поиск в обе стороны
  работает;
- пользователь сменил почту — старый адрес больше никуда не ведёт; адрес
  забрал другой — у первого его нет;
- `Put("a", "y")` при `a→x` и `b→y` оставляет ровно одну пару;
- `Delete` чистит обе стороны и возвращает `false` для отсутствующего;
- `Inverse()` — это представление: `Put` через него виден в исходной, и
  наоборот.

```go
type BiMap[K, V comparable] struct {
	fwd map[K]V
	rev map[V]K
}

func (m *BiMap[K, V]) Put(k K, v V) {
	if old, ok := m.fwd[k]; ok {
		delete(m.rev, old)
	}
	if oldK, ok := m.rev[v]; ok {
		delete(m.fwd, oldK)
	}
	m.fwd[k] = v
	m.rev[v] = k
}

func (m *BiMap[K, V]) Delete(k K) bool {
	v, ok := m.fwd[k]
	if !ok {
		return false
	}
	delete(m.fwd, k)
	delete(m.rev, v)
	return true
}

func (m *BiMap[K, V]) Inverse() *BiMap[V, K] {
	return &BiMap[V, K]{fwd: m.rev, rev: m.fwd}
}
```

`Get`, `GetKey` и `Len` — прямые обращения к `fwd`, `rev` и `len(fwd)`.

**Два параметра, оба `comparable`.** Значение тоже становится ключом
мапы — обратной, поэтому ограничение у `V` такое же, как у `K`. Типы
могут совпадать (`BiMap[string, string]`), и всё продолжает работать:
мапы разные.

**Инвариант держится на двух удалениях.** Наивный `Put` пишет в обе
мапы и оставляет мусор: у `rev` остаётся старая почта пользователя, а у
`fwd` — пользователь, чью почту забрали. После такого `GetKey` по
старому адресу пускает в чужой аккаунт. Удалять надо и старое значение
ключа, и старый ключ значения — в случае `a→x, b→y, Put(a, y)` это две
разные пары.

**`Inverse` — перестановка параметров типа.** `BiMap[V, K]` с теми же
двумя мапами, поменянными местами, — корректная биекция в обратную
сторону без копирования. Поэтому здесь конструктор обязателен: если
создавать мапы лениво при первом `Put`, представление, взятое у пустой
`BiMap`, осталось бы с собственными `nil`-мапами и разошлось с исходной.

**Что спросят дальше:** как сделать `BiMap` безопасной для горутин
(один мьютекс на обе мапы — иначе инвариант виден нарушенным между
двумя записями), чем отличается `Put` от «вставить, только если обе
стороны свободны» (`TryPut`, который возвращает ошибку конфликта) и где
такое встречается (кодировщики словарей, короткие ссылки).
