Допишите `Future[T]`, `Async`, `Await`, `Done` и `Then`. В Go обычно
хватает каналов, но этот примитив удобен, когда один запрос нужен
нескольким потребителям, например конфиг, который грузится при старте,
а ждут его все обработчики.

Что проверяют скрытые тесты:

- десять горутин одновременно ждут один `Future` — все получают значение,
  а задача выполнилась один раз; после этого `Done()` закрыт;
- `Await` с отменённым контекстом сразу возвращает `context.Canceled`, но
  задача не пропадает: следующий `Await` получает её результат;
- `Then` не блокирует вызывающего, меняет тип (`int` → `string` →
  `int`) и собирается в цепочку;
- если `src` вернул ошибку, `g` не вызывается, а ошибка доходит до конца
  цепочки;
- паника внутри задачи не роняет тесты, а становится ошибкой.

<Reveal>

```go
type Future[T any] struct {
	done chan struct{}
	val  T
	err  error
}

func Async[T any](f func() (T, error)) *Future[T] {
	fu := &Future[T]{done: make(chan struct{})}
	go func() {
		defer close(fu.done)
		defer func() {
			if r := recover(); r != nil {
				fu.err = fmt.Errorf("panic: %v", r)
			}
		}()
		fu.val, fu.err = f()
	}()
	return fu
}

func (fu *Future[T]) Done() <-chan struct{} { return fu.done }

func (fu *Future[T]) Await(ctx context.Context) (T, error) {
	select {
	case <-fu.done:
		return fu.val, fu.err
	case <-ctx.Done():
		var zero T
		return zero, ctx.Err()
	}
}

func Then[T, U any](src *Future[T], g func(T) (U, error)) *Future[U] {
	return Async(func() (U, error) {
		v, err := src.Await(context.Background())
		if err != nil {
			var zero U
			return zero, err
		}
		return g(v)
	})
}
```

**Закрытие канала — широковещательное событие.** Первая мысль —
`result chan T` с буфером 1, но значение из канала достаётся одному
читателю, остальные девять зависнут навсегда. Отменённый `Await` тоже
может успеть «съесть» результат. `close(done)` видят все и сколько угодно
раз, а само значение лежит в полях.

**Читать поля без мьютекса безопасно** благодаря модели памяти: запись в
`val`/`err` происходит до `close`, а `close` — до того, как кто-то
получил из канала. Поэтому гонки нет, `-race` молчит.

**Порядок `defer` важен.** Они выполняются в обратном порядке: сначала
`recover` записывает ошибку, потом `close` её публикует. Если поменять их
местами, ждущие увидят `nil`-ошибку от упавшей задачи. Без `recover`
паника в чужой горутине роняет весь процесс.

**`Then` — функция, а не метод.** У методов в Go не бывает собственных
параметров типа, поэтому `fu.Then[U](g)` написать нельзя: `U` не входит в
`Future[T]`. Так устроены и `slices`, и `maps` — всё, что меняет тип,
вынесено в функции пакета.

**Что спросят дальше:** как отменить саму задачу (передать `ctx` в `f`),
как сделать `All`/`Any` для нескольких `Future` и почему в идиоматичном Go
чаще пишут `errgroup` и каналы, чем промисы.
