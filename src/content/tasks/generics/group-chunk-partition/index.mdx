Допишите `GroupBy`, `Chunk` и `Partition`. Их зовут, например, чтобы
разложить заказы по городам для отчёта и отправить их в API пачками.

Что проверяют скрытые тесты:

- ключи `GroupBy` идут в порядке первого появления — и так на каждом из
  двадцати запусков; внутри группы порядок исходный;
- `GroupBy` от пустого входа возвращает мапу, в которую можно писать;
- `Chunk` режет с коротким хвостом; пустой вход и `size <= 0` → `nil`;
- `append` к первому куску не меняет второй кусок и исходный слайс;
- `Partition` возвращает обе части по порядку и не меняет вход.

<Reveal>

```go
func GroupBy[T any, K comparable](items []T, key func(T) K) (keys []K, groups map[K][]T) {
	groups = make(map[K][]T)
	for _, v := range items {
		k := key(v)
		if _, seen := groups[k]; !seen {
			keys = append(keys, k)
		}
		groups[k] = append(groups[k], v)
	}
	return keys, groups
}

func Chunk[T any](items []T, size int) [][]T {
	if size <= 0 || len(items) == 0 {
		return nil
	}
	out := make([][]T, 0, (len(items)+size-1)/size)
	for len(items) > 0 {
		n := min(size, len(items))
		out = append(out, items[:n:n])
		items = items[n:]
	}
	return out
}

func Partition[T any](items []T, pred func(T) bool) (yes, no []T) {
	for _, v := range items {
		if pred(v) {
			yes = append(yes, v)
		} else {
			no = append(no, v)
		}
	}
	return yes, no
}
```

**Два параметра типа в `GroupBy`.** Ключ должен быть `comparable`, чтобы
стать ключом мапы, а на элементы ограничений нет — `any`. Оба выводятся
из аргументов, явно их никто не пишет.

**Порядок ключей нужно хранить самому.** `range` по мапе в Go намеренно
случайный, поэтому отчёт, построенный обходом `groups`, будет каждый раз
в другом порядке. Отдельный слайс `keys` фиксирует порядок первого
появления.

**`items[:n:n]` — полное выражение среза.** Кусок `items[:n]` делит
массив с исходным слайсом, и его `cap` тянется до конца `items`. Тогда
`append` к нему пишет прямо в начало следующего куска. Ограничив `cap`,
мы заставляем `append` скопировать данные в новый массив.

**Фильтр на месте через `items[:0]` здесь не годится.** Приём
`out := items[:0]` экономит память, но переписывает вход — а вызывающий
его ещё использует. В общей библиотеке функция не должна менять
аргументы, если это не написано в контракте.

**Что спросят дальше:** есть ли это в стандартной библиотеке (есть
`slices.Chunk` — итератор с той же защитой через `cap`, а `GroupBy` нет),
и как сделать `GroupBy` без промежуточной мапы для отсортированного входа.
