Программа не компилируется:

```
cannot use nil as T value in return statement
```

Почините. Ожидаемый вывод:

```
0 false
го true
```

<Reveal>

**`nil` — нулевое значение только для некоторых типов.** Указатели, слайсы,
мапы, каналы, функции, интерфейсы. У `int` нуль — `0`, у `string` — `""`, у
структуры — структура из нулевых полей. `T` может оказаться любым из них,
поэтому `nil` в роли `T` не компилируется.

**Как чинят** — объявить переменную и вернуть её:

```go
var zero T
return zero, false
```

С Go 1.18 это единственный универсальный способ получить нулевое значение
параметра типа. Иногда пишут `*new(T)` — то же самое в одну строку, но
читается хуже.

**Про второе значение.** `bool` рядом с результатом здесь обязателен. Без
него вызывающий не отличит «слайс пуст» от «первый элемент равен нулю» — та
же ловушка, что с мапой без `ok`.

</Reveal>
