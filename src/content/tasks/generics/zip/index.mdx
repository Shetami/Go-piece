Напишите тело `Zip`: пары из элементов с одинаковыми индексами, длина — по
короткому слайсу.

Что проверяют скрытые тесты:

- `Zip([a b], [1 2])` → `[{a 1} {b 2}]`;
- слайсы разной длины — по короткому, в обе стороны;
- пустой вход — пустой результат.

<Reveal>

```go
func Zip[A, B any](as []A, bs []B) []Pair[A, B] {
	n := min(len(as), len(bs))
	out := make([]Pair[A, B], n)
	for i := range n {
		out[i] = Pair[A, B]{as[i], bs[i]}
	}
	return out
}
```

**Обобщённый тип внутри обобщённой функции.** `Pair[A, B]` — тип,
инстанцированный параметрами функции. Писать аргументы типа приходится
явно и в `make`, и в литерале: вывод типов работает для вызовов функций, а
не для составных литералов.

**Сравнение `Pair` через `==`** в тестах работает, потому что при
`A = int`, `B = bool` структура сравнима. Для `Pair[[]int, int]` то же
выражение не скомпилировалось бы.

**Длина заранее известна** — поэтому `make` с длиной и запись по индексу,
без `append`. `for i := range n` — цикл по целому числу (Go 1.22).

</Reveal>
