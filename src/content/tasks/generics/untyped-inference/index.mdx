`Pick` принимает два аргумента одного типа `T` и возвращает второй. Типа
явно не указывают — его выводит компилятор.

Напишите весь вывод программы.

<Reveal>

**Если есть типизированный аргумент, он и задаёт `T`.** `n` — `int8`,
значит, `T = int8`, и константа `100` приводится к нему. `Celsius(36.6)` —
`T = Celsius`, а `2` становится `Celsius(2)`. Печатается как `2`: `%v` для
дробного без лишних нулей.

**Если все аргументы — нетипизированные константы**, с Go 1.21 компилятор
берёт самый «широкий» вид среди них, по возрастанию: целое, руна, дробное,
комплексное.
`1` и `2.5` — дробное, `T = float64`. `1` и `'a'` — руна, `T = rune`,
а `rune` — это `int32`. `'a'` печатается числом 97.

Итого:

```
float64 2.5
int32 97
int8 100
main.Celsius 2
```

**До Go 1.21** `Pick(1, 2.5)` не компилировался: компилятор брал тип
первой константы (`int`), и `2.5` в него не помещалось. Если на это
наталкиваетесь в старом коде — укажите тип явно: `Pick[float64](1, 2.5)`.

</Reveal>
