Сумма трёх сотен — 300 и для `int`, и для `int8`. Программа печатает:

```
300
44
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 11: `var total T`.

**Сумма копится в типе элементов, а не в типе результата.** Для `int8`
переменная `total` — тоже `int8`, её диапазон −128…127. `100 + 100`
переполняется уже на втором шаге: целые числа в Go при переполнении молча
заворачиваются по модулю 256. `300 mod 256 = 44`. Приведение к `int64` в
конце уже ничего не спасает — оно расширяет испорченное значение.

Паники нет: переполнение целых в Go — не ошибка, а определённое поведение.

**Как правильно** — копить в широком типе с самого начала:

```go
var total int64
for _, x := range xs {
	total += int64(x)
}
```

`int64(x)` компилируется для любого `T` из набора: все они целые.

**Вывод про дженерики.** Параметр типа описывает вход, а не то, что с ним
удобно делать внутри. Промежуточные значения выбирайте так же, как в
необобщённом коде: по диапазону, который им нужен.

</Reveal>
