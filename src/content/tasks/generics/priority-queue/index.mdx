Допишите `PQ[T]` без `container/heap`.

Что проверяют скрытые тесты:

- числа выходят по возрастанию;
- пустая очередь → нулевое значение и `false`;
- с `less`, сравнивающим «больше», это очередь на максимум — задачи с
  высшим приоритетом первыми, в том числе добавленные между `Pop`;
- две тысячи случайных `Push` и `Pop` вперемешку сверяются с сортировкой;
- 200 000 `Push` и столько же `Pop` — быстрее двух секунд.

<Reveal>

```go
type PQ[T any] struct {
	items []T
	less  func(a, b T) bool
}

func (q *PQ[T]) Push(v T) {
	q.items = append(q.items, v)
	i := len(q.items) - 1
	for i > 0 {
		p := (i - 1) / 2
		if !q.less(q.items[i], q.items[p]) {
			break
		}
		q.items[i], q.items[p] = q.items[p], q.items[i]
		i = p
	}
}

func (q *PQ[T]) Pop() (T, bool) {
	var zero T
	n := len(q.items)
	if n == 0 {
		return zero, false
	}
	top := q.items[0]
	q.items[0] = q.items[n-1]
	q.items[n-1] = zero
	q.items = q.items[:n-1]

	i, n := 0, n-1
	for {
		l, r, m := 2*i+1, 2*i+2, i
		if l < n && q.less(q.items[l], q.items[m]) {
			m = l
		}
		if r < n && q.less(q.items[r], q.items[m]) {
			m = r
		}
		if m == i {
			break
		}
		q.items[i], q.items[m] = q.items[m], q.items[i]
		i = m
	}
	return top, true
}
```

**Куча — дерево, уложенное в слайс.** У элемента `i` дети `2i+1` и
`2i+2`, родитель `(i-1)/2`. Свойство кучи — родитель не больше детей,
значит, минимум всегда в корне.

**`Push` — в конец и всплытие**, `Pop` — последний на место корня и
погружение к меньшему из детей. И то и другое — высота дерева, `O(log n)`.

**Погружаться надо к *меньшему* из детей** — иначе меньший окажется под
большим, и свойство кучи сломается. Случайный тест ловит именно это.

**`q.items[n-1] = zero`** — чтобы снятый элемент не жил в массиве за
длиной слайса, если в `T` есть указатели.

**`container/heap`** придуман до дженериков: он работает через интерфейс
с пятью методами и `any`. С параметром типа очередь получается
типизированной и без упаковки каждого элемента в интерфейс.
