`Sum` складывает свои аргументы. Ограничение `Number` разрешает `int`,
`float64` и все типы, построенные на них. Четыре вызова: целые литералы,
смешанные литералы, `Celsius` с литералом и явный `float64` без аргументов.

Напишите весь вывод программы.

<Reveal>

**Вывод типа по нетипизированным константам.** `Sum(1, 2, 3)` — все
аргументы нетипизированные целые, `T` становится `int` (тип по умолчанию):
`6`. `Sum(1.5, 2)` — одна константа дробная; с Go 1.21 при смешении
выбирается «наибольший» вид, `float64`: `3.5`.

**Типизированный аргумент задаёт `T`.** В `Sum(Celsius(10), 20)` первый
аргумент имеет тип `Celsius`, значит `T = Celsius`, а `20` приводится к
нему. Результат — `Celsius`, `%T` показывает полное имя: `main.Celsius`.

**Без тильды это бы не скомпилировалось.** `~float64` значит «любой тип,
у которого базовый тип `float64`». Если бы в ограничении было просто
`float64`, `Celsius` не прошёл бы: это другой тип, хоть и с тем же
представлением.

**Пустой вызов.** `Sum[float64]()` — тип указан явно, аргументов нет, цикл
не выполняется, возвращается нулевое значение: `0`.

Итого:

```
6
3.5
30 main.Celsius
0 float64
```

</Reveal>
