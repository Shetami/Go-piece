Каждый файл качается секунду, на каждый — своя горутина. Ожидается, что
три загрузки пойдут одновременно. Программа печатает:

```
скачано: 3 за 3s
```

Почините. Ожидаемый вывод:

```
скачано: 3 за 1s
```

<Reveal>

**`wg.Wait()` внутри цикла ждёт каждую горутину сразу после запуска.**
Запустили первую — дождались, запустили вторую — дождались. Горутины
есть, а параллельности нет: в каждый момент работает ровно одна.

**Как правильно** — сначала запустить все, потом ждать один раз:

```go
for _, f := range files {
	wg.Add(1)
	go func() { ... }()
}
wg.Wait()
```

**Такой баг не ломает результат** — только время. Поэтому его не ловят
тесты на корректность, а замечают по графику задержек. Если параллельный
код работает ровно в N раз дольше, чем одна задача, — первым делом ищите,
где он ждёт.

</Reveal>
