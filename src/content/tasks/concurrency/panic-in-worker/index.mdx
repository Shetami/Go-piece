Каждая горутина пишет результат в свою ячейку слайса. На элементе 3
функция `work` паникует, и программа падает:

```
panic: плохие данные
```

Почините: сбой одной горутины должен превращаться в сообщение об ошибке в
её ячейке, остальные результаты — сохраняться. Ожидаемый вывод:

```
[0 1 4 ошибка: плохие данные 16]
```

<Reveal>

**Неперехваченная паника в любой горутине завершает всю программу.** Не
горутину, а процесс целиком — со всеми остальными горутинами, без
выполнения их `defer`.

**`recover` работает только в той горутине, где случилась паника.** Поставить
`recover` в `main` бесполезно: у каждой горутины свой стек, и паника
раскручивает только его. Поэтому перехват нужен внутри самой горутины:

```go
go func() {
	defer wg.Done()
	defer func() {
		if r := recover(); r != nil {
			results[i] = fmt.Sprint("ошибка: ", r)
		}
	}()
	results[i] = fmt.Sprint(work(i))
}()
```

Порядок `defer` тут важен: `recover` объявлен вторым и выполнится первым,
до `wg.Done()`. Иначе `main` мог бы проснуться и прочитать ячейку раньше,
чем туда записали ошибку.

**Гонки нет:** каждая горутина пишет только в свою ячейку, а `main` читает
после `wg.Wait()`.

</Reveal>
