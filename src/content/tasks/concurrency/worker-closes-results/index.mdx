Сумма квадратов от 1 до 5 — 55. Программа ведёт себя по-разному от запуска к
запуску: то паникует с `send on closed channel` или `close of closed channel`,
то печатает сумму меньше 55.

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 14: `close(results)` внутри воркера.

**Канал закрывает тот, кто точно знает, что отправок больше не будет.** Один
воркер знает только про себя. Когда `jobs` закончился, первый же воркер
закрывает `results`, хотя остальные ещё могут держать в руках задачу. Дальше
возможны три исхода:

- второй воркер отправляет результат — `send on closed channel`;
- второй воркер тоже доходит до `close` — `close of closed channel`;
- `main` видит закрытие, выходит из `range` и печатает неполную сумму,
  а оставшиеся воркеры падают или зависают уже никому не видимые.

**Как правильно** — закрывать в одном месте, после всех воркеров:

```go
var wg sync.WaitGroup
for range 3 {
	wg.Go(func() {
		for j := range jobs {
			results <- j * j
		}
	})
}
go func() {
	wg.Wait()
	close(results)
}()
```

`close` в отдельной горутине, а не в `main` перед `range`, — иначе `main`
ждал бы воркеров, а воркеры ждали бы, пока `main` прочитает их результаты.

</Reveal>
