Напишите `FetchAll`: загрузить все адреса параллельно и собрать результат.
Успешные ответы — в карту, неудачи — в одну ошибку через `errors.Join`.
Контракт — в doc-комментарии заготовки.

Что проверяют скрытые тесты:

- загрузки действительно идут одновременно, а не по очереди;
- адрес, который встречается во входе несколько раз, загружается один раз;
- ошибка сохраняет исходную причину (`errors.Is`), а её текст не зависит
  от того, какая загрузка упала раньше по времени;
- в карте — только успешные ответы; на пустом входе — пустая карта, не `nil`.

<Reveal>

```go
func FetchAll(urls []string, fetch func(url string) (string, error)) (map[string]string, error) {
	var uniq []string
	seen := make(map[string]bool)
	for _, u := range urls {
		if !seen[u] {
			seen[u] = true
			uniq = append(uniq, u)
		}
	}

	bodies := make([]string, len(uniq))
	errs := make([]error, len(uniq))
	var wg sync.WaitGroup
	for i, u := range uniq {
		wg.Add(1)
		go func() {
			defer wg.Done()
			bodies[i], errs[i] = fetch(u)
		}()
	}
	wg.Wait()

	res := make(map[string]string)
	var failed []error
	for i, u := range uniq {
		if errs[i] != nil {
			failed = append(failed, fmt.Errorf("%s: %w", u, errs[i]))
			continue
		}
		res[u] = bodies[i]
	}
	return res, errors.Join(failed...)
}
```

**Дедупликация — до горутин, а не внутри них.** Если проверять «уже
качали?» в самой горутине, понадобится мьютекс вокруг карты, и всё равно
легко получить две загрузки одного адреса, пока первая ещё не записала
результат. Отфильтровать вход заранее — проще и надёжнее.

**Ячейка на горутину вместо мьютекса и канала.** Каждая горутина пишет в
`bodies[i]` и `errs[i]` — в свои элементы. Это не гонка: разные элементы
слайса — разные переменные. А писать в общую карту из горутин без мьютекса
нельзя — `concurrent map writes` роняет процесс.

**Детерминированный порядок ошибок.** Если собирать ошибки через канал в
порядке прихода, текст ошибки будет меняться от запуска к запуску — логи не
сгруппировать, тест не написать. Раскладка по индексам и финальный проход в
порядке входа дают стабильный результат бесплатно. `errors.Join` от пустого
списка возвращает `nil`, отдельная проверка не нужна.

**`%w`, а не `%v`.** Обёртка с `%w` сохраняет цепочку: вызывающий код
может спросить `errors.Is(err, ErrNotFound)` у объединённой ошибки.

**Что спросят дальше.** Ограничение числа одновременных загрузок (на
тысяче адресов — тысяча соединений), отмена через `context` и таймаут на
каждую загрузку. Всё это — семафор плюс `ctx` в сигнатуре `fetch`.
