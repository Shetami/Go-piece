`squares` считает квадраты параллельно. Программа печатает:

```
[16 9 4 1]
```

Все четыре квадрата есть, но задом наперёд. Почините. Ожидаемый вывод:

```
[1 4 9 16]
```

<Reveal>

**Канал отдаёт результаты в порядке готовности, а не запуска.** Горутины
работают параллельно, и первым в канал попадает тот, кто первым
закончил. Здесь `work` для больших чисел работает быстрее — отсюда
обратный порядок. В жизни порядок был бы просто случайным.

**Как чинят** — писать каждый результат в свою ячейку:

```go
res := make([]int, len(nums))
for i, n := range nums {
	wg.Go(func() { res[i] = work(n) })
}
wg.Wait()
```

Гонки нет: горутины пишут в разные элементы слайса, а `wg.Wait()` делает
все записи видимыми для вызывающего.

**Если нужен именно канал** (например, результаты надо обрабатывать по мере
готовности) — передавайте индекс вместе со значением: `chan struct{ i, v int }`,
а на приёме раскладывайте по `res[r.i]`.

</Reveal>
