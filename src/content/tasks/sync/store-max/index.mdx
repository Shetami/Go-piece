Напишите тело `StoreMax` без мьютексов. Нужно, например, для метрики
«пиковое число одновременных запросов».

Что проверяют скрытые тесты:

- меньшее и равное значение не записываются, большее — записывается;
  отрицательные числа тоже работают;
- 8 горутин по 1000 раз обновляют один максимум; итог всегда равен
  настоящему максимуму — ни одна запись не затирает большее значение.

<Reveal>

```go
func StoreMax(p *atomic.Int64, v int64) bool {
	for {
		cur := p.Load()
		if v <= cur {
			return false
		}
		if p.CompareAndSwap(cur, v) {
			return true
		}
	}
}
```

**`if v > p.Load() { p.Store(v) }` — гонка, хоть обе операции и
атомарные.** Между проверкой и записью другая горутина может записать
значение больше `v`, и `Store` его затрёт. Каждая операция атомарна, а
пара — нет.

**`CompareAndSwap(cur, v)` — «запиши v, если там всё ещё cur».** Если за
это время значение поменялось, CAS ничего не пишет и возвращает `false`.
Тогда перечитываем и проверяем заново: может, новое значение уже больше
нашего — и делать ничего не надо.

**Цикл не бесконечный** в разумном смысле: каждый провал CAS означает, что
кто-то другой успешно записал большее значение. Это lock-free
алгоритм — прогресс есть всегда, хотя отдельная горутина может
повторить несколько раз.

**В Go 1.23 для флагов появились `atomic.Int64.Or` и `And`**, но
максимума среди готовых операций нет — CAS-цикл остаётся стандартным
приёмом.

</Reveal>
