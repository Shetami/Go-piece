Реализуйте `SpinLock` — замок, который не усыпляет горутину, а крутится
в цикле `CompareAndSwap`, пока не захватит. В проде так почти не делают
(см. разбор), но на собеседовании это частый способ проверить, понимаете
ли вы CAS и что `sync.Mutex` делает под капотом.

Что проверяют скрытые тесты:

- восемь горутин по 2000 раз входят в критическую секцию: внутри никогда
  не бывает двоих, неатомарный счётчик досчитал до 16000, никто не завис;
- `TryLock` на свободном и занятом замке;
- `Unlock` открытого замка паникует с сообщением из контракта;
- `SpinLock` передают в `sync.NewCond` как `sync.Locker`, и ожидание на
  условии работает.

<Reveal>

```go
type SpinLock struct {
	locked atomic.Bool
}

func (l *SpinLock) Lock() {
	for !l.locked.CompareAndSwap(false, true) {
		runtime.Gosched()
	}
}

func (l *SpinLock) TryLock() bool {
	return l.locked.CompareAndSwap(false, true)
}

func (l *SpinLock) Unlock() {
	if !l.locked.Swap(false) {
		panic("unlock of unlocked SpinLock")
	}
}
```

**Почему CAS, а не `Load` + `Store`.** «Проверить, что свободно, потом
занять» — две операции, и между ними другая горутина успевает сделать то
же самое. Обе видят `false`, обе пишут `true`, обе в секции. CAS делает
проверку и запись одной неделимой инструкцией (`LOCK CMPXCHG` на x86).

**`Swap` в `Unlock`.** Он атомарно записывает `false` и возвращает старое
значение — так мы бесплатно ловим двойной `Unlock`. С простым `Store` ошибка
тихо сойдёт с рук, и следующий `Unlock` откроет чужой замок.

**`runtime.Gosched()` в цикле.** Держатель замка мог быть вытеснен с
процессора. Если ждущий крутится без уступки, он сжигает свой квант, пока
держатель стоит в очереди планировщика. `sync.Mutex` делает похоже, но
умнее: несколько коротких спинов (только на многоядерной машине и если
есть другие работающие P), потом горутина паркуется в очереди семафора и
не тратит CPU вообще.

**`sync.Locker` — всего два метода**, `Lock` и `Unlock`, поэтому
`sync.Cond` работает с любым замком. `Cond.Wait` сам отпускает замок перед
сном и берёт его снова после пробуждения.

**Что спросят дальше.** Почему спинлоки в Go почти не пишут? Горутина
может быть вытеснена, держа замок, и все ждущие будут крутиться впустую,
а честности нет — любая горутина может «перехватить» замок у долго
ждущей. `sync.Mutex` после 1 мс ожидания переходит в режим голодания и
отдаёт замок строго по очереди.
