На каждый счёт — горутина, которая под мьютексом счёта начисляет 10.
Программа печатает:

```
100
200
```

Почините. Ожидаемый вывод:

```
110
210
```

<Reveal>

**`range` по слайсу структур копирует каждый элемент в `acc`.** Горутина
берёт мьютекс *копии*, меняет баланс *копии* и отпускает мьютекс *копии*.
Всё корректно синхронизировано — только не с тем объектом. Слайс
`accounts` никто не трогал.

**`go vet` об этом предупреждает:**
`range var acc copies lock: main.Account contains sync.Mutex`. Структуру с мьютексом копировать нельзя
никогда — копия мьютекса ничего не защищает.

**Как правильно** — работать с элементом слайса через указатель:

```go
for i := range accounts {
	acc := &accounts[i]
	...
}
```

Или хранить указатели с самого начала: `[]*Account`. Для структур с
мьютексом это обычный выбор — их всё равно нельзя копировать.

</Reveal>
