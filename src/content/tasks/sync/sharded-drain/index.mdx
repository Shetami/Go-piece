Реализуйте `Counter`: счётчики по ключам, куда пишут сотни горутин, и
`Drain` — метод, которым экспортёр раз в несколько секунд забирает
накопленное и обнуляет счётчики. Чтобы все `Add` не стояли в очереди к
одному мьютексу, разложите ключи по шардам.

Что проверяют скрытые тесты (с детектором гонок):

- `Get` после `Drain` — ноль; повторный `Drain` без новых `Add` — пустая,
  но не `nil` мапа; изменения результата `Drain` не влияют на счётчик;
- восемь горутин непрерывно вызывают `Add`, а экспортёр в цикле вызывает
  `Drain`: сумма всех выгрузок равна числу прибавлений — ни одно не
  потеряно и не посчитано дважды.

<Reveal>

```go
type shard struct {
	mu sync.Mutex
	m  map[string]int64
}

type Counter struct {
	seed   maphash.Seed
	shards [shardCount]shard
}

func (c *Counter) shardFor(key string) *shard {
	return &c.shards[maphash.String(c.seed, key)%shardCount]
}

func (c *Counter) Add(key string, delta int64) {
	s := c.shardFor(key)
	s.mu.Lock()
	s.m[key] += delta
	s.mu.Unlock()
}

func (c *Counter) Drain() map[string]int64 {
	out := make(map[string]int64)
	for i := range c.shards {
		s := &c.shards[i]
		s.mu.Lock()
		old := s.m
		s.m = make(map[string]int64, len(old))
		s.mu.Unlock()
		for k, v := range old {
			out[k] = v
		}
	}
	return out
}
```

**Главная ловушка — «скопировать, потом очистить» двумя проходами.**
Между проходом копирования и проходом очистки писатели успевают прибавить
ещё, и `clear` стирает эти прибавления, которые ни в какую выгрузку не
попали. Даже в одном шарде «прочитать под блокировкой, отпустить, взять
снова и обнулить» — та же потеря обновления. Забрать и обнулить нужно за
один захват мьютекса.

**Подмена мапы вместо копирования под блокировкой.** Под мьютексом —
только обмен указателя на свежую мапу, это O(1). Копирование в результат
идёт уже без блокировки: старую мапу больше никто не видит. Писатели
ждут наносекунды, а не время обхода тысяч ключей.

**Шардирование.** Хеш ключа выбирает один из 16 шардов, у каждого свой
мьютекс, и `Add` по разным ключам почти не конкурируют. `hash/maphash` —
быстрый хеш стандартной библиотеки со случайным seed. Размер 16 — степень
двойки, остаток от деления компилятор превратит в маску. Если шарды
лежат в массиве вплотную, их мьютексы делят кэш-линию (false sharing) — в
горячих местах шард дополняют до 64 байт.

**Что спросят дальше.** Снимок разных шардов берётся в разные моменты —
`Drain` не атомарен по всему счётчику, только по каждому шарду. Для
метрик это не важно: прибавление попадёт в эту выгрузку или в следующую.
А если ключей немного и они известны заранее, быстрее всего —
`atomic.Int64` на ключ в неизменяемой мапе.
