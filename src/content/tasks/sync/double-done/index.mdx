Четыре горутины делают запросы, чётные кончаются ошибкой. Программа
падает:

```
panic: sync: negative WaitGroup counter
```

А если не падает — печатает не все строки. Почините. Ожидаемый вывод:

```
1: ok
2: ошибка
3: ok
4: ошибка
```

<Reveal>

**На пути с ошибкой `Done` вызывается дважды:** один раз явно перед
`return`, второй — отложенный. Каждая чётная горутина уменьшает счётчик
на два.

Отсюда оба симптома. Счётчик может дойти до нуля раньше времени — тогда
`wg.Wait()` вернётся, `main` закроет канал, и результат опоздавшей
горутины либо потеряется, либо уронит программу отправкой в закрытый
канал. А если счётчик уйдёт ниже нуля — `WaitGroup` паникует сразу.

**Как правильно** — `defer wg.Done()` первой строкой и больше нигде.
Ранние `return` тогда ничего не ломают.

**С Go 1.25 есть `wg.Go(func() { ... })`** — он сам делает `Add(1)` и
`Done()`, и перепутать их количество уже нельзя.

</Reveal>
