`Worker` читает задачи из `jobs`. `main` отправляет одну и останавливает
воркера. Программа падает:

```
fatal error: all goroutines are asleep - deadlock!
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 25: `w := &Worker{done: make(chan struct{})}` — канал
`jobs` не создан.

**Нулевое значение канала — `nil`.** Литерал структуры заполнил только
`done`, поле `jobs` осталось `nil`. А с `nil`-каналом всё блокируется
навсегда: и отправка, и чтение. `main` встаёт на `w.jobs <- "письмо"`,
воркер — на `range w.jobs`. Больше никого нет, рантайм видит, что все
спят, и падает.

Будь в программе ещё хоть одна живая горутина — HTTP-сервер, тикер, — не
было бы и падения. Всё просто молча висело бы.

**Как правильно** — конструктор, который создаёт все каналы:

```go
func NewWorker() *Worker {
	return &Worker{jobs: make(chan string), done: make(chan struct{})}
}
```

**Чем nil-канал полезен.** Та же блокировка навсегда — удобный способ
выключить ветку `select`. Но в поле структуры `nil`-канал почти всегда
означает «забыли `make`».

</Reveal>
