Программа печатает только `main закончил`, а шагов не видно — или видно
не все, как повезёт.

Почините: сначала три шага, потом сообщение `main`. Ожидаемый вывод:

```
шаг 1
шаг 2
шаг 3
main закончил
```

<Reveal>

**Когда `main` возвращается, программа завершается.** Сразу и целиком: без
ожидания остальных горутин, без их отложенных вызовов. `go func()` только
ставит горутину в очередь планировщика, а `main` печатает свою строку и
выходит раньше, чем горутина успела начать.

**Как чинят** — дождаться. Канал-сигнал:

```go
done := make(chan struct{})
go func() {
	defer close(done)
	...
}()
<-done
```

Или `sync.WaitGroup`, если горутин несколько.

**`time.Sleep` — не починка.** Пауза «на всякий случай» работает на
ноутбуке и перестаёт работать под нагрузкой, в CI, на медленной машине.
Порядок между горутинами задаётся только синхронизацией: каналами,
`WaitGroup`, мьютексами.

</Reveal>
