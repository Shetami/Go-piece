Сумма показаний `5 + 3 + 0 + 7` равна 15. Программа печатает:

```
сумма показаний: 8
```

Почините. Ожидаемый вывод:

```
сумма показаний: 15
```

<Reveal>

**Чтение из закрытого канала возвращает нулевое значение — но ноль
возвращает и открытый канал, если в него положили ноль.** Код проверяет
`v == 0` как признак закрытия. Нулевое показание датчика неотличимо от
закрытия, и цикл заканчивается на третьем значении.

**Как чинят.** Самое простое — `range`:

```go
for v := range readings {
	sum += v
}
```

Если нужна ручная форма (например, внутри `select`), — второе значение:

```go
v, ok := <-readings
if !ok {
	break // вот теперь канал действительно закрыт
}
```

**Правило.** Никаких «особых» значений в роли сигнала конца. Ноль, пустая
строка, `-1` рано или поздно окажутся настоящими данными. Конец потока в Go
сообщают закрытием канала.

</Reveal>
