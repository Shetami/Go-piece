Напишите `Mailbox[T]`. Так передают телеметрию, позицию курьера, прогресс
загрузки: если потребитель отстал, ему нужны свежие значения, а не очередь
из устаревших. И уж точно нельзя, чтобы медленный потребитель
останавливал того, кто пишет.

Что проверяют скрытые тесты:

- буфер на 3, в него положили `1..5` — `Push` вернул
  `false false false true true`, читается `3 4 5`, `Dropped` — 2;
- восемь писателей по 500 значений в буфер на 1 без единого читателя —
  никто не блокируется, выброшено ровно 3999;
- четыре писателя и параллельный читатель — никто не блокируется, и
  прочитано + выброшено + осталось в буфере = всё, что положили.

<Reveal>

```go
type Mailbox[T any] struct {
	ch      chan T
	mu      sync.Mutex
	dropped int
}

func NewMailbox[T any](capacity int) *Mailbox[T] {
	return &Mailbox[T]{ch: make(chan T, capacity)}
}

func (m *Mailbox[T]) Push(v T) (dropped bool) {
	m.mu.Lock()
	defer m.mu.Unlock()
	for {
		select {
		case m.ch <- v:
			return dropped
		default:
		}
		select {
		case <-m.ch:
			dropped = true
			m.dropped++
		default:
		}
	}
}

func (m *Mailbox[T]) C() <-chan T { return m.ch }

func (m *Mailbox[T]) Dropped() int {
	m.mu.Lock()
	defer m.mu.Unlock()
	return m.dropped
}
```

**Наивное `default: <-ch; ch <- v` блокируется.** Между неудачной
отправкой и `<-ch` читатель может забрать последнее значение — и `<-ch`
на пустом канале ждёт вечно. Поэтому выбрасывание — тоже неблокирующий
`select`, а всё вместе — цикл: не получилось выбросить, значит, место уже
освободил читатель.

**Мьютекс нужен между писателями, а не с читателем.** Без него писатель A
выбросил старое, писатель B тут же занял место, и `ch <- v` у A снова
упирается в полный буфер. Читатель мьютекс не берёт: он читает канал
напрямую, и это безопасно — канал сам синхронизирован.

**Счётчик выброшенного — обязательная часть.** Сброс данных без метрики —
это тихая потеря. В проде `Dropped` уходит в Prometheus, и по нему видно,
что потребитель не справляется.

**Что спросят дальше:** почему не кольцевой буфер на слайсе (можно, но
тогда читателю нужен свой сигнал «появились данные» и `select` с
контекстом делается сложнее) и как сделать вариант «выбрасывать новое» —
это просто `select` с `default` без второго шага.
