Два источника: `a` отдаёт 1 и 2, `b` — 10, оба потом закрываются. Цикл
читает их через `select` и, увидев закрытие, присваивает каналу `nil`.
Цикл крутится, пока хотя бы один канал не `nil`.

Напишите весь вывод программы.

<Reveal>

**Зачем обнулять.** Чтение из закрытого канала мгновенно возвращает
`ok == false`. Если оставить закрытый `a` в `select`, эта ветка будет готова
*всегда*, и цикл будет крутиться вхолостую, съедая процессор, пока не
закроется `b`. `nil`-канал в `select` не готов никогда — ветка выключается.

**Порядок значений случаен, результат — нет.** Какой канал `select` выберет
первым, не определено, но все три значения будут прочитаны: `1 + 2 + 10 = 13`.
Каждый канал закроется ровно один раз, и после каждого закрытия счётчик
растёт: `2`. Когда оба стали `nil`, условие цикла ложно — выход.

Итого:

```
13 2
```

**Это слияние (merge) без горутин.** Для фиксированного числа входов так
пишут `Merge` в одном цикле. Для произвольного — по горутине на вход и
`WaitGroup`, потому что в `select` число веток задаётся в коде (или через
`reflect.Select`, что медленно и неудобно).

</Reveal>
