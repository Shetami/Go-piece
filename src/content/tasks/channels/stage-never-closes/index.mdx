Генератор отдаёт числа, стадия `square` возводит их в квадрат, `main`
складывает. Все три квадрата до `main` доходят, но потом программа
падает:

```
fatal error: all goroutines are asleep - deadlock!
```

Почините. Ожидаемый вывод:

```
сумма квадратов: 14
```

<Reveal>

**Конец потока — это закрытие канала, и его надо передать дальше.**
`gen` закрывает свой выход, и `range in` в стадии `square` завершается.
Горутина стадии выходит — но свой канал `out` не закрывает. `main`
вычитал три значения и ждёт четвёртого или закрытия. Не дождётся: писать
в `out` больше некому, закрыть — тоже.

**Как чинят** — каждая стадия закрывает свой выход:

```go
go func() {
	defer close(out)
	for n := range in {
		out <- n * n
	}
}()
```

**Правило конвейера.** Стадия, которая создала канал и пишет в него, — его
владелец и единственная, кто его закрывает. `defer close(out)` в первой
строке горутины — привычка, которая спасает от этого бага в любой стадии.
А закрытие каскадом проходит весь конвейер: источник закрылся — каждая
следующая стадия закрывается за ним.

</Reveal>
