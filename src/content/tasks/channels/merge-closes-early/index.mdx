`merge` на каждый вход запускает горутину, которая перекладывает значения
в общий выход. Сумма всех чисел — 136. Программа печатает меньше, а
иногда падает:

```
panic: send on closed channel
```

Почините. Ожидаемый вывод:

```
сумма: 136
```

<Reveal>

**Выход закрывает каждая горутина, а закрыть его можно только один раз.**
Первая закончившая горутина закрывает `out`. Цикл `range` в `main` на
этом заканчивается — значения из остальных входов уже никто не прочтёт.
А остальные горутины либо пишут в закрытый канал, либо закрывают его
повторно — и то и другое паника. Успеет ли она случиться до выхода
`main`, зависит от планировщика.

**Как правильно** — писатели только пишут, закрывает координатор:

```go
var wg sync.WaitGroup
wg.Add(len(ins))
for _, in := range ins {
	go func() {
		defer wg.Done()
		for v := range in {
			out <- v
		}
	}()
}
go func() {
	wg.Wait()
	close(out)
}()
```

Координатор — отдельная горутина, иначе `merge` не вернула бы канал, пока
его никто не читает.

</Reveal>
