Поле — матрица из нулей и единиц: 1 — живая клетка, 0 — мёртвая. У каждой
клетки восемь соседей, включая диагональных. За краями поля клеток нет —
они считаются мёртвыми.

Напишите `Tick` — следующее поколение по правилам Конвея:

- живая клетка с двумя или тремя живыми соседями выживает, иначе умирает;
- мёртвая клетка с ровно тремя живыми соседями оживает.

Все клетки меняются *одновременно*: новое поколение считается целиком по
старому. Входная матрица меняться не должна.

Тесты — из открытого набора [Exercism](https://github.com/exercism/problem-specifications) (MIT).

<Reveal>

```go
func Tick(matrix [][]int) [][]int {
	next := make([][]int, len(matrix))
	for r, row := range matrix {
		next[r] = make([]int, len(row))
		for c, cell := range row {
			n := liveNeighbours(matrix, r, c)
			if n == 3 || (cell == 1 && n == 2) {
				next[r][c] = 1
			}
		}
	}
	return next
}

func liveNeighbours(m [][]int, r, c int) int {
	n := 0
	for dr := -1; dr <= 1; dr++ {
		for dc := -1; dc <= 1; dc++ {
			rr, cc := r+dr, c+dc
			if (dr != 0 || dc != 0) && rr >= 0 && rr < len(m) && cc >= 0 && cc < len(m[rr]) {
				n += m[rr][cc]
			}
		}
	}
	return n
}
```

**Новая матрица, а не правка на месте.** Если записать новое значение в
`matrix[r][c]` сразу, соседи справа и снизу посчитают уже изменённую клетку —
это не «одновременно». Отдельная `next` решает вопрос за O(n·m) памяти.

**Правила в одну строку.** «Выживает при 2–3, рождается при 3» сворачивается
в `n == 3 || (живая && n == 2)`: при трёх соседях клетка жива в любом случае.

**Продолжение на собеседовании — «а без лишней памяти?»** (LeetCode 289).
Кодируют оба состояния в одной клетке: бит 0 — текущее, бит 1 — следующее.
Соседей считают по `& 1`, в конце сдвигают всё на бит вправо.
