*Изограмма* — слово или фраза, в которой ни одна буква не встречается дважды:
`lumberjacks`, `background`, `six-year-old`.

Напишите `IsIsogram`. Правила:

- регистр не важен: в `Alphabet` буква *a* повторяется;
- пробелы и дефисы буквами не считаются и могут повторяться сколько угодно;
- пустая строка — изограмма.

Тесты — из открытого набора [Exercism](https://github.com/exercism/problem-specifications) (MIT).

<Reveal>

```go
func IsIsogram(phrase string) bool {
	seen := make(map[rune]bool)
	for _, r := range phrase {
		if !unicode.IsLetter(r) {
			continue
		}
		r = unicode.ToLower(r)
		if seen[r] {
			return false
		}
		seen[r] = true
	}
	return true
}
```

**Множество увиденного.** Один проход, на каждой букве — вопрос «уже было?».
O(n) по времени, память — по числу различных букв.

**`range` по строке отдаёт руны,** а не байты, поэтому решение не ломается на
не-ASCII. Индексация `phrase[i]` дала бы байты UTF-8, и кириллическая буква
превратилась бы в два «символа».

**Если алфавит известен заранее** — например, только латиница, — мапу можно
заменить битовой маской в `uint32`: `mask&(1<<(r-'a')) != 0`. Это любимое
продолжение вопроса на собеседовании.

</Reveal>
