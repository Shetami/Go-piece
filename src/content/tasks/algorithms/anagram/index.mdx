*Анаграмма* — слово из тех же букв в другом порядке: `listen` и `inlets`.

Напишите `Anagrams`: из `candidates` вернуть те, что являются анаграммами
`subject`.

- регистр не важен: `Orchestra` и `Carthorse` — анаграммы;
- в ответе — слова-кандидаты как есть, в исходном порядке и регистре;
- слово не анаграмма самого себя, в том числе в другом регистре: для `BANANA`
  ни `BANANA`, ни `banana` не подходят;
- каждая буква используется ровно столько раз, сколько встречается:
  `tapper` и `patter` — не анаграммы.

Слова бывают не только латиницей: тесты есть и на греческом.

Тесты — из открытого набора [Exercism](https://github.com/exercism/problem-specifications) (MIT).

<Reveal>

```go
func Anagrams(subject string, candidates []string) []string {
	lower := strings.ToLower(subject)
	key := sortedRunes(lower)
	var out []string
	for _, c := range candidates {
		cl := strings.ToLower(c)
		if cl != lower && sortedRunes(cl) == key {
			out = append(out, c)
		}
	}
	return out
}

func sortedRunes(s string) string {
	r := []rune(s)
	slices.Sort(r)
	return string(r)
}
```

**Канонический ключ.** У всех анаграмм одинаковый набор букв, а значит,
одинаковая отсортированная строка. Сравниваем ключи — O(k log k) на слово
длины k. Тот же ключ работает в задаче «сгруппируй анаграммы»: мапа
`ключ → слова`.

**Счётчик вместо сортировки** — O(k): `map[rune]int` или `[26]int` для
латиницы. Массив на 26 букв — самый быстрый вариант, но тесты с греческими
буквами его сломают. Хорошо спросить у интервьюера про алфавит до того, как
выбирать.

**Руны, а не байты.** Тест `a⬂` против `€a` подобран так, что байты UTF-8
у этих строк одни и те же, только в другом порядке. Сортировка байтов
объявила бы их анаграммами.

**Сумма кодов букв** как «хэш» не работает: `mass` и `last` дают одну и ту же
сумму — для этого в наборе и есть тест «identical checksum».
