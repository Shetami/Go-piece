Поле — слайс строк одинаковой длины: `*` — цветок, пробел — пустая клетка.
Напишите `Annotate`: в каждую пустую клетку поставить число цветов среди
восьми её соседей. Если цветов рядом нет, клетка остаётся пробелом.

```
" * * "        "1*3*1"
"  *  "   →    "13*31"
"  *  "        " 2*2 "
"     "        " 111 "
```

Бывают пустое поле, поле из одной строки, из одного столбца и поле без единой
пустой клетки.

Тесты — из открытого набора [Exercism](https://github.com/exercism/problem-specifications) (MIT).

<Reveal>

```go
func Annotate(garden []string) []string {
	out := make([]string, len(garden))
	for r, row := range garden {
		line := []byte(row)
		for c := range line {
			if line[c] == '*' {
				continue
			}
			n := 0
			for rr := r - 1; rr <= r+1; rr++ {
				for cc := c - 1; cc <= c+1; cc++ {
					if rr >= 0 && rr < len(garden) && cc >= 0 && cc < len(garden[rr]) && garden[rr][cc] == '*' {
						n++
					}
				}
			}
			if n > 0 {
				line[c] = byte('0' + n)
			}
		}
		out[r] = string(line)
	}
	return out
}
```

**Строку не поменять на месте.** `row[c] = '1'` не скомпилируется: строки
в Go неизменяемы. Строку копируют в `[]byte`, правят и собирают обратно.
Поле — только ASCII, так что байт и есть клетка.

**Соседей считаем по исходному полю.** Цифры пишутся в копию `line`, а цветы
ищутся в `garden` — поэтому уже проставленная цифра ничего не испортит. Сама
клетка в квадрат 3×3 тоже попадает, но она пустая и цветком не считается.

**Больше 8 не бывает,** поэтому `'0' + n` — всегда одна цифра.

**Другой порядок обхода** — от каждого цветка прибавить единицу восьми соседям —
быстрее, когда цветов мало. Ответ тот же.

</Reveal>
