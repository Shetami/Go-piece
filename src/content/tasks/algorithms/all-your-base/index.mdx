Число задано слайсом цифр в системе счисления `inputBase`, старшая цифра —
первая: `[4 2]` в десятичной — это 42. Напишите `Rebase`: вернуть цифры того же
числа в системе `outputBase`.

- `Rebase(2, [1 0 1 0 1 0], 10)` → `[4 2]`;
- `Rebase(3, [1 1 2 0], 16)` → `[2 10]` — «цифра» в системе 16 может быть больше 9;
- ведущие нули во входе допустимы, в ответе их нет: `Rebase(7, [0 6 0], 10)` → `[4 2]`;
- ноль — это `[0]`, в том числе для пустого входа и для `[0 0 0]`.

Вернуть ошибку, если основание меньше 2 или какая-то цифра вне `[0, inputBase)`.
Текст ошибки тесты не проверяют.

`strconv` и `math/big` не используйте — перевод нужно написать самому.

Тесты — из открытого набора [Exercism](https://github.com/exercism/problem-specifications) (MIT).

<Reveal>

```go
func Rebase(inputBase int, digits []int, outputBase int) ([]int, error) {
	if inputBase < 2 {
		return nil, errors.New("input base must be >= 2")
	}
	if outputBase < 2 {
		return nil, errors.New("output base must be >= 2")
	}

	n := 0
	for _, d := range digits {
		if d < 0 || d >= inputBase {
			return nil, errors.New("all digits must satisfy 0 <= d < input base")
		}
		n = n*inputBase + d
	}
	if n == 0 {
		return []int{0}, nil
	}

	var out []int
	for ; n > 0; n /= outputBase {
		out = append(out, n%outputBase)
	}
	slices.Reverse(out)
	return out, nil
}
```

**Через обычное число.** Сначала собрать значение схемой Горнера — каждая
новая цифра: «умножить накопленное на основание и прибавить», — потом разобрать
его остатками от деления. Возводить основание в степени не нужно.

**Остатки идут с младшей цифры,** поэтому в конце разворот. Альтернатива —
вставлять в начало слайса, но это O(k²).

**Ноль — отдельный случай.** Цикл `for n > 0` для нуля не выполнится ни разу
и вернёт пустой слайс, а ответ — `[0]`.

**Где это ломается.** Через `int` решение работает, пока число влезает
в 64 бита. Для длинных входов переводят напрямую, «делением столбиком»
слайса цифр на `outputBase` — без промежуточного числа.
