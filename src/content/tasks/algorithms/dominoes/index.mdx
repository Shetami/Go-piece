Кость домино — пара чисел `[a|b]`, её можно переворачивать. Напишите
`CanChain`: можно ли выложить *все* кости в цепочку так, чтобы соседние
половинки совпадали, а свободные концы первой и последней кости — тоже
(цепочка замыкается в кольцо).

- `[2|1] [2|3] [1|3]` → да: `[1|2] [2|3] [3|1]`;
- `[1|2] [4|1] [2|3]` → нет: `[4|1] [1|2] [2|3]` не замыкается, 4 ≠ 3;
- пустой набор — да; одна кость `[1|1]` — да, `[1|2]` — нет.

Кости могут повторяться. Тесты ловят и случай, когда кости разбиваются на
два отдельных кольца, которые не соединить в одно.

Тесты — из открытого набора [Exercism](https://github.com/exercism/problem-specifications) (MIT).

**Перебор с возвратом** — решение, которого обычно ждут первым. Кладём
первую кость, на каждом шаге пробуем приставить любую неиспользованную в
одной из двух ориентаций, при тупике откатываемся. В конце сверяем концы.
Работает, но в худшем случае экспоненциально.

**Решение через граф:**

```go
func CanChain(dominoes [][2]int) bool {
	if len(dominoes) == 0 {
		return true
	}
	degree := map[int]int{}
	parent := map[int]int{}
	var find func(int) int
	find = func(x int) int {
		if _, ok := parent[x]; !ok {
			parent[x] = x
		}
		if parent[x] != x {
			parent[x] = find(parent[x])
		}
		return parent[x]
	}
	for _, d := range dominoes {
		degree[d[0]]++
		degree[d[1]]++
		parent[find(d[0])] = find(d[1])
	}
	root := find(dominoes[0][0])
	for v, deg := range degree {
		if deg%2 != 0 || find(v) != root {
			return false
		}
	}
	return true
}
```

**Кость — это ребро.** Числа на половинках — вершины графа, кость `[a|b]` —
ребро между ними. Цепочка, в которой каждая кость встречается ровно один раз
и которая замыкается, — это *эйлеров цикл*: обход по всем рёбрам ровно по
одному разу с возвратом в начало.

**Теорема Эйлера.** В связном графе эйлеров цикл есть тогда и только тогда,
когда степень каждой вершины чётна: сколько раз в вершину вошли, столько и
вышли. Кость-дубль `[1|1]` — петля, она добавляет вершине сразу 2.

**Связность — отдельное условие.** `[1|1] [2|2]` — степени чётные, но это
два кольца. Проверяем через систему непересекающихся множеств: все вершины
должны оказаться в одном множестве с первой.

O(n) вместо экспоненты — и ответ на вопрос «а если костей тысяча?».
