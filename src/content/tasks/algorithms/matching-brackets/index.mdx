Дана строка — кусок кода, формула, что угодно. Напишите `IsPaired`: правда ли,
что все скобки `()`, `[]` и `{}` в ней сбалансированы и правильно вложены.

- `{[()]}` и `f(x[1]) + {y}` — да;
- `{[)]}` — нет: круглая закрылась поверх квадратной;
- `([]` — нет: круглая не закрыта;
- `}{` — нет: закрывающая раньше открывающей.

Символы, которые не скобки, ничего не значат. Пустая строка — сбалансирована.

Тесты — из открытого набора [Exercism](https://github.com/exercism/problem-specifications) (MIT).

<Reveal>

```go
func IsPaired(value string) bool {
	pair := map[rune]rune{')': '(', ']': '[', '}': '{'}
	var stack []rune
	for _, r := range value {
		switch r {
		case '(', '[', '{':
			stack = append(stack, r)
		case ')', ']', '}':
			if len(stack) == 0 || stack[len(stack)-1] != pair[r] {
				return false
			}
			stack = stack[:len(stack)-1]
		}
	}
	return len(stack) == 0
}
```

**Стек открытых скобок.** Закрывающая скобка обязана закрывать *последнюю*
открытую — это и есть «правильная вложенность». Поэтому открытые складываем
в стек, а на закрывающей смотрим на вершину.

**Три способа ошибиться,** и тесты ловят каждый:

- закрывающая при пустом стеке — `}{`;
- закрывающая не своего типа — `{[)]}`;
- стек не пуст в конце — `([]`.

**Счётчик вместо стека** работает, только пока скобки одного вида. На трёх
видах он пропустит `([)]`: каждой открывающей есть пара, а вложенность
сломана.

O(n) по времени и O(n) памяти в худшем случае — строка из одних открывающих.
