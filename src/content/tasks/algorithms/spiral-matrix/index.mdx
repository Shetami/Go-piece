Напишите `Spiral`: квадратная матрица `size×size`, заполненная числами от 1
до `size²` по спирали — по часовой стрелке от левого верхнего угла к центру.

```
size = 4

 1  2  3  4
12 13 14  5
11 16 15  6
10  9  8  7
```

Для `size = 0` — пустая матрица, для `size = 1` — `[[1]]`.

Тесты — из открытого набора [Exercism](https://github.com/exercism/problem-specifications) (MIT).

<Reveal>

```go
func Spiral(size int) [][]int {
	m := make([][]int, size)
	for i := range m {
		m[i] = make([]int, size)
	}
	dr := [4]int{0, 1, 0, -1}
	dc := [4]int{1, 0, -1, 0}
	r, c, dir := 0, 0, 0
	for n := 1; n <= size*size; n++ {
		m[r][c] = n
		nr, nc := r+dr[dir], c+dc[dir]
		if nr < 0 || nr >= size || nc < 0 || nc >= size || m[nr][nc] != 0 {
			dir = (dir + 1) % 4
			nr, nc = r+dr[dir], c+dc[dir]
		}
		r, c = nr, nc
	}
	return m
}
```

**Направления как данные.** Вместо четырёх циклов «вправо, вниз, влево,
вверх» с отдельными границами — массив смещений и одно правило: если
следующая клетка за краем или уже заполнена, повернуть по часовой. Ноль
в клетке значит «свободна», потому что числа начинаются с единицы.

**Вариант с границами** — `top`, `bottom`, `left`, `right`, сжимающиеся
после каждой стороны, — тоже правильный и не требует читать матрицу. Но в нём
четыре цикла и четыре места для ошибки на единицу; на нечётном размере
центральную клетку легко записать дважды или пропустить.

**Обратная задача** — обойти готовую матрицу по спирали — решается тем же
кодом: читать вместо записи и помечать посещённые отдельно.

</Reveal>
