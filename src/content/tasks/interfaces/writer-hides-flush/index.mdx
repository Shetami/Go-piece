`report` пишет две строки в `io.Writer`. В `main` это буферизованный
вывод на экран. Программа завершается без ошибок, но на экране пусто.

Почините. Ожидаемый вывод:

```
заказов: 3
выручка: 1250
```

<Reveal>

**`bufio.Writer` копит данные в буфере** — по умолчанию 4 КБ — и отдаёт их
дальше, только когда буфер заполнится или когда вызовут `Flush`. Две
короткие строки буфер не заполнили, `Flush` никто не вызвал, программа
завершилась — данные пропали вместе с процессом.

**Почему не вызвали.** Переменная объявлена как `io.Writer`. У интерфейса
есть только `Write`, и `w.Flush()` не скомпилируется. Спрятав тип за
интерфейсом, автор спрятал и обязанность.

**Как правильно** — держать конкретный тип там, где им владеют, и
отдавать интерфейс только туда, где нужна запись:

```go
w := bufio.NewWriter(os.Stdout)
defer w.Flush()
report(w)
```

**Правило.** Тот, кто создал буферизованный writer, отвечает за `Flush`
(и за проверку его ошибки: запись на диск может упасть именно там). Для
файлов то же относится к `Close`.

</Reveal>
