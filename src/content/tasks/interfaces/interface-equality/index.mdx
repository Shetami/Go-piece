Шесть сравнений значений типа `any`. Во всех случаях «внутри» лежит одно и
то же число или одна и та же точка — но положено туда по-разному.

Напишите весь вывод программы.

<Reveal>

**Интерфейс — пара (динамический тип, значение).** Два интерфейса равны,
только если совпадают **оба**: сначала типы, потом значения по правилам
этого типа.

- `a == b` — оба `(int, 1)`: `true`.
- `a == c` — `(int, 1)` против `(int64, 1)`: типы разные, `false`.
  Никакого приведения чисел здесь нет.
- `a == 1` — нетипизированная константа `1` превращается в `any` со своим
  типом по умолчанию, `int`. Получается `(int, 1)`: `true`.
- `a == d` — `ID` и `int` — разные типы, хоть под `ID` и лежит `int`:
  `false`.
- `s == t` — структуры сравниваются по полям: `true`.
- `p == q` — указатели сравниваются по адресу, а адреса разные: `false`.

Итого:

```
true
false
true
false
true
false
```

**Где это стреляет.** Ключи `map[any]T`: `m[1]` и `m[int64(1)]` — два
разных ключа. Данные, пришедшие из JSON, лежат в `any` как `float64`, и
`v == 1` для них всегда ложно — сравнивать надо с `1.0`, а лучше сначала
привести тип.

</Reveal>
