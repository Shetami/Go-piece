`Service` встраивает `*Logger` и зовёт `Log` так, будто это его собственный
метод. Программа падает:

```
panic: runtime error: invalid memory address or nil pointer dereference
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 19: `return &Service{name: name}` — встроенный
`*Logger` не создан.

**Встраивание — это просто поле.** Поле называется `Logger`, у него тип
`*Logger`, и нулевое значение — `nil`. `s.Log(...)` — сокращение для
`s.Logger.Log(...)`: метод вызывается на `nil`-указателе. Сам вызов
проходит — метод на указателе можно вызвать и на `nil`, — а падает он на
`l.prefix`.

Компилятор здесь ничем не поможет: для него `s.Log` — законный вызов,
метод продвинут из встроенного поля.

**Как правильно** — создавать встроенный указатель в конструкторе:

```go
return &Service{Logger: &Logger{prefix: "[billing] "}, name: name}
```

Или встраивать значение, а не указатель: `Logger` вместо `*Logger` —
тогда ноль у него рабочий, пусть и с пустым префиксом.

</Reveal>
