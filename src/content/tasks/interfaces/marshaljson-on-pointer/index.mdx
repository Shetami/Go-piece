Чтобы пароль не утёк в логи и ответы API, у `Password` есть свой
`MarshalJSON`. Программа печатает:

```
{"Login":"admin","Password":"hunter2"}
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 11: `MarshalJSON` объявлен на указателе.

**`json.Marshal(u)` получает копию структуры в `any`.** Поле `Password` в
этой копии не адресуемо: взять его адрес, чтобы вызвать метод на
`*Password`, нельзя. `encoding/json` проверяет, реализует ли *значение*
поля `json.Marshaler`, — а у `Password` такого метода нет, он есть только у
`*Password`. Остаётся маршалинг по умолчанию: строка как есть.

Передайте `json.Marshal(&u)` — и звёздочки появятся: теперь поле адресуемо.
Поведение зависит от того, как вызывающий передал структуру, — худший
вариант для защитного кода.

**Как правильно** — метод на значении: `func (p Password) MarshalJSON()`.
Тогда он есть и у `Password`, и у `*Password`, и вызывается всегда.
Правило: `MarshalJSON`, `MarshalText` и `String` объявляют на значении,
`UnmarshalJSON` — на указателе, ему нужно менять получателя.

</Reveal>
