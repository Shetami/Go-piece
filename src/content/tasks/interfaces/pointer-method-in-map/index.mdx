У `Counter` метод `Inc` с получателем-указателем. Счётчики лежат в мапе по
адресу страницы. Компилятор отказывается:

```
cannot call pointer method Inc on Counter
```

Почините. Ожидаемый вывод:

```
/ 2
/about 1
```

<Reveal>

**Чтобы вызвать метод на указателе у значения, Go берёт его адрес:**
`v.Inc()` — это `(&v).Inc()`. Для переменной это работает. Но элемент мапы
**не адресуем**: мапа может перестроиться при росте, и указатель на
элемент стал бы висячим. Поэтому `&pages[p]` запрещено, а значит, и
`pages[p].Inc()`.

**Починка 1 — хранить указатели:** `map[string]*Counter`. Тогда
`pages[p]` уже указатель, и метод вызывается на нём. Сам объект лежит в
куче и никуда не переезжает.

**Починка 2 — достать, изменить, положить обратно:**

```go
c := pages[p]
c.Inc()
pages[p] = c
```

Работает, но три строки на каждое изменение — и легко забыть третью.

**Где ещё это встречается.** Метод-указатель не входит в набор методов
значения: `Counter` не реализует интерфейс `interface{ Inc() }`, а
`*Counter` — реализует. Та же причина: у значения в интерфейсе нет адреса.

</Reveal>
