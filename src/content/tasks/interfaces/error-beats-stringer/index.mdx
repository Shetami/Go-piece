У `status` два метода — `String` и `Error`. У `temp` только `String`.
Значения печатают разными способами.

Напишите весь вывод программы.

<Reveal>

**Если у значения есть и `Error`, и `String`, `fmt` берёт `Error`.** Порядок
проверки в `fmt` жёсткий: сначала `Formatter`, потом `error`, потом
`Stringer`.

**Но только для «строковых» глаголов.** Методы вызываются для `%v`, `%s`,
`%q`, `%x` и `%X`. Для `%d` `fmt` форматирует значение как есть — структуру
по полям: `{404}`.

**С `temp` то же самое.** `Println` печатает через `%v` — вызывается
`String`. А `%.2f` — глагол для чисел, и `fmt` печатает `float64` под
`temp` напрямую, `String` не вызывается.

Итого:

```
ошибка 404
ошибка 404 | ошибка 404 | {404}
21.5°C
21.50
```

**Где это полезно.** Именно поэтому внутри `String` можно писать
`fmt.Sprintf("%.1f", float64(t))` — но нельзя `fmt.Sprintf("%v", t)`: `%v`
снова вызовет `String`, и получится бесконечная рекурсия.

</Reveal>
