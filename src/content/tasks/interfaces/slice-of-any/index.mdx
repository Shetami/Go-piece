title: "[]string — это не []any"
description: Функция принимает []any, чтобы печатать что угодно. Слайс строк в неё не передаётся — компилятор против. Почините.
kind: fix
topic: interfaces

---

`printAll` принимает `[]any`, раз `any` вмещает что угодно. Передать ей
`[]string` не получается:

```
cannot use names (variable of type []string) as []any value in argument to printAll
```

Почините. Ожидаемый вывод:

```
аня
боря
1
2
```

<Reveal>

**`string` можно положить в `any`, но `[]string` — не `[]any`.** Это разные
типы с разным устройством в памяти. Элемент `[]string` — заголовок строки,
16 байт. Элемент `[]any` — пара «тип + указатель на данные», тоже 16 байт,
но совсем другого содержания. Чтобы превратить один слайс в другой, надо
пройти по всем элементам и упаковать каждый. Go не делает такую работу
неявно.

**Починка 1 — дженерик.** `func printAll[T any](items []T)` принимает
слайс любого типа как есть, без копирования.

**Починка 2 — явная конвертация**, если функцию менять нельзя:

```go
items := make([]any, len(names))
for i, n := range names {
	items[i] = n
}
printAll(items)
```

**Почему `printAll(names...)` не спасает.** Для вариативного
`func(items ...any)` так тоже нельзя: `names...` передаёт сам слайс, и
тип обязан совпадать.

</Reveal>
