Отладка выключена, буфер для лога не создавался. `process` проверяет
`w != nil`, но программа падает:

```
panic: runtime error: invalid memory address or nil pointer dereference
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 19: `var buf *bytes.Buffer`.

**Интерфейс равен `nil`, только если в нём нет ни типа, ни значения.**
`buf` — это `nil` типа `*bytes.Buffer`. Когда его передают в параметр
`io.Writer`, в интерфейс кладётся пара `(*bytes.Buffer, nil)`. Тип есть —
значит, интерфейс не `nil`, и проверка `w != nil` пропускает дальше.

`Fprintln` вызывает `w.Write`, то есть `(*bytes.Buffer)(nil).Write`, и метод
буфера разыменовывает нулевой указатель.

Сама проверка в `process` написана правильно. Ошибка в том, как
вызывающий готовит аргумент.

**Как правильно** — объявить переменную сразу как интерфейс:

```go
var w io.Writer
if debug {
	w = new(bytes.Buffer)
}
process(w, "старт")
```

Без отладки `w` остаётся настоящим `nil`-интерфейсом.

**Правило.** Не держите «может быть `nil`» в переменной конкретного
указательного типа, если она потом уезжает в интерфейс. Особенно часто это
случается с ошибками — `var err *MyError` вместо `var err error` — и тогда
`err != nil` срабатывает, хотя ошибки нет.

</Reveal>
