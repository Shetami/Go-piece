Первая строка печатается, а на числе программа падает:

```
panic: interface conversion: interface {} is int, not string
```

Почините. Ожидаемый вывод:

```
строка длины 4
не строка: int
не строка: <nil>
```

<Reveal>

**`v.(string)` в форме с одним результатом паникует при несовпадении.**
Приведение типа проверяет динамический тип в рантайме, и если там не
`string`, выбора у него нет: вернуть нечего, значит — паника.

**Форма с двумя результатами не паникует:**

```go
s, ok := v.(string)
if !ok {
	return fmt.Sprintf("не строка: %T", v)
}
```

При несовпадении `s` — нулевое значение, `ok == false`.

**`%T` для `nil`** печатает `<nil>`: у пустого интерфейса нет типа вовсе.

Если вариантов больше двух — `switch x := v.(type)`, он читается лучше
цепочки `if` с `ok`.

**Когда паникующая форма уместна.** Когда несовпадение означает баг в
программе, а не плохие данные: значение положили вы же, строкой выше. Тогда
паника — честный способ сказать «так не бывает». Для всего, что пришло
снаружи, — только форма с `ok`.

</Reveal>
