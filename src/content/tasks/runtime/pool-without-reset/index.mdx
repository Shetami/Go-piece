Программа печатает:

```
привет, Аня
привет, Аняпривет, Боря
```

Почините. Ожидаемый вывод:

```
привет, Аня
привет, Боря
```

<Reveal>

**`sync.Pool` отдаёт объект таким, каким его вернули.** Пул ничего не знает
о `bytes.Buffer` и не очищает его. Первый вызов берёт новый буфер, пишет
в него и возвращает в пул. Второй получает тот же буфер — с «привет, Аня»
внутри — и дописывает к нему.

**Как чинят** — сбрасывать состояние после `Get`:

```go
buf := pool.Get().(*bytes.Buffer)
buf.Reset()
```

(Или перед `Put` — важно одно: где-то это должно происходить всегда.)

**Ещё два подвоха с пулами.**

- `pool.Get()` не обязан вернуть тот же объект, что вы положили: сборщик
  мусора может очистить пул в любой момент. Код не должен от этого зависеть
  — здесь это было бы видно как «иногда работает правильно».
- Возвращать в пул огромные буферы вредно: один запрос на 100 МБ оставит в
  пуле буфер на 100 МБ, и все следующие будут держать его. Стандартная
  библиотека (`fmt`, `encoding/json`) не кладёт обратно буферы больше
  порога.

Детектор гонок, кстати, намеренно выбрасывает часть объектов из пула —
чтобы тесты не полагались на повторное использование.

</Reveal>
