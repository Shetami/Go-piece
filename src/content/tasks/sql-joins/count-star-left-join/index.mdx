Три отдела, в «Дизайне» пока никого нет.

Что вернёт запрос? Три строки: название отдела и число через `|`.

<Reveal>

```
Бэкенд   | 3
Дизайн   | 1
Фронтенд | 1
```

**`LEFT JOIN` не выбрасывает отдел без сотрудников, а даёт ему одну строку**,
где все колонки `employees` — `NULL`. `count(*)` считает строки, и эта
строка-заглушка честно посчитана. Пустой отдел превращается в отдел из
одного человека.

**Правильно — считать непустое значение с правой стороны:**

```sql
SELECT d.name, count(e.id) AS staff
```

`count(e.id)` у «Дизайна» даст 0: единственное значение `e.id` там `NULL`.

Та же ошибка вылезает в любом отчёте «сколько X у каждого Y» —
заказов у клиента, комментариев у поста.

</Reveal>
