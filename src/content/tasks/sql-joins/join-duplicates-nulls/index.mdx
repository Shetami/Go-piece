В таблице `a` значения `1, 1, 2, NULL`, в таблице `b` — `1, 1, 1, NULL, 3`.

Что вернёт запрос? Одна строка, три числа через `|`.

<Reveal>

```
6 | 8 | 10
```

**INNER: 6.** Совпадает только единица: две единицы из `a` и три из `b`
дают каждая с каждой 2 × 3 = 6 пар. Соединение не «сопоставляет» строки
один к одному — оно перебирает все пары, для которых условие истинно.

**`NULL = NULL` — не истина**, поэтому `NULL` из `a` и `NULL` из `b` друг с
другом не соединяются.

**LEFT: 8.** Шесть пар плюс строки `a`, у которых пары нет, — `2` и `NULL`,
каждая по одной строке с `NULL` справа.

**FULL: 10.** Восемь из LEFT плюс строки `b` без пары — `NULL` и `3`.

Именно так на собеседовании проверяют, понимаете ли вы соединение как
декартово произведение с фильтром, а не как «подклеить соседнюю таблицу».

</Reveal>
