Для каждого пользователя найдите самую длинную серию заходов подряд — день
за днём, без пропусков. Несколько заходов за один день — это один день.

- колонки: `user_name`, `longest_streak` (в днях);
- порядок: по `user_name`.

<Reveal>

```sql
WITH days AS (
  SELECT DISTINCT user_name, day
  FROM logins
),
grouped AS (
  SELECT user_name, day,
         day - row_number() OVER (PARTITION BY user_name ORDER BY day)::int AS grp
  FROM days
),
streaks AS (
  SELECT user_name, grp, count(*) AS len
  FROM grouped
  GROUP BY user_name, grp
)
SELECT user_name, max(len) AS longest_streak
FROM streaks
GROUP BY user_name
ORDER BY user_name;
```

**Приём «дата минус номер».** Внутри непрерывной серии дата растёт на 1 и
номер строки растёт на 1 — их разность постоянна. На пропуске дата прыгает
на 2 и больше, номер — на 1, и разность меняется. Эта разность и есть метка
серии («острова»).

```
день        rn   день − rn
05-01        1   04-30
05-02        2   04-30
05-03        3   04-30
05-05        4   05-01   ← новый остров
05-06        5   05-01
```

**`DISTINCT` в начале обязателен**: повторный заход 2 мая получил бы свой
номер, и разность съехала бы.

**Второй способ** — `lag(day)`: пометить начало острова там, где
`day - lag(day) <> 1`, и нарастающим `sum` пронумеровать острова.

</Reveal>
