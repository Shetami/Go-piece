Приложение для бега поздравляет с личным рекордом. Найдите все пробежки,
которые были рекордом **на момент, когда их пробежали**.

- порядок пробежек бегуна: `run_date`, в один день — по `id`;
- рекорд — дистанция **строго больше** всех предыдущих пробежек бегуна;
  первая пробежка с известной дистанцией — рекорд;
- пробежки с `distance_km IS NULL` не бывают рекордом и не влияют на другие;
- `prev_best` — предыдущий рекорд (максимум дистанции среди предыдущих
  пробежек), `NULL` у первого рекорда;
- колонки: `runner`, `run_date`, `distance_km`, `prev_best`;
- порядок: по `runner`, `run_date`, `distance_km`.

Что проверяют скрытые данные: две пробежки в один день, обе рекордные;
пробежка, повторившая рекорд; пробежка без дистанции перед первой
нормальной.

<Reveal>

```sql
WITH with_best AS (
  SELECT runner, run_date, id, distance_km,
         max(distance_km) OVER (
           PARTITION BY runner
           ORDER BY run_date, id
           ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING
         ) AS prev_best
  FROM runs
)
SELECT runner, run_date, distance_km, prev_best
FROM with_best
WHERE distance_km IS NOT NULL
  AND (prev_best IS NULL OR distance_km > prev_best)
ORDER BY runner, run_date, distance_km;
```

Ответ:

```
Ася | 2024-03-01 | 5.00 | NULL
Ася | 2024-03-05 | 6.00 | 5.00
Ася | 2024-03-05 | 6.50 | 6.00
Ася | 2024-03-10 | 10.00 | 6.50
Бен | 2024-03-04 | 3.00 | NULL
```

**Нужен максимум *предыдущих*, а не «по текущую включительно».** Рамка
`ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING` исключает текущую
строку. С рамкой по текущую строку условие `distance = max` пропускало бы
повтор рекорда (6.50 → 6.50) — а он не рекорд.

**`RANGE` по дате склеивает пробежки одного дня.** С `ORDER BY run_date` и
рамкой по умолчанию обе пробежки 5 марта видят максимум дня — 6.50, и
6.00 перестаёт быть рекордом, хотя утром она им была. Порядок по `run_date,
id` плюс `ROWS` — честная хронология.

**`lag` — не прошлый рекорд,** а прошлая пробежка: у Аси перед 10 км была
6.50, а до неё 4.00 — это не рекорд.

**`NULL` разбираются сами:** `max` их пропускает; строку с `NULL`
отбрасывает `distance_km IS NOT NULL`; у Бена первый `NULL` не мешает
3.00 стать первым рекордом (`prev_best IS NULL`).
