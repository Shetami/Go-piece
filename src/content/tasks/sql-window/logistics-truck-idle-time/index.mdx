Логисту нужно видеть, сколько машины простаивают между рейсами.

- рейсы машины упорядочены по `departed_at` (при равенстве — по `id`);
- простой после рейса — от его `arrived_at` до `departed_at` следующего
  рейса этой машины; после последнего рейса простоя нет;
- если следующий рейс записан с выездом раньше приезда (ошибка в данных),
  простой считается равным **0**;
- в отчёте **все** машины из `trucks`; без рейсов или с одним рейсом —
  нули;
- колонки: `truck`, `trips`, `idle_hours` (сумма простоев в часах,
  `round(…, 2)`), `longest_idle_min` (самый длинный простой в минутах, целое);
- порядок: по `idle_hours` по убыванию, затем по `truck`.

Что проверяют скрытые данные: `id`, не совпадающие с порядком рейсов;
пересекающиеся рейсы; машина с одним рейсом; машина без рейсов.

<Reveal>

```sql
WITH gaps AS (
  SELECT truck,
         greatest(lead(departed_at) OVER (PARTITION BY truck ORDER BY departed_at, id) - arrived_at,
                  INTERVAL '0') AS idle
  FROM trips
)
SELECT t.plate AS truck,
       count(g.truck) AS trips,
       round(coalesce(sum(extract(epoch FROM g.idle)), 0) / 3600, 2) AS idle_hours,
       coalesce(max(extract(epoch FROM g.idle)), 0)::int / 60 AS longest_idle_min
FROM trucks t
LEFT JOIN gaps g ON g.truck = t.plate
GROUP BY t.plate
ORDER BY idle_hours DESC, t.plate;
```

Ответ:

```
T2 | 3 | 3.00 | 180
T1 | 3 | 1.50 | 60
T3 | 1 | 0.00 | 0
T4 | 0 | 0.00 | 0
```

**Порядок — по времени, а не по `id`.** У T1 рейс 3 (10:30) идёт между
рейсами 1 и 2. С `ORDER BY id` простой после первого рейса считался бы до
13:00 — 3 часа вместо 30 минут.

**`lead` от текущего рейса или `lag` от следующего — одно и то же**, если
формула правильная: `следующий выезд − текущий приезд`. Главное — не
перепутать концы и не смешать машины (нужен `PARTITION BY truck`).

**Отрицательный простой — `greatest(…, interval '0')`.** У T2 второй рейс
выехал в 8:30, а первый приехал в 9:00. Без отсечения сумма простоев T2
станет 2.5 часа вместо 3.

**`NULL` после последнего рейса** агрегаты пропускают сами, а для машин без
простоев `sum`/`max` дают `NULL` — отсюда `coalesce`. `count(g.truck)` после
`LEFT JOIN` даёт 0 для T4, `count(*)` дал бы 1.

**Что спросят дальше.** Простой только в рабочее время (обрезать интервалы
по сменам), и как считать, если рейсы идут через полночь и отчёт нужен
по суткам.
