description: Анонимная функция вызывает саму себя через переменную, которой присвоена, и программа не компилируется. Почините.
kind: fix

Программа не компилируется:

```
undefined: fib
```

Почините. Ожидаемый вывод:

```
55
```

<Reveal>

**Имя, объявленное через `:=`, видно только после конца объявления.**
Правая часть `fib := func...` вычисляется до того, как `fib` появится.
Внутри тела функции имени `fib` ещё нет — компилятор честно говорит
`undefined`.

**Как чинят** — разделить объявление и присваивание:

```go
var fib func(n int) int
fib = func(n int) int {
	...
	return fib(n-1) + fib(n-2)
}
```

Теперь `fib` существует (со значением `nil`) к моменту, когда компилируется
тело, и замыкание захватывает эту переменную. К моменту первого вызова в ней
уже лежит сама функция.

**Где это встречается.** Обход дерева или графа внутри функции, которой
нужен доступ к локальному состоянию (`visited`, результат), без выноса на
уровень пакета. Если состояния нет, проще обычная именованная функция.

</Reveal>
