Внешняя `x` одна. Четыре функции обращаются к ней по-разному: объявляют
свою через `:=`, увеличивают внешнюю, получают параметром, копируют в свою
переменную и увеличивают копию.

Напишите весь вывод программы.

<Reveal>

**`x := 2` внутри замыкания — новая переменная**, которая затеняет внешнюю.
Внешняя остаётся 1.

**`x++` без объявления — внешняя переменная.** Замыкание захватило её саму,
а не копию значения. После двух вызовов — 3.

**Параметр — это копия.** Имя совпадает, но `x` внутри `reset` — своя
локальная переменная, её обнуление снаружи не видно.

**`x := x * 10` справа читает внешнюю x, слева объявляет новую.** Правая
часть вычисляется до того, как новое имя вступает в силу. Возвращённое
замыкание захватило новую переменную со значением 30 и увеличивает её.
Внешняя так и осталась 3.

Итого:

```
1
3
3
31 32 3
```

**Где на этом ловятся.** `err := ...` внутри замыкания, которое должно было
записать ошибку во внешнюю `err`. Код компилируется, внешняя `err` остаётся
`nil`. Такое находит отдельный анализатор `shadow` из `golang.org/x/tools`,
обычный `go vet` — нет.

</Reveal>
