В Go 1.22 переменная цикла стала своей у каждой итерации. Поэтому автор
ожидал, что три замыкания напечатают 0, 1 и 2. Программа печатает:

```
задача 3
задача 3
задача 3
```

Почините. Ожидаемый вывод:

```
задача 0
задача 1
задача 2
```

<Reveal>

**Go 1.22 изменил семантику только для переменных, объявленных в самом
`for`** — в `for i := 0; i < n; i++` и в `for i, v := range ...`. Здесь
цикл вида «пока» (`for i < 3`), и `i` объявлена *до* него обычным `:=`.
Для компилятора это просто переменная снаружи цикла — одна на все
итерации. Все три замыкания захватили её, а к моменту вызова там 3.

**Починка 1 — копия внутри тела:** `n := i`, и замыкание захватывает
`n`. Переменная, объявленная в теле, своя у каждой итерации всегда, в
любой версии Go.

**Починка 2 — объявить `i` в самом цикле:**

```go
for i := 0; i < 3; i++ {
```

Тогда работает правило Go 1.22.

</Reveal>
