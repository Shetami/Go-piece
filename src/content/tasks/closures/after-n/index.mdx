Напишите тело `After`. Пригождается, например, чтобы писать в лог только
после третьей подряд неудачи.

Что проверяют скрытые тесты:

- `After(3, f)`: первые два вызова ничего не делают, третий и дальше —
  вызывают `f`;
- `n` равное 1, 0 или отрицательное → `f` вызывается с первого раза;
- две обёртки считают вызовы независимо.

<Reveal>

```go
func After(n int, f func()) func() {
	calls := 0
	return func() {
		calls++
		if calls >= n {
			f()
		}
	}
}
```

**Счётчик — в `After`, а не в возвращаемой функции.** Переменная, объявленная
в теле возвращаемой функции, создавалась бы заново при каждом вызове.
Переменная из `After`, захваченная замыканием, живёт между вызовами — и
своя у каждого вызова `After`.

**`>=`, а не `==`** — чтобы `f` срабатывала и после n-го раза, и чтобы
`n <= 1` работало без отдельной ветки.

**Под конкурентным доступом** `calls++` — гонка. Если обёртку зовут из
разных горутин, счётчик — `atomic.Int64`.

</Reveal>
