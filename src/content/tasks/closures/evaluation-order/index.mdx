`next` — замыкание над `n`, каждый вызов увеличивает счётчик. Его зовут три
раза в одних аргументах, потом в множественном присваивании, которое заодно
меняет индекс `i`.

Напишите весь вывод программы.

<Reveal>

**Вызовы функций в выражении выполняются слева направо.** Спецификация это
гарантирует: `next(), next(), next()` дают `1 2 3`.

**Множественное присваивание идёт в две фазы.** Сначала вычисляются индексы
слева и все выражения справа, потом присваивания выполняются по порядку.
`a[i]` зафиксировал `i = 0` ещё до того, как `i` стал 2. Справа `next()`
вернул 4. Итог: `a[0] = 4`, `i = 2`.

**То же правило даёт обмен без временной переменной.** Справа сначала
вычисляются `y` и `x+y` — `2` и `3` — и только потом оба значения
присваиваются.

Итого:

```
1 2 3
[4 0 0] 2
2 3
```

**Где осторожнее.** Порядок вызовов гарантирован, а вот порядок чтения
переменных относительно вызовов — нет: в `fmt.Println(n, next())`
спецификация не говорит, прочтётся `n` до вызова или после. Не
смешивайте в одном выражении чтение переменной и вызов, который её меняет.

</Reveal>
