description: Курс фиксируется в момент оформления заказа. Потом курс в конфиге обновляют — и уже оформленный заказ пересчитывается по новому. Почините.
kind: fix

`pricer` вызывают при оформлении заказа и получают функцию пересчёта по
текущему курсу — 90. Потом курс в конфиге меняется. Заказ на 900 рублей
должен остаться за 10 долларов, а программа печатает:

```
9.00
```

Почините. Ожидаемый вывод:

```
10.00
```

<Reveal>

**Замыкание захватило указатель на конфиг, а не курс.** `cfg.Rate`
читается при каждом вызове — то есть уже после обновления. Функция
получилась «живой», а по контракту должна быть снимком.

**Как правильно** — прочитать значение при создании и захватить копию:

```go
rate := cfg.Rate
return func(rub float64) float64 {
	return rub / rate
}
```

**Обе стороны бывают нужны.** Живая ссылка — когда функция должна видеть
изменения (метрика текущей длины очереди). Снимок — когда результат
обязан быть воспроизводимым (цена заказа, подпись запроса). Главное —
выбирать осознанно: по коду `cfg.Rate` внутри замыкания не видно, когда
он читается.

</Reveal>
