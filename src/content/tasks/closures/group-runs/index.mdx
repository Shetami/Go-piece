Поток событий отсортирован по времени, и нужно схлопнуть подряд идущие
события одного пользователя в «серии» — как `uniq` в Unix, только с
группами. Источник может быть огромным, поэтому ответ тоже ленивый:
`iter.Seq2[K, []T]`, которую обходят через `for k, group := range …`.

Напишите `Runs`.

Что проверяют скрытые тесты:

- события пользователей `"", "", ann, "", bob, bob` → четыре группы с
  ключами `"", ann, "", bob` и размерами `2, 1, 1, 2`;
- потребитель сохраняет все группы, и они остаются целыми после обхода;
- пустой источник — ни одной группы;
- `break` на первой группе: никакой паники, а из источника прочитано не
  больше, чем нужно, чтобы понять, что первая группа кончилась;
- результат `Runs` обходят дважды — оба раза выходят все группы.

<Reveal>

```go
func Runs[T any, K comparable](seq iter.Seq[T], key func(T) K) iter.Seq2[K, []T] {
	return func(yield func(K, []T) bool) {
		var (
			cur   K
			group []T
		)
		stopped := false
		seq(func(v T) bool {
			k := key(v)
			if len(group) > 0 && k != cur {
				if !yield(cur, group) {
					stopped = true
					return false
				}
				group = nil
			}
			cur = k
			group = append(group, v)
			return true
		})
		if !stopped && len(group) > 0 {
			yield(cur, group)
		}
	}
}
```

**Три уровня замыканий.** `Runs` возвращает итератор; итератор при обходе
создаёт своё состояние (`cur`, `group`) и передаёт в источник функцию, которая
это состояние меняет. Если объявить `cur` и `group` в самой `Runs`, а не
внутри итератора, второй обход начнёт с хвоста первого — это и ловит тест
на повторный обход.

**Ключ-ноль — законный ключ.** Соблазнительно начать с `var cur K` и
считать «группы ещё нет», пока `cur` равен нулю. Но пользователь `""` или
id `0` — реальные данные, и первая группа приклеится неизвестно к чему.
Признак начатой группы — непустой `group`.

**Новый слайс на каждую группу.** Оптимизация `group = group[:0]`
переиспользует массив, но потребитель уже держит предыдущую группу — и
следующие события перезапишут её элементы. Если хочется экономить,
контракт должен прямо говорить «слайс действителен до следующей итерации»,
как у `bufio.Scanner.Bytes`.

**`break` должен дойти до источника.** Когда `yield` вернул `false`, мы
возвращаем `false` источнику, и он прекращает работу. Флаг `stopped` нужен,
чтобы после этого не отдать хвостовую группу: вызов `yield` после `false`
Go ловит паникой «range function continued iteration».
