Каждому имени страницы назначается обработчик. Код запускается на
современном Go, где у каждой итерации своя переменная `name`. Но программа
печатает:

```
страница: выход
страница: выход
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 11: `routes[name] = func() { handler() }`.

**Go 1.22 исправил переменную цикла, но не все переменные.** `name` —
переменная цикла, и у каждой итерации она своя: замыкание, созданное в
строке выше, правильно захватывает «главная», «профиль», «выход».

Но в мапу кладётся *другое* замыкание — обёртка, которая вызывает
`handler()`. А `handler` объявлен до цикла, он один на все итерации. Обёртка
захватила эту переменную, а не её текущее значение. К моменту вызова в
`handler` лежит последний обработчик — для «выхода».

Это та же самая ошибка «замыкание в цикле», что была до Go 1.22, только
теперь её не спишешь на семантику `for`.

**Как правильно** — положить в мапу значение, а не обёртку над переменной:

```go
routes[name] = handler
```

Или объявить `handler` внутри цикла через `:=`, тогда он тоже будет свой на
каждой итерации.

**Правило.** Замыкание захватывает переменные по ссылке — всегда. Go 1.22
изменил только то, сколько переменных создаёт `for`. Всё, что объявлено
снаружи цикла, по-прежнему общее.

</Reveal>
