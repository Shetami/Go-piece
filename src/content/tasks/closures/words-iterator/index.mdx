Напишите тело `Words`.

Что проверяют скрытые тесты:

- `"  привет,\tмир \n  go "` → `привет,`, `мир`, `go`;
- пустая строка и строка из одних пробелов → ни одного слова;
- после конца каждый вызов возвращает `"", false`;
- два итератора по одной строке независимы;
- на первое слово строки из четверти миллиона слов уходит не больше пары
  выделений памяти — значит, строку не режут целиком заранее.

<Reveal>

```go
func Words(s string) func() (string, bool) {
	rest := s
	return func() (string, bool) {
		rest = strings.TrimLeftFunc(rest, unicode.IsSpace)
		if rest == "" {
			return "", false
		}
		end := strings.IndexFunc(rest, unicode.IsSpace)
		if end < 0 {
			end = len(rest)
		}
		w := rest[:end]
		rest = rest[end:]
		return w, true
	}
}
```

**Состояние — непрочитанный остаток строки.** Замыкание захватило `rest`
и каждый раз продвигает его. Подстроки не копируют байты, поэтому ни
слово, ни остаток ничего не выделяют — в отличие от
`strings.Fields(s)`, который сразу строит слайс из всех слов.

**Конец итерации устойчив:** когда `rest` опустел, каждый следующий вызов
снова находит пустоту и отвечает `false`.

**В современном Go** то же самое пишут как `iter.Seq[string]` — функцию,
которую обходят через `for w := range words(s)`. С Go 1.24 есть готовый
`strings.FieldsSeq`. Замыкание «вызови ещё раз» — предок этой идеи и до
сих пор встречается в API вроде `bufio.Scanner`.

</Reveal>
