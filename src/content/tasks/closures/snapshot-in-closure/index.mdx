Система метрик получает функцию при старте и зовёт её раз в несколько
секунд. После двух `Push` она должна показать 2, а показывает:

```
в очереди: 0
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 16: `items := q.items`.

**Замыкание захватило локальную переменную `items`, а не поле очереди.** В
`items` скопирован заголовок слайса на момент вызова `LenFunc` — пустой.
`Push` потом присваивает полю `q.items` новый слайс, но локальная копия
об этом не знает. Замыкание честно возвращает длину своей копии.

Даже если бы в очереди уже что-то было, копия застыла бы на той длине: у
заголовка слайса своя длина, `append` в поле её не меняет.

**Как правильно** — захватывать то, что живёт дольше, — указатель на
очередь:

```go
return func() int { return len(q.items) }
```

**Если очередь меняется из других горутин,** такое чтение — гонка. Тогда
нужен мьютекс внутри замыкания или счётчик `atomic.Int64`.

</Reveal>
