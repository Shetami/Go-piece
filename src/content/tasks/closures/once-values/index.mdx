Конфиг, пул соединений, скомпилированный шаблон — всё это хочется создать
лениво, при первом обращении, и ровно один раз, даже если обратились сразу
из сотни горутин. В стандартной библиотеке для этого есть
`sync.OnceValues`; напишите её сами поверх `sync.Once` и замыкания.

Что проверяют скрытые тесты:

- 50 горутин вызывают обёртку одновременно: `f` вызвана один раз, и все
  получили её результат, а не нули;
- ошибка запоминается: `f` не перезапускается;
- если `f` паникует, паникуют все вызовы — второй и третий тоже, с тем же
  значением; `f` при этом вызвана один раз;
- две обёртки не делят состояние.

<Reveal>

```go
func OnceValues[T any](f func() (T, error)) func() (T, error) {
	var (
		once     sync.Once
		val      T
		err      error
		panicked bool
		pval     any
	)
	return func() (T, error) {
		once.Do(func() {
			panicked = true
			defer func() {
				if panicked {
					pval = recover()
				}
			}()
			val, err = f()
			f = nil
			panicked = false
		})
		if panicked {
			panic(pval)
		}
		return val, err
	}
}
```

**Состояние живёт в замыкании, синхронизация — в `sync.Once`.** `Do`
гарантирует не только «один раз», но и что остальные вызовы ждут, пока
первый закончит, и видят всё, что он записал (happens-before). Поэтому
`val` и `err` читаются без мьютекса. Самодельный флаг `done bool` без
`Once` — это гонка: вторая горутина увидит `done == true` раньше, чем
`val`.

**Паника — главный подвох.** `sync.Once` считает функцию выполненной, даже
если она запаниковала. Наивная обёртка паникует один раз, а на втором
вызове молча возвращает `0, nil` — и сервис работает с пустым конфигом.
Поэтому паника перехватывается, запоминается и перебрасывается на каждом
вызове. Флаг `panicked` ставится до вызова `f` и снимается после — так
`defer` отличает панику от нормального возврата (и не спотыкается о
`panic(nil)`, который в Go 1.21+ всё равно превращается в
`*runtime.PanicNilError`).

**`f = nil`** — мелочь, которую есть в стандартной реализации: после вызова
`f` не нужна, а всё, что она захватила, иначе жило бы, пока жива обёртка.

**Что спросят дальше:** как сделать вариант, который повторяет неудачную
попытку (тогда `sync.Once` не подходит — нужен мьютекс и флаг «успешно»), и
почему `f` внутри не должна вызывать ту же обёртку — это дедлок на `Once`.
