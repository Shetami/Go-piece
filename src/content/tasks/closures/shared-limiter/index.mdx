Задумано так: каждому пользователю два запроса, третий отклоняется.
Программа печатает:

```
аня true
аня true
аня false
боря false
боря false
боря false
```

Отметьте строку, в которой заложена поломка.

<Reveal>

Сломано в строке 18: `allow := limiter`.

**Присваивание функции не создаёт новое замыкание.** `limiter` — одно
замыкание с одной переменной `count`. `allow := limiter` копирует ссылку на
него, а не состояние. Оба пользователя увеличивают один и тот же счётчик:
Аня доводит его до трёх, и Боре остаются только отказы.

Новая `count` появляется только при новом *вызове* `newLimiter`: именно
там исполняется `count := 0`.

**Как правильно:**

```go
allow := newLimiter(2)
```

— внутри цикла, свой лимитер на каждого.

**В реальном коде** лимитеры по пользователям держат в мапе
`map[string]*rate.Limiter` и создают при первом обращении. Та же ошибка там
выглядит как «достали из мапы общий лимитер вместо персонального».

</Reveal>
