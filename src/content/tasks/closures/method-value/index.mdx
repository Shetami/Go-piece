`hello` — метод на значении, сохранённый в переменную. `bye` — метод на
указателе, тоже сохранённый. `later` — обычное замыкание, которое вызывает
`g.Hello()`. После этого имя меняют на «Боря».

Напишите весь вывод программы.

<Reveal>

**Method value связывает получатель в момент вычисления.** `g.Hello` без
скобок — это функция с уже подставленным получателем. Для метода на значении
получатель копируется прямо сейчас: `hello` держит свою копию `g` с «Аней».

**Для метода на указателе копируется адрес.** `g.Bye` — это `(&g).Bye`,
связан указатель на `g`. К моменту вызова по адресу лежит «Боря».

**Замыкание захватывает переменную.** `later` не вычисляет `g` заранее — она
прочитает `g` в момент вызова, и это будет «Боря».

Итого:

```
привет, Аня
пока, Боря
привет, Боря
```

**Где пригодится.** `http.HandleFunc("/", srv.handle)` или
`go w.run()` — это method value. Если метод на значении, горутина или
обработчик получают снимок структуры на момент регистрации, и изменения
конфигурации до них не дойдут. Это ровно тот же механизм, что у `defer` с
методом на значении.

</Reveal>
