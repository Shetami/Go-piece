Артефакт собирается один раз — из коммита в `main`, с тегом по SHA и неизменяемым дайджестом. Дальше меняется только ссылка на него в конфигурации окружения:

```yaml
# overlays/prod/kustomization.yaml
images:
  - name: api
    newName: registry.example.com/api
    digest: sha256:9f86d081884c7d65…
```

Что может различаться между окружениями: адреса зависимостей, секреты, число реплик, лимиты ресурсов, значения [флагов](/glossary/feature-flag/). Каждое такое отличие — место, которое предыдущее окружение не проверило.

Пересборка «для прода» ломает смысл проверки: другая сборка может отличаться базовым образом, версией компилятора, пакетами. В [GitOps](/glossary/gitops/) продвижение — это пулл-реквест, меняющий дайджест в конфигурации следующего окружения.
