**RED** — для всего, что обслуживает запросы:

- **Rate** — сколько запросов в секунду;
- **Errors** — сколько из них ошибочных;
- **Duration** — распределение длительности (гистограмма, а не среднее).

**USE** — для каждого ресурса: процессора, памяти, диска, пула соединений, очереди:

- **Utilization** — какую долю времени ресурс занят;
- **Saturation** — сколько работы ждёт ресурс: длина очереди, время ожидания;
- **Errors** — отказы ресурса.

Насыщение важнее загрузки. Загрузка в 70% ничего не говорит о том, ждёт ли кто-то; растущая очередь — говорит. Для сервиса на Go это:

| Ресурс | Насыщение |
| --- | --- |
| пул `database/sql` | `WaitCount`, `WaitDuration` из `db.Stats()` |
| `pgxpool` | `EmptyAcquireCount`, `AcquireDuration` из `pool.Stat()` |
| процессор в контейнере | время троттлинга из cgroup |
| горутины | `go_goroutines`, если растёт без роста нагрузки |
| память | частота циклов сборщика, близость к `GOMEMLIMIT` |
| потребитель Kafka | лаг во времени |

Вместе с задержкой, трафиком и ошибками насыщение составляет «четыре золотых сигнала» из книги Google SRE.
