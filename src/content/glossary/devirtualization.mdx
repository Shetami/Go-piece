Вызов через интерфейс — косвенный: адрес метода берётся из [itab](/glossary/itab/) во время выполнения. Компилятор не знает, кого вызывают, поэтому не может встроить тело метода, а [анализ побега](/glossary/escape-analysis/) вынужден считать, что аргументы убегают.

Девиртуализация снимает это в двух случаях:

- **статически** — когда из кода видно, что в интерфейсе лежит конкретный тип: `var s Shape = Rect{}; s.Area()` или вызов после встраивания функции, принимающей интерфейс;
- **по профилю (PGO)** — с Go 1.21: если в `default.pgo` видно, что в горячем месте почти всегда лежит один тип, компилятор вставляет проверку `if t, ok := s.(Rect); ok { t.Area() } else { s.Area() }`.

Проверить: `go build -gcflags=-m` печатает `devirtualizing s.Area to Rect`.
