```go
type Counter struct {
    mu sync.Mutex
    n  map[string]int
}

func (c *Counter) Inc(k string) {
    c.mu.Lock()
    defer c.mu.Unlock()
    c.n[k]++
}
```

Как он устроен: быстрый путь — один CAS по полю состояния. Если занято, горутина немного крутится в ожидании, а потом паркуется (как на канале). Если кто-то ждёт дольше **1 мс**, мьютекс переходит в режим голодания: замок передаётся строго по очереди, новые горутины не перехватывают его. Это ограничивает хвосты задержки ценой пропускной способности.

Правила:

- **Мьютекс не копируют.** Структура с мьютексом — только по указателю, и методы — на указателе. `go vet` ловит копии.
- **Мьютекс не реентерабелен.** Повторный `Lock` в той же горутине — вечная блокировка.
- **Мьютекс не привязан к горутине.** Разблокировать может другая, но так почти никогда не нужно.
- **Внутри критической секции не ждут.** Никакого ввода-вывода, походов в сеть, отправки в канал: всё это растягивает секцию и собирает очередь.
- **Мьютекс лежит рядом с тем, что защищает**, а поля под ним обычно отделяют пустой строкой или комментарием.
