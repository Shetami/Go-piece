Уровни находок:

- **модуль** есть в зависимостях;
- **пакет** с уязвимостью импортирован;
- **функция** с уязвимостью достижима из вашего кода.

Ненулевой код возврата — только для последнего уровня. Это резко снижает шум по сравнению со сканерами, которые смотрят только на версии.

Граф вызовов строится статически: вызовы через рефлексию и интерфейсы анализ может оценить неточно.

Запускают в трёх местах:

- в пулл-реквестах — `govulncheck ./...`;
- **по расписанию на `main`** — новые уязвимости появляются в базе, когда код не меняется;
- по готовому бинарнику — `govulncheck -mode=binary ./app`: информация о модулях записана в бинарнике.

О намеренно вредоносных модулях govulncheck не знает — только об опубликованных уязвимостях.
