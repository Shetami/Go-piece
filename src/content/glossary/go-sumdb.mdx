Защита зависимостей в Go складывается из нескольких частей:

- **`go.sum`** — хеши каждой версии модуля в проекте. Другое содержимое — сборка падает;
- **база контрольных сумм** — при первом добавлении версии хеш сверяется с публичным журналом. Автор не может показать разным пользователям разное содержимое одной версии;
- **зеркало модулей** `proxy.golang.org` кэширует версии навсегда: удалённый или переписанный тег в git не меняет того, что отдаёт зеркало;
- **`-mod=readonly`** по умолчанию — сборка не меняет `go.mod` сама;
- **нет скриптов установки** — код зависимости не выполняется при сборке.

Приватные модули исключают из проверки через `GOPRIVATE` — иначе их пути уйдут во внешний сервис.

Не защищает от вредоносного модуля, добавленного сознательно. Пример: тайпсквоттинг `github.com/boltdb-go/bolt` с бэкдором, найденный в 2025 году, несколько лет отдавался зеркалом из кэша даже после того, как тег в git переписали на чистый код.
