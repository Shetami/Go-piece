```go
c.L.Lock()
for !ready() {   // только for, не if
    c.Wait()     // атомарно: отпустить L, уснуть, при пробуждении снова взять L
}
use()
c.L.Unlock()
```

Условие проверяют в цикле: между пробуждением и повторным захватом замка его мог изменить кто-то другой.

У Cond нет отмены: `Wait` нельзя прервать ни контекстом, ни таймаутом. Поэтому в сервисном коде его почти всегда заменяют каналом: одноразовый сигнал всем — [закрытие канала](/glossary/chan-close/), многоразовый — канал, который подменяют на новый при каждом событии.
