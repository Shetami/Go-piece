```go
type iface struct {     // интерфейс с методами: io.Reader, error
    tab  *itab          // какой интерфейс, какой тип, адреса методов
    data unsafe.Pointer // значение
}

type eface struct {     // пустой интерфейс: any
    _type *_type        // только тип — методов не обещано
    data  unsafe.Pointer
}
```

Переменная интерфейсного типа занимает 16 байт на 64-битной платформе. Первое слово отвечает на вопрос «что внутри», второе — «где оно».

- **присваивание в интерфейс копирует значение.** Если тип сам по себе указатель (`*T`, карта, канал, функция), он кладётся прямо в `data`. Иначе `data` указывает на копию — часто в куче, если компилятор не докажет, что она не убегает;
- **интерфейс равен `nil`, только когда пусты оба слова.** Nil-указатель с известным типом внутри — уже не nil, см. [nil с типом](/glossary/typed-nil/);
- **`==` сравнивает тип и значение.** `any(1) == any(int64(1))` — ложь, а сравнение двух интерфейсов, в которых лежат слайсы, — паника.
