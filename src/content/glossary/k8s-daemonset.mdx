Приложениям DaemonSet почти никогда не нужен: число реплик должно определяться нагрузкой, а не числом узлов. Его место — инфраструктура: fluent-bit, node-exporter, CNI-плагины (Cilium, Calico), CSI-драйверы, kube-proxy.

Чтобы агент работал и на особых узлах (с taint-ами для GPU, для control plane), ему добавляют соответствующие tolerations. Ограничить набор узлов можно через `nodeSelector` или affinity.

Поды DaemonSet обновляются плавно, по одному узлу за раз (`maxUnavailable: 1` по умолчанию).
