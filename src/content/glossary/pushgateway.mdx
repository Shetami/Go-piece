Pull не работает для задач, которые живут меньше интервала сбора: cron, миграция, CI. Такая задача перед выходом отправляет метрики в Pushgateway:

```go
push.New("http://pushgateway:9091", "nightly_export").
    Collector(lastSuccess).
    Collector(rowsExported).
    Push()
```

Ограничения, из-за которых Pushgateway — инструмент для узкого случая:

- **значения живут вечно**, пока их не удалят. Задача, которая перестала запускаться, выглядит как последний успешный запуск. Поэтому главная метрика — время последнего успеха: алерт на `time() - job_last_success_timestamp_seconds > 26 * 3600`;
- **`up` означает «жив Pushgateway»**, а не задача;
- **единая точка отказа** и место, где копятся метрики всех задач.

Для постоянно работающих сервисов, которые нельзя собирать по pull, используют OTLP или [remote write](/glossary/remote-write/) через агент.
