```
traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01
             версия-ID трассы-ID родительского спана-флаги (01 — выбрана)
```

Внутри процесса Go контекст трассы живёт в `context.Context`. На границах его переносит пропагатор: `Extract` из входящего запроса, `Inject` в исходящий. Готовые обёртки (`otelhttp`, `otelgrpc`) делают это сами, для Kafka пишут маленький адаптер `TextMapCarrier` над заголовками сообщения или берут плагин клиента.

Где трасса рвётся:

- исходящий вызов без контекста: `http.NewRequest` вместо `http.NewRequestWithContext`;
- фоновая горутина с `context.Background()` — новая трасса без родителя. Нужен `context.WithoutCancel(ctx)`: значения сохраняются, отмена — нет;
- очередь или брокер без заголовков контекста;
- прокси или шлюз, который не пропускает `traceparent`.

**Baggage** — соседний заголовок с парами «ключ-значение», которые едут по всей цепочке. Уходит во все вызовы, включая внешние, поэтому — ничего секретного и ничего большого.
