| Тип | Методы с получателем `T` | Методы с получателем `*T` |
| --- | --- | --- |
| `T` | есть | **нет** |
| `*T` | есть | есть |

Поэтому `var w io.Writer = buf` не скомпилируется, если `Write` объявлен на `*Buffer`, а `buf` — значение: нужно `&buf`.

Причина — адресуемость. Метод с получателем-указателем должен менять исходный объект. Интерфейс же хранит **копию** значения, и взять её адрес так, чтобы изменения дошли до оригинала, нельзя. Вместо тихой работы с копией язык запрещает такое присваивание.

Прямой вызов `v.Inc()` на адресуемой переменной работает — компилятор сам подставит `(&v).Inc()`. Ограничение касается только интерфейсов и неадресуемых значений вроде `m[k].Inc()`.
