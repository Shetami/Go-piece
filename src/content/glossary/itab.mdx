```go
type ITab struct {
    Inter *InterfaceType
    Type  *Type
    Hash  uint32     // копия Type.Hash — для type switch
    Fun   [1]uintptr // на самом деле столько, сколько методов в интерфейсе
}
```

`Fun` перечисляет методы интерфейса в порядке сортировки по имени. Вызов `r.Read(p)` компилируется в «взять `tab.Fun[0]`, вызвать, передав `data` получателем» — косвенный вызов, как через vtable в C++.

Откуда берётся:

- **компилятор** создаёт itab заранее для каждой пары, которая видна в коде как преобразование `T → I`. В бинарнике это символы `go:itab.main.Rect,main.Shape`;
- **рантайм** строит её при утверждении типа к интерфейсу (`x.(io.WriterTo)`), если пары нет: `getitab` сливает отсортированные списки методов типа и интерфейса за O(n + m) и кладёт результат в глобальную таблицу `itabTable`. Следующая проверка той же пары — поиск в хэш-таблице.

Отрицательный результат тоже кэшируется: у такой itab `Fun[0] == 0`.
