Это [контроллер](/glossary/k8s-controller/), у которого желаемое состояние лежит в git: цикл «прочитать git → сравнить с кластером → применить разницу».

По сравнению с push-доставкой из CI:

- **CI не нужен доступ к кластеру** — только к репозиторию конфигурации;
- **история окружения — история git**: кто, когда и что поменял, с ревью;
- **дрейф виден**, а с self-heal — исправляется.

Ловушки self-heal:

- **ручной откат** на инциденте (`kubectl rollout undo`) агент считает дрейфом и возвращает сломанную версию. Откатывают через `git revert` или сначала отключают автосинхронизацию;
- **`replicas` в git + HPA** — агент сбрасывает число реплик, поднятое автомасштабированием. Поле убирают из манифеста или добавляют в `ignoreDifferences`.

Секреты в git — только зашифрованные (Sealed Secrets, SOPS) или ссылками на внешнее хранилище (External Secrets Operator).
