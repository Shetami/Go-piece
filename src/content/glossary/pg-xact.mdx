Версия строки знает только номер создавшей её транзакции. Чтобы понять, видна ли она, нужно узнать, чем эта транзакция кончилась. Для этого есть pg_xact — плотный массив статусов, по два бита на каждый xid, страницы которого кэшируются в памяти.

Отсюда главное свойство MVCC в PostgreSQL: **коммит и откат не трогают строки**. Транзакция изменила миллион строк — на коммите меняется один статус в pg_xact, и все миллион версий разом становятся видны. Откат такой же мгновенный: статус «откачена», и все её версии стали мёртвыми.

Для скорости результат проверки кэшируется в самой строке (hint bits в [заголовке версии](/glossary/xmin-xmax/)), чтобы следующему читателю не нужно было смотреть в pg_xact.
