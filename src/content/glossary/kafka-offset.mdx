Оффсет — индекс записи в [партиции](/glossary/kafka-partition/): 0, 1, 2… Продюсер его заранее не знает — номер назначает лидер в момент записи и возвращает в ответе.

У одной партиции есть несколько важных оффсетов сразу:

| Оффсет | Что значит |
| --- | --- |
| log start | самый старый, который ещё хранится ([retention](/glossary/log-retention/) удаляет всё до него) |
| committed группы | с какого места группа продолжит чтение ([коммит](/glossary/offset-commit/)) |
| [high watermark](/glossary/high-watermark/) | всё ниже него закоммичено и видно потребителям |
| log end (LEO) | куда будет записано следующее сообщение |

Потребитель сам хранит свою позицию, брокер за него ничего не помнит. Поэтому перечитать топик — это просто сдвинуть оффсет назад (`kafka-consumer-groups.sh --reset-offsets`), а разница между HW и закоммиченным оффсетом — это [лаг](/glossary/consumer-lag/).

Тонкость: после [нечистого выбора лидера](/glossary/leader-election/) на один и тот же оффсет могут в разное время попасть разные сообщения. Однозначен оффсет только вместе с эпохой лидера.
