Составные части:

- **cosign** подписывает образ **по дайджесту**. В режиме без ключей используется [OIDC-токен](/glossary/ci-oidc/) конвейера: Fulcio выдаёт короткоживущий сертификат с именем workflow и репозитория, подпись записывается в журнал прозрачности Rekor;
- **аттестация происхождения** (SLSA provenance) — подписанное утверждение: из какого коммита, каким workflow, на каком раннере собран этот дайджест. В GitHub — `actions/attest-build-provenance`;
- **проверка при допуске** — Kyverno или Sigstore policy-controller в кластере пропускают только образы с подписью нужного workflow из нужной ветки.

Без проверки подпись бесполезна: её наличие ничего не меняет, если кластер запускает и неподписанные образы. С проверкой образ, запушенный в реестр украденными учётными данными, не запустится.
