short: Цепочка стадий, соединённых каналами. Каждая стадия читает вход, пишет выход и закрывает его, когда вход кончился. Отмена — общий контекст для всех стадий.
aliases: [pipeline, конвейер, стадия, stage, генератор]
category: механизм
related: [fan-out-fan-in, chan-close, backpressure, context-cancellation]
---

Стадия конвейера — функция с одной формой:

```go
func stage(ctx context.Context, in <-chan A) <-chan B {
    out := make(chan B)
    go func() {
        defer close(out)              // стадия — единственный писатель, она и закрывает
        for a := range in {
            select {
            case out <- f(a):
            case <-ctx.Done():
                return                // потребитель ушёл — не висим на отправке
            }
        }
    }()
    return out
}
```

Свойства, ради которых конвейер строят:

- **Стадии работают одновременно**: пока третья пишет в базу, первая уже читает следующий кусок.
- **Обратное давление бесплатно.** Медленная стадия не забирает значения, предыдущая блокируется на отправке — [backpressure](/glossary/backpressure/) без единой строчки кода.
- **Пропускная способность = пропускной способности самой медленной стадии.** Ускорять имеет смысл только её — обычно через [fan-out](/glossary/fan-out-fan-in/).
