Транспорт `net/http` держит пул соединений по хостам. Соединение HTTP/1.1 возвращается в пул только когда тело ответа **прочитано до конца и закрыто**:

- тело не закрыто — соединение, файловый дескриптор и две горутины транспорта (`readLoop` и `writeLoop`) живут, пока процесс не упадёт. Это утечка;
- закрыто, но не дочитано — транспорт не может переиспользовать соединение (в нём остались чужие байты) и закрывает его. Следующий запрос платит за новое соединение и TLS.

```go
resp, err := client.Do(req)
if err != nil {
    return err
}
defer resp.Body.Close()
// Если тело не нужно — дочитать, но с пределом: вдруг там гигабайт.
defer io.Copy(io.Discard, io.LimitReader(resp.Body, 64<<10))
```

`defer` выполняются в обратном порядке: сначала дочитывание, потом закрытие. Линтер `bodyclose` ловит забытый `Close`.
