На диске партиция — это каталог `orders-0/` с файлами:

```
00000000000000000000.log        данные: пакеты записей подряд
00000000000000000000.index      оффсет → позиция в .log (разреженный)
00000000000000000000.timeindex  время → оффсет
00000000000000482193.log        следующий сегмент начинается с оффсета 482193
...
```

Имя сегмента — оффсет его первой записи. Пишется только последний (активный) сегмент; когда он дорастает до `segment.bytes` (1 ГБ) или стареет на `segment.ms`, открывается новый.

Зачем резать лог на куски:

- **Удалять дёшево.** [Retention](/glossary/log-retention/) удаляет старые сегменты целиком — одной операцией с файлом, без перезаписи.
- **Искать быстро.** Чтобы найти оффсет, брокер бинарным поиском выбирает сегмент по имени, потом по разреженному индексу — ближайшую позицию, и дочитывает несколько килобайт.

Индекс разреженный: запись в него делается раз на `index.interval.bytes` (4 КБ) данных, поэтому он маленький и целиком живёт в памяти.
